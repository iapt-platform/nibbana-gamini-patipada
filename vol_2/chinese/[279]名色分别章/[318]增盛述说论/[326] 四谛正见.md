### 四谛正见(catusacca sammādiṭṭhi)

Katamā ca bhikkhave sammādiṭṭhi? Yaṃ kho bhikkhave dukkhe ñāṇaṃ, dukkhasamudaye ñāṇaṃ, dukkhanirodhe ñāṇaṃ, dukkhanirodhagāminiyā paṭipadāya ñāṇaṃ.
Ayaṃ vuccati bhikkhave sammādiṭṭhi. (M 1, 88.)

无论称作正见(sammādiṭṭhi)，还是称作慧根(paññindriya)=慧(paññā)，还是称作无痴(amoha)，还是称作择法(dhammavicaya)，如此以种种异门(pariyāya)名称来称呼、使用的这个法，其实只是慧根这一个心所(cetasika)而已。

- 1. 以过去(atīta)、未来(anāgata)、现在(paccuppanna)、内在(ajjhatta)、外在(bahiddha)、粗(oḷārika)、细(sukhuma)、劣(hīna)、胜(paṇīta)、远(dūra)、近(santika)这十一种形态而存在的五取蕴(upādānakkhandhā)——苦谛(dukkha-saccā)诸法，能了知它们的智，名为正见。
在这一组苦谛诸法当中，禅那(jhāna)诸法也包含在内。

- 2. 正如《增支部(Aṅguttara)·三集(Tikanipāta)·外道处经(Titthāyatana Sutta)》中所开示的那样，能如实了知因—果相续=缘起法(paṭiccasamuppāda)诸法的因—果关联方式与形态的智，名为了知集谛(samudaya-saccā)的正见。
在这一部分中，能透彻观见业(kamma)—业之果报的业自性正见(kammassakatā sammādiṭṭhi)以圆满的程度包含在内。
这是最高层次的业自性正见。
之所以说它是最高层次，是因为它并非依凭他人的言说而怀想，而是自己亲眼现见、透彻观见业—业之果报的智。
至于依凭老师言说而怀想的、对业—业之果报的懂得与了解，就不如自己亲眼现见、透彻观见的那样层次高。
层次虽然不高，但对于还不能以智见触及究竟法(paramattha)的凡夫(puthujjana)世人来说，依据老师们的教诫为基础、借助比量智(anumāna)加以推测，也能够对业—业之果报生起信受，也能够成为业自性正见。
若连这种业自性正见都不了知，或者根本没有，那么在造作某一善行(kusala)时，就会成为不带智的、层次极其低下的那种业。
当那种业给予果报时，就会成为智力迟钝者、呆滞者、愚痴者、痴呆者一类的人。

- 3. 能透彻了知诸行(saṅkhāra)之坏灭(bhaṅga)的观智(vipassanā ñāṇa)，以及能透彻观见名为毕竟灭(accantanirodha)的、诸行诸法止息之处的无为界(asaṅkhata dhātu)、寂静界、涅槃(nibbāna)=灭谛(nirodha-saccā)诸法的圣道智(ariya magga ñāṇa)，都名为正见。
（观智是世间(lokī)正见，圣道智是出世间(lokuttarā)正见。）这是了知灭谛的正见。

- 4. 亲身现见、透彻观见通往苦之止息处涅槃的修行次第——即世间道谛(magga-saccā)、出世间道谛诸法，这也名为正见。
凡是真正的正见，全都归摄于这四谛正见之中，全都以这四谛正见为归趣。
因此，从另一种角度，也可以按下列方式对正见加以区分界定。

- 1. 业自性正见=懂得了知“唯有业才是自己所拥有的财产”这一事实的正见。
  - （甲）依老师们的教诫、借比量智推测而信受的业自性正见；
  - （乙）借名色分别智(nāmarūpapariccheda ñāṇa)、缘摄受智(paccayapariggaha ñāṇa)，亲身以现见的亲见(paccakkha)之智，透彻观见苦谛诸法、集谛诸法之因—果关联的性质，从而获得的业自性正见——
- 2. 禅那正见(jhāna sammādiṭṭhi)=与禅那定(samādhi)相应的智这种正见（归摄于了知苦谛的智之中）。
- 3. 观正见(vipassanā sammādiṭṭhi)=与能透彻观见苦谛诸法、集谛诸法之无常(anicca)-苦-无我(anatta)形态的观智相应的正见——
- 4. 道正见(magga sammādiṭṭhi)=与圣道(ariya magga)相应的智——
- 5. 果正见(phala sammādiṭṭhi)=与圣果(ariya phala)相应的智——

粗略地说，也可以这样把正见区分为五种。
它们全都归摄于四谛正见之中。
这些正见之智，称为无痴=慧。

在造作某一善行时，至少也需要具备这样的业自性正见——即依老师们的教诫而懂得了知“唯有业才是自己所拥有的财产”的那种正见。
倘若连这种正见之智都没有，不能端正地持守正确的见解，那么所造作的一切善，大多就只会是智不相应善(ñāṇavippayutta kusala)而已。
这些善若逢机缘成熟而给予果报，就会把人送入愚劣者、痴愚者、痴呆者的境地，乃至沦为顽冥愚钝的境地。

倘若有能力，能亲自获得名色分别智、缘摄受智，从而生起、具足业自性正见的智见，并以这智为先导来培育造作某一善行，那么它就能成为一个层次更高的业。
当那种业给予果报时，在果报所现起的那一生里，就能成为智慧广大的人。

倘若具足禅那正见之智，那么与这正见之智相应的禅那善思(cetanā)，便有能力把人送往层次高的梵天(brahmā)之生。
只要直到临终禅那都不退失，就能够到达梵天界。

倘若能在观正见诸智的环绕下培育造作某一业，那么在人中就能成为人上之人，在天神(deva)中成为天上之天神。
但是，对于色-名(rūpa-nāma)——正如本书“色业处(kammaṭṭhāna)部分”“名业处部分”中所陈述的那样——必须让智见深入到究竟法为止，这是必要的。
如此这般智见已深入到究竟法的一位善人——在造作某一次供养饮食的布施(dāna)善行时——

- 1. 把正在行布施的自己相续(santāna)中存在的色-名-究竟法诸法摄取起来，用智加以分辨，将这些色-名安立于无常-苦-无我三种相(lakkhaṇa)上，修习观修行(bhāvanā)业处；——
- 2. 对于各个受施补特伽罗(puggala)相续中存在的色-名-究竟法诸法，也作为同属外在、彼此相同、一般地总括汇集起来摄取，然后将这些色-名安立于三相上，修习观修行业处；——
- 3. 若对各种各样的所施之物专注地以四界观照，就只会发现色聚(rūpa kalāpa)的微粒。
这些色聚，只不过是由存在于一个色聚内部的火界(tejo dhātu)=季节(utu)所辗转不断产生的、以食素(ojā)居第八的“食素为第八的色(ojaṭṭhamaka rūpa)”而已。
用智把这些“食素为第八的色”分辨、摄取起来后，将这些色法安立于三相上，修习观修行业处；——
- 4. 对于以布施之善思为先导的大善(mahākusala)意门速行心路的心(manodvārika javana vīthicitta)这一系列的名法诸法，也摄取起来，将这些善法安立于三相上，修习观修行业处；——

若在这样的观智环绕下培育造作某一布施善行，那么由于该布施业被层次最高的观智所环绕，当该布施业逢机缘成熟给予果报、以结生(paṭisandhi)之力促成某一生时，那人便会成为具足如金刚杵(vajira)武器、如雷电之力般极其锐利、犀利之智慧的人。

智慧锐利的种种情形，佛陀在《随流经(Sotānugata Sutta)》中作了开示。
其中一种情形是这样的。

So muṭṭhassati kālaṃ kurumāno aññataraṃ devanikāyaṃ upapajjati, tassa tattha sukhino dhammapadā plavanti, dandho bhikkhave satuppādo, atha so satto khippaṃyeva visesagāmī hoti. (A 1, 505.)

（意思是）——某位比库(bhikkhu)虽修习观修行业处，却未能达到道智(magga ñāṇa)、果智(phala ñāṇa)，而以凡夫之身命终，那么他便会以结生（以化生(opapātika)结生）投生到某一天界。
在那天界、天的世间中享有安乐、乐(sukha)的那位天子的相续里，作为观智所观照对象（所缘 ārammaṇa）的色-名诸行=一组组法句，都清晰显现着（=大大地浮现着）。
诸比库！那与能顺次遍观、审察这些究竟法之法句的观智相应的念(sati)之生起（=与念相应的观智之生起），仍很迟缓；然而实际上，那位天子有情(satta)却能极其迅速地获得（道智、果智）称为涅槃的那种殊胜之法、伟大之妙法。(A 1, 505.)

这就是一个例证：由于能在层次最高的观智环绕下培育造作层次最高的诸业，凭借那些业，便获得了能透彻观见直至涅槃的殊胜之法、伟大妙法的极其锐利的智慧。

Tassa te dhammā sotānugatā honti vacasā paricitā manasānupekkhitā diṭṭhiyā suppaṭividdhā. (A 1, 505.)

**Diṭṭhiyā suppaṭividdhā**ti atthato ca kāraṇato ca paññāya suṭṭhu paṭividdhā paccakkhaṃ katā. (A-a 2, 364.)

那位天子，当他身处人间、还是比库时，就学习并背诵了具足九分(aṅga)的佛陀之诸法教，并以究竟法自体、义理的方式，用正见之智慧亲身现见、透彻观见了色究竟法(rūpa paramattha)、名究竟法(nāma paramattha)诸法，以及那些色-名的因缘诸法。
他获得了观正见诸智。
直到临死、临终速行(maraṇāsanna javana)之时，他都能修习观修行业处。
那位比库的临终速行，缘取着诸行诸法的无常形态，或者苦形态，或者无我形态。
正是那比库之生的临终速行的所缘，被天子之生的结生、有分(bhavaṅga)、死殁(cuti)所承接、缘取。

由于作为家主的有分心本身在缘取诸行诸法，换言之，由于它在缘取诸行诸法的无常形态、苦形态、无我形态中的某一种，因此，当能顺次忆念、摄取那法教的、与观智相应的念在那位天子的相续中生起时，那与观智相应的念之生起虽仍很迟缓；然而实际上，在那位比库的了知之智中作为观智所观照对象的、于比库之生所曾修习熟练的一组组法句，便——**pasanne ādāse chāyāviya pavanti, pākaṭā hutvā paññāyanti**。(A-a 2, 365.)

= 如同镜面上的影子般显赫地浮现着，清清楚楚地显现出来。
因此，与能顺次遍观、审察那法教的观智相应的念之生起虽然迟缓，他却极其迅速地获得了涅槃。

然而，在这一部分中应当注意的一点是——若不曾亲见真实的究竟法色-名，仅凭口中念诵“无常-苦-无我”，是不会成为观智的。
被不真、不实的假观智所环绕的业，是不可能像被真实观智所环绕的业那样，把人送到智慧广大者的层次的。
这一点是很应当注意的。
