### 观察区 简要

- 一、**见(diṭṭha)** ---- (甲) 所见之法 = 色所缘(rūpārammaṇa)
  - ( 乙 ) 能见之法 = 眼门心路(cakkhudvāravīthi)、意门心路(manodvāravīthi)的名(nāma)法群
- 二、**闻(suta)** ---- (甲) 所闻之法 = 声所缘(saddārammaṇa)
  - ( 乙 ) 能闻之法 = 耳门心路(sotadvāravīthi)、意门心路的名法群
- 三、**觉知(muta)** ---- (甲) 所触之法 ---- 1. 香所缘(gandhārammaṇa)
- 2. 味所缘(rasārammaṇa)
- 3. 触所缘(phoṭṭhabbārammaṇa)
  - ( 乙 ) 能触之法 ---- 

- 1. 鼻门心路(ghānadvāravīthi) ---- 意门心路的名法群
- 2. 舌门心路(jivhādvāravīthi) ---- 意门心路的名法群
- 3. 身门心路(kāyadvāravīthi) ---- 意门心路的名法群
- 四、**识知(viññāta)** ---- (甲) 所识知之法 = 法所缘(dhammārammaṇa)
  - ( 乙 ) 能识知之法 = 意门心路的名法群

对上述这(四)种 ---- 见-闻-觉知-识知诸法，要用智(ñāṇa)将所谓「色团色块、名团名块」的色密集(rūpaghana)、名密集(nāmaghana)加以破析摧毁，使智见契入究竟法(paramattha)，首先应当摄取。 
要用智加以辨别划分。(摄取的方式已在前面详细说明过了。)

此后，探寻那些色、名的因法，摄取因法与果法。 
(这将在缘起法(paṭiccasamuppāda)部分、缘摄受智(paccayapariggahañāṇa)部分中显明。)

此后，将连同其因法的那些色、名安立于三种相(lakkhaṇa)之上，修习观(vipassanā)并加以审察。(这将在观禅部分中显明。) 
此后，关于往后应当继续修习的工作领域，世尊对跋黑亚(bāhiya)以**yato kho te bāhiya** ---- 等语继续作了开示。
