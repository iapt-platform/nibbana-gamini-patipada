### 法随观 觉支节(bojjhaṅgapabba)(= 觉支部分)第一阶

puna caparaṃ bhikkhave bhikkhu dhammesu dhammānupassī viharati sattasu bojjhaṅgesu.
kathañca pana bhikkhave bhikkhu dhammesu dhammānupassī viharati sattasu bojjhaṅgesu.

idha bhikkhave bhikkhu santaṃ vā ajjhattaṃ satisambojjhaṅgaṃ "atthi me ajjhattaṃ satisambojjhaṅgo"ti pajānāti, asantaṃ vā ajjhattaṃ satisambojjhaṅgaṃ "natthi me ajjhattaṃ satisambojjhaṅgo"ti pajānāti, yathā ca anuppannassa satisambojjhaṅgassa uppādo hoti, tañca pajānāti, yathā ca uppannassa satisambojjhaṅgassa bhāvanāya pāripūrī hoti, tañca pajānāti. (M-1-80.)

诸比库……再者，那位瑜伽者(yogāvacara)比库(bhikkhu)于七种觉支(bojjhaṅga)的诸法自性之中，一再地、层层反复地惯常观照诸法自性而安住。
诸比库……瑜伽者比库究竟是如何于七种觉支的诸法自性之中，一再地、层层反复地惯常观照诸法自性而安住的呢？

诸比库……在此教法中，那位瑜伽者比库当自己的相续(santāna)中念觉支(satisambojjhaṅga)之法明显现前时，便了知"我的相续中念觉支之法明显现前"。
当自己的相续中念觉支之法未明显现前时，便了知"我的相续中念觉支之法未明显现前"。
对于尚未生起的念觉支之法的生起之因法，他也了知。
对于已经生起的念觉支之法之修习(bhāvanā)智的圆满成就之因法，他也了知。(M-1-80。)

对于择法觉支(dhammavicayasambojjhaṅga)、精进觉支(vīriyasambojjhaṅga)、喜觉支(pītisambojjhaṅga)、轻安觉支(passaddhisambojjhaṅga)、定觉支(samādhisambojjhaṅga)、舍觉支(upekkhāsambojjhaṅga)诸法，也以同样的方式作了开示。全部合起来便是七种觉支。

- 1。(甲)能摄受名为身(kāya)-受(vedanā)-心(citta)-法(dhamma)的五取蕴(upādānakkhandhā)的念(sati)，
  - ( 乙 ) 能摄受那五取蕴的诸因法的念，
  - ( 丙 ) 能摄受连同因法在内的那五取蕴的无常(anicca)之情状、苦(dukkha)之情状、无我(anatta)之情状、不净(asubha)之情状的念 --- 这各别的念便名为**世间(lokī)念觉支**。
  - (丁) 与圣道(ariyamagga)相应的念便名为**出世间(lokuttarā)念觉支**。
- 2。(甲)能探究思择 = 能洞穿了知那名为善(kusala)、不善(akusala)等的身-受-心-法的五取蕴的慧(paññā)，
  - ( 乙 ) 能探究思择 = 能洞穿了知那五取蕴的诸因法的慧，
  - ( 丙 ) 能探究思择 = 能洞穿了知连同因法在内的那五取蕴的无常之情状、苦之情状、无我之情状、不净之情状的观慧(vipassanā paññā) --- 这各别的慧便名为**世间择法觉支**。
  - (丁) 与圣道相应的慧便名为**出世间择法觉支**。
- 3。(甲)为了洞穿了知名为身-受-心-法的五取蕴而努力精勤 = 精进(vīriya)，
  - ( 乙 ) 为了了知那五取蕴的诸因法而努力精勤 = 精进，
  - ( 丙 ) 为了洞穿了知连同因法在内的那五取蕴的无常之情状、苦之情状、无我之情状、不净之情状而努力精勤 = 精进，这各别的精进便名为**世间精进觉支**。即是与观智(vipassanā ñāṇa)相应的精进。
  - (丁) 与圣道相应的正精进(sammāvāyāma)道支(maggaṅga)便名为**出世间精进觉支**。
- 4。(甲)在洞穿了知那与念-择法-精进诸觉支相应的、名为身-受-心-法的五取蕴之际所生起的喜悦——喜(pīti)，
  - ( 乙 ) 在洞穿了知那五取蕴的诸因法之际所生起的喜悦——喜，
  - ( 丙 ) 在洞穿了知连同因法在内的那五取蕴的无常之情状、苦之情状、无我之情状、不净之情状之际所生起的喜悦——喜 --- 这各别的喜便名为**世间喜觉支**。
即是与观智相应的喜。
  - (丁) 与圣道相应的喜便名为**出世间喜觉支**。
- 5。(甲)在洞穿了知那与念-择法-精进-喜诸觉支相应的、名为身-受-心-法的五取蕴之际所生起的心、心所(cetasika)的寂静——轻安(passaddhi)，
  - ( 乙 ) 在洞穿了知那五取蕴的诸因法之际所生起的心、心所的寂静——轻安，
  - ( 丙 ) 在洞穿了知连同因法在内的那五取蕴的无常之情状、苦之情状、无我之情状、不净之情状之际所生起的心、心所的寂静——观轻安 --- 这各别的轻安便名为**世间轻安觉支**。
  - (丁) 与圣道相应的轻安便名为**出世间轻安觉支**。
- 6。(甲)在那与念-择法-精进-喜-轻安等觉支相应的、名为身-受-心-法的五取蕴所缘(ārammaṇa)之上安住专注——定(samādhi)，
  - ( 乙 ) 在那五取蕴的诸因法所缘之上安住专注的定，
  - ( 丙 ) 在连同因法在内的那五取蕴的无常之情状、苦之情状、无我之情状、不净之情状这某一种情状之上安住专注的定 --- 这各别的定便名为**世间定觉支**。
[**注** --- 藉由修习止(samatha)业处(kammaṭṭhāna)而获得的近行定(upacārasamādhi)、安止定(appanāsamādhi)，也同样名为世间定觉支。]
  - (丁) 与圣道相应的定便名为**出世间定觉支**。
- 7。(甲)能把在那与念-择法等觉支相应的、名为身-受-心-法的五取蕴所缘之上共同生起的心、心所诸法保持安住于中庸(majjhatta)情状的觉支舍(bojjhaṅgupekkhā)，
  - ( 乙 ) 能把在那五取蕴的诸因法所缘之上共同生起的心、心所诸法保持安住于中庸情状的觉支舍，
  - ( 丙 ) 能把在连同因法在内的那五取蕴的无常之情状、苦之情状、无我之情状、不净之情状之上共同生起的心、心所诸法保持安住于中庸情状的觉支舍 = 观舍(vipassanupekkhā) = 行舍(saṅkhārupekkhā) --- 这各别的舍便名为**世间舍觉支**。
在法体上，即是中舍性(tatramajjhattatā)心所。
(与第三禅(tatiyajhāna)相应的中舍性心所——即禅舍(jhānupekkhā)，与第四禅(catutthajhāna)相应的中舍性心所——即遍净舍(pārisuddhupekkhā)，也同样名为世间舍觉支。)
  - (丁) 与圣道相应的中舍性心所，便名为出世间舍觉支。
尊贵的瑜伽者个体(puggala)为了圆满具足尊贵的七种出世间觉支之法，就必须努力使自己圆满具足尊贵的七种世间觉支之法。
若要举出一种范式来说明：

- 1。把眼净色了知为色法的意门路速行心(manodvārikavīthijavana)，
- 2。把眼净色了知为眼净色的意门路速行心，
- 3。把眼净色了知为无常的意门路速行心，
- 4。把眼净色了知为苦的意门路速行心，
- 5。把眼净色了知为无我的意门路速行心，
- 6。把眼净色了知为不净的意门路速行心，

在这各个意门路速行心之中(若与智相应、与喜相应)，各自有名法三十四个。
在那些名法当中，含摄着念-择法-精进-喜-轻安-定-舍——即所谓的七种世间觉支之法。

若能以智把那些含有七种觉支之法的名法——把名为名团、名块的种种名密集(nāmaghana)——用智加以破解摧毁，直至智见抵达究竟法(paramattha)而摄受观修，那么当那些觉支之法在自己的相续中明显现前时，便也算是了知了它们明显现前的情形。
倘若未能把那些含有七种觉支之法的名法摄受到抵达究竟法的程度，那么便也算是了知了那些觉支之法在自己身上未明显现前的情形。
