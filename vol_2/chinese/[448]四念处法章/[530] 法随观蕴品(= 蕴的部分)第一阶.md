### 法随观(dhammānupassanā)蕴(khandha)品(= 蕴的部分)第一阶

Puna caparaṃ bhikkhave bhikkhu dhammesu dhammānupassī viharati pañcasu upādānakkhandhesu.
Kathañca pana bhikkhave bhikkhu dhammesu dhammānupassī viharati pañcasu upādānakkhandhesu.
Idha bhikkhave bhikkhu ---

- 1. iti rūpaṃ, iti rūpassa samudayo, iti rūpassa atthaṅgamo.
- 2. iti vedanā, iti vedanāya samudayo, iti vedanāya atthaṅgamo.
- 3. iti saññā, iti saññāya samudayo, iti saññāya atthaṅgamo.
- 4. iti saṅkhārā, iti saṅkhārānaṃ samudayo, iti saṅkhārānaṃ atthaṅgamo.
- 5. iti viññāṇaṃ, iti viññāṇassa samudayo, iti viññāṇassa atthaṅgamoti. (M-1-78.)

= 诸比库……再者,此外,瑜伽行者(yogāvacara)比库在五执取蕴(pañcupādānakkhandhā)的诸法(dhamma,法之自性)之中,一次又一次、层层叠叠地观察诸法而住。
诸比库……瑜伽行者比库如何在五执取蕴的诸法之中,一次又一次、层层叠叠地观察诸法而住呢?

诸比库……在此教法(sāsana)中,瑜伽行者比库——
- 1. (a) 这是色(rūpa)法。
  - ( b ) 这些是色法的生起之因的自性与生起的自性。
  - ( c ) 这些是色法的灭之因的自性与灭的自性。
- 2. (a) 这是受(vedanā)法。
  - ( b ) 这些是受法的生起之因的自性与生起的自性。
  - ( c ) 这些是受法的灭之因的自性与灭的自性。
- 3. (a) 这是想(saññā)法。
  - ( b ) 这些是想法的生起之因的自性与生起的自性。
  - ( c ) 这些是想法的灭之因的自性与灭的自性。
- 4. (a) 这些是心所(cetasika)的行(saṅkhāra)诸法聚。
  - ( b ) 这些是心所的诸行法的生起之因的自性与生起的自性。
  - ( c ) 这些是心所的诸行法的灭之因的自性与灭的自性。
- 5. (a) 这是识(viññāṇa)法。
  - ( b ) 这些是识法的生起之因的自性与生起的自性。
  - ( c ) 这些是识法的灭之因的自性与灭的自性。

如此,一次又一次、层层叠叠地观察而住。(M-1-78。)
