### 觉支(bojjhaṅga)= 觉支

在圣道智(ariyamaggañāṇa)之际，那尊贵的七种觉支之法无不足、无过分的和合一致，便称为**法和合(dhammasāmaggī)**。
其中，以择法(dhammavicaya)、精进(vīriya)、喜(pīti)为主导的法和合〔= 和合一致的七种觉支之法〕---

- 1。从修习所缘(bhāvanā-ārammaṇa)一再退缩、畏缩而生起的懈怠 = 以懈怠(kosajja)为主导的不善心(akusala citta)相续，也就是退缩(līna)之法的，
- 2。无论在此生、还是在轮回(saṃsāra)中，藉由烦恼(kilesa)之力而停滞不前，另一种说法即藉由渴爱(taṇhā)之力而停滞不前 = 停滞法(paṭiṭṭhāna)的，(意指以渴爱贪着执取某一世的生命而安住其中、不为求解脱而奋力挣扎。)
- 3。黏着于感官欲乐，为了享受感官欲乐而一再努力精勤 = 沉迷欲乐行(kāmasukhallikānuyoga)的，
- 4。以「所谓生命，仅存在于摇篮与棺材之间；一旦死亡便断灭无有；棺材那一边什么也没有」这样错误、颠倒地作意的 = 断灭黏着(ucchedaabhinivesa)的正相反、正面对立。
以轻安(passaddhi)、定(samādhi)、舍(upekkhā)为主导的法和合〔= 和合一致的七种觉支之法〕---

- 1。从修习所缘散乱开去的心散乱 = 掉举(uddhacca)的，
- 2。为了能在轮回中存续，为了往后一世又一世 = 为了使往后一世又一世、往后一蕴又一蕴不断生起而造作经营——即努力精勤于名为福行(puññābhisaṅkhāra)的欲界善业(kāmāvacara kusala kamma)、色界善业(rūpāvacara kusala kamma)，名为非福行(apuññābhisaṅkhāra)的不善业(akusala kamma)，以及名为不动行(āneñjābhisaṅkhāra)的无色界善业(arūpa kusala kamma)——即加行(āyūhana)的，另一种说法即藉由见(diṭṭhi)之力而精勤造作的加行的，
- 3。一再地、重重反复地努力精勤于使自身疲惫、折磨自己的苦行 = 自我疲惫行(attakilamathānuyoga)的，
- 4。以「我(atta)是恒常的，死后也不会断灭，只是一世接一世地迁移轮转」这样等等地作意的 = 常见黏着(sassataabhinivesa)的正相反、正面对立。

在圣道智之际，那和合一致的七种法的聚集，便称为菩提(bodhi)。
那名为菩提的、和合一致的法和合诸法聚集的组成部分，便名为觉支。所要表达的实义如下：

在出世间(lokuttarā)道智刹那所生起的、与上述心退缩、心散乱等众多逼近折磨的种种祸患正相反的、名为念(sati)、择法、精进、喜、轻安、定、舍的诸法的和合一致 = 藉由法和合，圣弟子(ariyasāvaka)——

- 1。能够从名为烦恼相续的沉睡中觉醒过来。
- 2。另一种说法，他能够洞穿觉知四谛圣法。
- 3。另一种说法，他能够藉由直接现证名为灭谛(nirodhasacca)的伟大尊贵的涅槃(nibbāna)圣法，而洞穿彻见它。

因此，那法和合便被称为菩提。
那七种法的和合一致 = 被称为法和合的那菩提的组成部分，便名为觉支。
应当如同禅支(jhānaṅga)= 禅支、道支(magganga)= 道支等情况一样来理解记忆。

正如把五个禅支的聚集称为禅那(jhāna)，而把那禅那的某一组成部分、某一支称为禅支 = 禅支一样；也正如把八种道支法体的聚集称为道(magga)，而把那道的某一组成部分、某一支称为道支 = 道支一样；同样地，依照「bodhiyā aṅgo bojjhaṅgo」---所说，那名为七种觉支之聚集的法和合的组成部分、即念等各别的一支，便应称为觉支 = 觉支---意即如此。(Abhi-A-1-262。Abhi-A-2-296。)

**bodhissa vā aṅgo bojjhaṅgo** --- 另一种说法 --- 由于藉由念、择法等这七种法的会合一致而能了知四谛，故那能了知四谛的圣弟子也被称为菩提。
又由于是那名为菩提的圣弟子的支分、组成部分，故名为觉支 = 觉支。
正如名为「军」(sena)的军队的组成部分——象军等——被称为军支(senaṅga)一样；正如马车 = 马车(即马拉的车)的组成部分——车轴、车声等——被称为车支(rathaṅga)= 车(ratha)的组成部分、支分一样；那生起于名为菩提的、被称为个体(puggala)的圣者尊贵之人的名色蕴(rūpanāmakhandha)相续中的念等，由于也是那名色相续的组成部分，故应称为觉支 = 觉支---意即如此。

**bodhāya saṃvattantīti bojjhaṅgā** = 由于是了知四谛之因法的缘故，念等七种法便名为觉支。

**bujjhantīti bojjhaṅgā** = 由于能了知四谛，故念等七种法的聚集名为诸菩提。
那些菩提本身便名为觉支 = 觉支。(菩提与支(aṅga)意义相同。)
anubujjhantīti bojjhaṅgā = 由于能随顺于观智(vipassanā ñāṇa)、道智(maggañāṇa)、果智(phalañāṇa)等因法而了知那些应知、值得了知的种种法的缘故，另一种说法，由于能随顺于值得了知的四谛诸法而了知它们的缘故，〔念等七种法〕便名为觉支 = 觉支。

**paṭibujjhantīti bojjhaṅgā** = 由于能藉由现证四谛圣法、另一种说法即现证尊贵的涅槃圣法的方式而朝向了知的缘故，念等诸法便名为觉支 = 觉支。

**sambujjhantīti bojjhaṅgā** = 由于能如实无误、不偏不倒地了知四谛圣法、另一种说法即尊贵的涅槃圣法的缘故，念等七种法便名为觉支 = 觉支。(Paṭisam-302。Abhi-A-1-262。)

觉支生起之因的诸法，请如同在**入出息念定(ānāpānassati samādhi)部分**中所清楚阐述的那样来记取。在那些觉支生起之因的诸法当中 ---- **tattha yonisomanasikāra bahulīkāro, ayamāhāro** ---- (Sam-3-60。) ----
正如佛陀(Buddha)如此等等地开示的那样，藉由获得道智、果智、涅槃等利益安乐之因而以正确的方法、正确的途径作意——如理作意(yonisomanasikāra)——正是那七种殊胜的觉支之法得以生起的最切近之因法。
对于真实确凿是无常(anicca)-苦(dukkha)-无我(anatta)-不净(asubha)的善(kusala)法、不善(akusala)法等的五蕴(khandhā)= 色名诸法，一再地作意其为无常、为苦、为无我、为不净 = 反复多次地进行如理作意，这既是尚未生起的七种殊胜觉支之法得以明显生起之因法，也是已经生起的七种殊胜觉支之法乃至抵达阿拉汉道(arahattamagga)、圆满具足之因法。
