### 宿世曾造福德(pubbe ca katapuññatā)之轮的力量

- 1。 居于适宜之处(patirūpadesavāsa)= 得以居住在能获得生善(kusala)机会、三宝(ratana)兴盛、诸圣善之人所在、适宜相称而美善的地方，
- 2。 亲近善士(sappurisūpanissaya)= 得以依止、亲近以佛陀(Buddha)为首的诸圣善之人，
- 3。 听闻正法(saddhammassavana)= 得以听闻善士之正法，
- 4。 宿世曾造福德(pubbe katapuññatā)= 成为具有往昔诸生中所培育积集的、名为波罗蜜(pāramī)、福(puñña)、资粮(sambhāra)之善业功德的构造与实质者 ----

如此等强而有力的所依止(upanissaya)因缘诸法，能令如理作意(yonisomanasikāra)得以生起——此点已于前文加以阐明。 
此处继续就宿世曾造福德之轮极为重要之处，略作阐述。

**宿世曾造福德之轮** - 所谓此者，即于过去种种生世中 ----

- 1。 正自菩提智(sammāsambodhi ñāṇa)，
- 2。 独觉菩提智(paccekabodhi ñāṇa)，
- 3。 上首弟子菩提智(aggasāvakabodhi ñāṇa)，
- 4。 大弟子菩提智(mahāsāvakabodhi ñāṇa)，
- 5。 普通弟子菩提智(pakatisāvakabodhi ñāṇa) ----

即是为了成就上述各种菩提智(bodhi ñāṇa)之所缘、名为寂止之界的涅槃(nibbāna)这一至尊广大之法，而着眼于此所培育起来的明(vijjā)之良种、行(caraṇa)之良种。

**三种明**

- 1。 宿住随念智(pubbenivāsānussati ñāṇa)= 能以智(ñāṇa)顺次追溯、忆念并了知往昔曾经历过的色(rūpa)、名(nāma)（=蕴(khandha)）之相续的神通智(abhiññā)，
- 2。 天眼智(dibbacakkhu ñāṇa)= 犹如天神之眼，能尽见远近一切所有的神通智，
- 3。 漏尽智(āsavakkhaya ñāṇa)= 了知、照见作为四种漏(āsava)之尽处的涅槃的阿拉汉道智(arahattamagga ñāṇa) ----

世尊在《怖畏惊骇经(Bhayabherava Sutta)》(中，1，26。)中，把这三种智称为三种明。

**八种明**

再者，在《盎拔闼经(Ambaṭṭha Sutta)》(长，1，94。)中——(世尊)开示了八种明。

- 1。 **种种神变智(iddhividha ñāṇa)** = 能变现遁入地下、飞行虚空等种种神通威力的神通智，
- 2。 **天耳通智(dibbasota ñāṇa)** = 犹如天神之耳，能听闻远近所有存在的、于人间发出的声音与于天界发出的声音的神通智，
- 3。 **他心辨知智(cetopariya ñāṇa)** = 能以自己的心(citta)了知他人之心的神通智，
- 4。 **宿住随念智** = 能以智顺次追溯、忆念并了知往昔曾经历过的色、名（=蕴）之相续的神通智，
- 5。 **天眼智** = 犹如天神之眼，能尽见远近一切所有的神通智，
- 6。 **漏尽智** = 了知、照见作为四种漏之尽处的涅槃的阿拉汉道智，
- 7。 **观智(vipassanā ñāṇa)** = 即于名为苦谛(dukkhasacca)、集谛(samudayasacca)的诸行(saṅkhāra)法之无常(anicca)相、苦(dukkha)相、无我(anatta)相中善加安住的、名为法住(dhammaṭṭhiti)的观智，
- 8。 意所成神变智(manomayiddhi ñāṇa)= 能变现众多以心成就的意所成(manomaya)蕴身的神通智-

这八者即是八种明。 
即是随顺聆听各该经的诸有情(satta)之意愿、意乐根性(ajjhāsaya)倾向，而如此分别开示的。

**十五种行法**

- 1。 **戒律仪(sīlasamvara)** = 守护、防护自身的品行戒(sīla)，
- 2。 **守护根门(indriyesu guttadvāratā)** = 于名为止(samatha)业处、观业处(kammaṭṭhāna)的任一业处所缘上，恒常安置自己的心（=恒常作意(manasikāra)业处法），从而防护眼、耳、鼻、舌、身、意这六种门(dvāra)＝六道大门，使贪(lobha)、嗔(dosa)、痴(moha)等烦恼(kilesa)垢秽不得侵入，
- 3。 **饮食知量(bhojane mattaññutā)** = 于饮食懂得节量适度，
- 4。 **警寤精勤(jāgariyānuyoga)** = 保持警醒觉寤 = 于警醒中具足奋发之精进(vīriya)（夜分三时中至多只睡一时），
- 5-11。 **七正法(satta saddhamma)** = 即信(saddhā)、惭(hirī)、愧(ottappa)、多闻(bāhusacca)、精进、念(sati)、慧(paññā)——所谓善士之七法，
- 12-15。 依四分法而立的初禅(paṭhamajhāna)、第二禅(dutiyajhāna)、第三禅(tatiyajhāna)、第四禅(catutthajhāna)这色界(rūpāvacara)四种禅那(jhāna)——将全部合计，便成为十五种行法。
