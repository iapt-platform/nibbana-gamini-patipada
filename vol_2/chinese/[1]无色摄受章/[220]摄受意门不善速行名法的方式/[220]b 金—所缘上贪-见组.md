### 金 — 所缘上贪(lobha)-见(diṭṭhi)组 全部 -20- (贪根心)

逐步建立起定(samādhi)之后 ---

- 1. 摄受有分(bhavaṅga)意清净界。
- 2. 取一件你所喜爱、属于自己的戒指、项链、耳环等金块金锭作为所缘。（应当是借助智慧光明之助而见到的物体）
- 3. 当那金所缘迎向有分意清净界、落入并显现于其中时，便以名为「金」的概念(paññatti)块为所缘，生起诸意门速行心路(manodvārikajavanavīthi)之心的相续。
- 4. 让那心路中所含的意门转向(manodvārāvajjana)去把这金判定为「净(subha)」，如此作意。由于是不如理作意(ayonisomanasikāra)，便会生起诸贪见不善速行组。

- 1. **认知心(citta)** = 摄取金所缘的状态。
- 2. **触(phassa)** = 以触及金所缘的方式而生起的状态。
- 3. **受(vedanā)** = （欢喜地）领受金所缘之滋味的状态。
- 4. **想(saññā)** = 把金所缘标记为「净」的状态。
- 5. **思(cetanā)** = 促使、激励诸相应法(sampayutta dhamma)到达金所缘的状态。
- 6. **一境性(ekaggatā)** = 心落于并安住在单一金所缘上的状态；使诸相应法不涣散、不散乱的状态。
- 7. **命(jīvita)** = 守护名法寿命之界 = 守护诸相应法的状态。
- 8. **作意(manasikāra)**= 把心转向、推送到金所缘一方的状态；把金所缘铭记于心的状态。
- 9. **寻(vitakka)** = 把心投向并安放于金所缘之上的状态。
- 10. **伺(vicāra)** = 反复审察、思量金所缘的状态；反复揣摩的状态、一再取金所缘的状态。
- 11. **胜解(adhimokkha)** = 把金所缘判定为「净」的状态。
- 12. **精进(vīriya)** = 在金所缘上为生起贪见等不善（为生起贪染(rāga)）而努力奋发的状态。
- 13. **喜(pīti)** = 喜爱金所缘的状态。
- 14. **欲(chanda)** = 渴望、企求金所缘的状态。（想要生起贪染的状态。）
- 15. **痴(moha)** = 不了知金所缘之「不净(asubha)」真实本性的状态；把金所缘误认作「净」的状态。
- 16. **无惭(ahirika)** = 对在金所缘上生起贪见等不善不感羞耻的状态。
- 17. **无愧(anottappa)**= 对在金所缘上生起贪见等不善不感畏惧的状态。
- 18. **掉举(uddhacca)** = 心在金所缘上不宁静、飘散不定的状态。
- 19. **贪** = 把金所缘执取为「我的」的状态；贪求、迷恋金所缘的状态，黏著的状态。
- 20. **见** = 坚执、深信金所缘为「净」的状态；把金所缘误认作「净」＝错误接受、错误观念的状态。
