### 掉举(uddhacca)组 名法的观照体系

**掉举** = 于眼明净界(cakkhupasāda)所缘上心不寂静、散乱漂浮的性质。

- 1. 请摄取有分(bhavaṅga)意明净界。
- 2. 请伸缘取那平时惯于生起掉举的眼明净界所缘。
- 3. 当那眼明净界所缘朝向落入、显现于有分意明净界之时，诸意门心路速行心(manodvārikavīthijavanacitta)的相续便会明显地生起。
- 4. 请让那心路心相续中所含的意门转向(manodvārāvajjana)把它作意为『一个足以令心不寂静的所缘』。

由于生起了不如理作意(ayonisomanasikāra)，以掉举为首的诸不善(akusala)速行心相续便会明显地生起。

#### 掉举组名法(16)个

那每一个速行中，各有名法(16)个。那些名法如下。

| | |
|:-|:-|
|1. 识知心(citta) = 取眼明净界所缘的性质 |- 1|
|2. 不含喜(pīti)-欲(chanda)的同他(aññasamāna) = 两方通用心所(cetasika) |- 11|
|3. 痴(moha)-无惭(ahirika)-无愧(anottappa)-掉举 = 通一切不善心所(akusalasādhāraṇacetasika) |- 4|
|全部合计，掉举组名法 --- |共成为16个。|

以眼明净界等究竟法(paramattha)所缘为所缘而生起的、以掉举为首的痴根心(mohamūlacitta)名法之聚，在摄取修观它们时，那所缘应当是最能引生掉举的所缘。 
应当是既不生贪(lobha)、也不生瞋(dosa)的眼明净界等那类所缘；这是因为与贪相应的掉举已分别含于贪组之中，与瞋相应的掉举已分别含于瞋组之中的缘故。 
在此，是要选取那类在眼明净界等所缘上心多散乱漂浮、而不生贪、不生瞋的所缘来观照。
意思是指由于眼睛里有某种情况而心不寂静的那种状态。 
在这一组中，痴就是误认为『我的眼明净』等的错误认知性质。
