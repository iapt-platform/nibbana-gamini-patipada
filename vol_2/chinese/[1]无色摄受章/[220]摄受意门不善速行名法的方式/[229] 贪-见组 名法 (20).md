### 贪(lobha)-见(diṭṭhi)组 名法 (20)

- 1. **心(citta)** = 执取眼净色(cakkhupasāda)所缘(ārammaṇa)的性质。
- 2. **触(phassa)** = 以触及眼净色所缘的方式而生起的性质。= 使眼净色所缘与能知之心相连结的性质。(作用(rasa))
- 3. **受(vedanā)** = 欢喜地感受眼净色所缘之滋味的性质。(此处即是悦受(somanassavedanā)。若是舍(upekkhā)则作中等的感受。)
- 4. **想(saññā)** = 把眼净色所缘标记为(净美(subha))的性质。
- 5. **思(cetanā)** = 朝向眼净色所缘、与之相应的心-心所(cetasika) = 促使相应(sampayutta)诸法(dhamma)之聚到达 = 催促、激励的性质。
- 6. **一境性(ekaggatā)** = 心安住于眼净色单一所缘之上的性质。= 使相应诸法在眼净色所缘上不散乱、不涣散的性质。
- 7. **命(jīvita)** = 守护在眼净色所缘上与之相应的心-心所、相应诸法的性质。(守护名(nāma)寿之界(dhātu))
- 8. **作意(manasikāra)** = 将心(= 相应诸法)转向并推送至眼净色所缘那一方的性质。= 作意眼净色所缘的性质。
- 9. **寻(vitakka)** = 把心(= 相应诸法)导向、安置于眼净色所缘之上的性质(= 寻思的性质。)
- 10. **伺(vicāra)** = 对眼净色所缘反复省察、反复琢磨的性质 = 反复取所缘的性质。
- 11. **胜解(adhimokkha)** = 对眼净色所缘作出(是净美)的决断的性质。
- 12. **精进(vīriya)** = 为使贪-见等诸不善(akusala)法在眼净色所缘上生起(= 为使贪染(rāga)生起)而努力策励的性质。
- 13. **喜(pīti)** = 对眼净色所缘喜悦的性质。
- 14. **欲(chanda)** = 对眼净色所缘欲求、渴望的性质，(= 想要生起贪染的性质。)
- 15. **痴(moha)** = 不了知眼净色所缘(不净(asubha))真实本质的性质。= 把眼净色所缘认知错误为(净美)的性质。
- 16. **无惭(ahirika)** = 对在眼净色所缘上生起贪-见等不善之事不感到羞耻的性质。
- 17. **无愧(anottappa)** = 对在眼净色所缘上生起贪-见等不善之事不感到畏惧的性质。
- 18. **掉举(uddhacca)** = 心在眼净色所缘上不平静、散乱飘荡的性质。
- 19. **贪(lobha)** = 把眼净色所缘执取为“我的”的性质。= 对眼净色所缘欲求贪恋的性质 = 黏着的性质。
- 20. **见(diṭṭhi)** = 执迷坚信眼净色所缘为净美的性质。= 把眼净色所缘错认为净美 = 见地错误的性质。

[**注** --- 对于把眼净色所缘执取为常(nicca)、乐(sukha)、我(atta)的情形，也请以同样的方式领会其义。
把（所缘）错认为常、乐、我的这种认知错误的性质，即是不了知无常(anicca)、苦(dukkha)、无我(anatta)真实本质的性质，正是痴。
把（所缘）错信为常、乐、我的这种信念错误、见地错误，正是见。
受方面，若生起悦则含喜。
若生起舍则不含喜。
若是有行(sasaṅkhārika)、有怂恿，则含昏沉(thīna)-睡眠(middha)；若是无行(asaṅkhārika)、无怂恿，则不含昏沉-睡眠。
请就以(4)项来观照。
若在观照眼净色所缘时不生起喜，则减去喜便成(19)种名法，此时与舍受(upekkhāvedanā)相应。
不与悦受相应。
若在眼净色所缘上，与贪、见的生起相关，心的势头不太强盛，则由于是有行，昏沉-睡眠便会相应。
与昏沉-睡眠相应的诸名法之聚分别为(22)与(21)。
请通过逐一分别观照、以及依心路过程(vīthi)次第整体地观照一切名法，反复多次地练习。]
