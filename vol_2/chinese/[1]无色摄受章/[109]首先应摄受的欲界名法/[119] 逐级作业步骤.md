### 逐级作业步骤

- 1. 重新把安般念定(ānāpānassati samādhi)修到第四禅那(jhāna)为止，再次确立定(samādhi)。
从该禅那出定后 ----
- 2. 重新摄受住立于(6)门(dvāra)、(42)身分(koṭṭhāsa)中的一切色法(rūpa)。
- 3. 摄受有分(bhavaṅga)意明净界，以智(ñāṇa)加以辨别。此后 ----
- 4. 伸取眼明净界(cakkhu)为所缘，加以摄受。

当那眼明净界显现于有分意明净界时，或者当那眼明净界朝向着落入有分意明净界时，便会生起了知（＝缘取）该眼明净界所缘的意门(manodvāra)速行(javana)心路(vīthi)诸心相续。
在那意门速行心路诸心相续中含摄住立的意门转向(manodvārāvajjana)，则 ----

- 1. 当审察判定为眼明净界时 ----<br> 了知、观照为眼明净界的诸心路心相续，会被有分相隔而接连不断地生起。同样地 ----
- 2. 当把那眼明净界审察判定为色法时，了知、观照为色法的意门速行心路诸心相续，
- 3. 当取那眼明净界生起后即坏灭的性质为所缘、审察判定并观照为无常(anicca)时，了知、观照为无常的意门速行心路诸心相续，
- 4. 当取那眼明净界因生灭的逼迫而恒常不断地遭受煎逼压迫的性质为所缘、审察判定并观照为苦(dukkha)时，了知、观照为苦的意门速行心路诸心相续，
- 5. 当取那眼明净界并非不坏灭地作为团块、坚固、以实质而住立的、并非我(atta)的性质为所缘、审察判定并观照为无我(anatta)时，了知、观照为无我的意门速行心路诸心相续，
- 6. 当取那眼明净界与恶臭气味等相混杂的、令人厌恶可憎的不净(asubha)性质为所缘、审察判定为不净时，了知、观照为不净的意门速行心路诸心相续，便各自生起。

以上这 ----

- 1. 判定为「眼明净界」，
- 2. 判定为「色法」，
- 3. 判定为「无常」，
- 4. 判定为「苦」，
- 5. 判定为「无我」，
- 6. 判定为「不净」 ----

这各自的审察判定，正是如理作意(yonisomanasikāra)。
即以正确方法、正确途径将其纳入心中（作意）。
那如理作意的法体，在此处，正是作为意门速行心路之基本根源、名为速行引发作意(javana paṭipādaka manasikāra)的意门转向名法(nāma)聚（＝心(citta)＋心所(cetasika)＝12）种。
由于意门转向的审察判定即是如理作意、作意正确之故，对于凡夫(puthujjana)、有学(sekkha)个体(puggala)而言，便只会有善(kusala)速行运行。

Yoniso bhikkhave manasi karoto anuppannā ceva kusalā dhammā uppajjanti, uppannā ca akusalā dhammā parihāyanti. (A.1.12.)

Yoniso bhikkhave manasi karoto anuppannā ceva bojjhaṅgā uppajjanti, uppannā ca bojjhaṅgā bhāvanāpāripūriṃ gacchanti. (A.1.13.)

＝ 诸比库……对于具足以正确方法、正确途径而善加作意之如理作意的人，尚未生起的善法也会生起，已生起的不善(akusala)法也会退失坏灭。(A.1.12.)

＝ 诸比库……对于具足如理作意的人，尚未生起的觉支(bojjhaṅga)诸法也会生起，已生起的觉支诸法也会达到修习(bhāvanā)的圆满。(A.1.13.)

依照上述的巴利圣典，若有如理作意，善速行便会运行。
若没有如理作意、而生起不如理作意(ayonisomanasikāra)，则善速行便无法运行，只会有不善速行运行。
因此，为使善速行运行，如理作意乃是最切近的一种因法。
你这位尊贵的瑜伽行者(yogāvacara)个体，若想摄受、修习善速行心路诸心相续，若想以智加以辨别，那么就必须努力使如理作意生起。
如此努力的话，尚未生起的根(indriya)、力(bala)、觉支、道支(maggaṅga)诸法便会明显地生起，已生起的根、力、觉支、道支诸法也会达到修习的圆满（＝达到阿拉汉道(arahatta magga)的修习圆满）。

这正是把你这位尊贵的瑜伽行者个体的心相续，一直提升到名为阿拉汉道、阿拉汉果(arahatta phala)这一最崇高阶次的**最无危险的提升心志之伟大作业**。

在那(6)种如理作意当中，你这位善行的瑜伽者(yogī)，请首先着手摄受第(1)号——了知为眼明净界的意门速行心路诸心相续。
无论是从了知心识(viññāṇa)开始，或从触(phassa)开始，或从受(vedanā)开始，都可以摄受。

假如从了知心识开始摄受，那么诸了知心便 ----

- 1. 意门转向(1)次、
- 2. 速行(7)次、
- 3. 彼所缘(tadārammaṇa)(2)次 ----

请首先练习，以智见到并能辨别：依照上述「心定律(citta niyāma)」轨道、一般而言这样生起的情形。
此处之所以说「一般而言」，是因为：有时，当你这位善行瑜伽者当下正在观照、作为所缘的眼明净界之类的所缘，在你瑜伽者的心相续中变得不明显、模糊朦胧时，彼所缘便无法落下，心路诸心相续甚至可能就在速行处便停止了。
当眼明净界显现于有分意明净界时，请练习：以有分意明净界为依托、依止心所依处色(hadaya vatthu)，如此了知那眼明净界的意门速行心路诸心相续，会在一个心路与另一个心路之间以有分相隔、接连多次地生起——务必以智见到，亲自现前地洞穿了知这一情形。
由于这是把依处(vatthu)与所缘一并摄受而修习的作业，故成功迟早总会获得。
一旦获得成功，请把诸心所一个一个、逐渐逐渐地增添 ----

- 1. 意门转向中名法(12)个、
- 2. 各个速行中各名法(34)个、
- 3. 各个彼所缘中各名法(34)个 ----

请观照，直到圆满为止，务必以智见到。
请练习见到那各个名法在每一个心刹那(citta khaṇa)之内一齐生起的情形。
对于其余的诸如理作意，也请以同样的方法观照。
如此观照时，请反复多次练习，以领会到：它并不像禅那速行那样多次生起，而是一般而言只有速行(7)次在运行。
如此观照时，在速行与彼所缘当中 ----

- 1. 有时，智与喜(pīti)二者皆含摄其中，与悦受(somanassa)相应，成为智相应(ñāṇasampayutta)善。
- 2. 有时，智相应而喜不相应，与舍受(upekkhā)相应，成为智相应善。
- 3. 有时，智不相应而只有喜相应，与悦受相应，成为智不相应(ñāṇavippayutta)善。
- 4. 有时，智与喜二者皆不相应，与舍受相应，成为智不相应善。

合计为(4)项。

- 1. 观照为眼明净界时，须依照智与喜的相应—不相应，轮转(4)项而观照。
- 2. 同样地，把眼明净界观照为色法时，
- 3. 观照为无常时，
- 4. 观照为苦时，
- 5. 观照为无我时，
- 6. 观照为不净时 ----

在这些当中，也请各自各观照(4)项。
全部合计，须观照(4 × 6 = 24)次。

So sabbepi te arūpadhamme **namanalakkhaṇena** ekato katvā "etaṃ **nāma**"nti passati. (Visuddhi-2-223.)

如此观照时，当能以智见到、能摄受、能观照——每一个心路心刹那中各个名法完全无余地一齐相应结合而生起的情形——之时；＝当能以智把依照心定律轨道生起的诸名法聚，各自破除其密集(ghana)、加以拆解坏灭，从而能摄受、能修习之时，便取那一切名法朝向眼明净界所缘倾附偏向的意涵为所缘 ----

“**这即是名法**”，或者

“**名法、名法**”这样观照。

**有行(sasaṅkhārika)**

为使缘取眼明净界的诸大善(mahā kusala)速行得以生起，须由自己亲自策励、或须由他人策励——这种性质称为有行。

**无行(asaṅkhārika)**

为使缘取眼明净界的诸大善速行得以生起，若无须自己策励自己、也无须他人策励，诸大善速行便自行生起，那么这些善速行便是无行。

由于有行与无行的差别并不会导致心、心所的数目有所差别，故本文中仅列示(4)项。
有行中有(4)项、无行中有(4)项，两者合计，便是大善心(8)种。
（对于仅在诸阿拉汉(arahant)尊者相续中生起的诸大唯作(mahā kiriya)心，也请以同样的方法记取。）
