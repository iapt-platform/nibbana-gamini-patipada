### 名法（34）个

- 1、**识知心（citta）** = 摄取眼明净界所缘（ārammaṇa）的性质，
- 2、**触（phassa）** = 以触及眼明净界所缘的方式而生起的性质，= 使眼明净界所缘与识知心相连结的性质，
- 3、**受（vedanā）** = 感受眼明净界所缘之味的性质，（悦受（somanassavedanā），）
（在后面的诸心所（cetasika）中，若说到**所缘**，请记作**眼明净界所缘**。）
- 4、**想（saññā）** = 把所缘（记作眼明净界）标记铭记下来的性质，
- 5、**思（cetanā）** = 促使相应诸法（sampayutta dhamma）抵达所缘之上的性质，= 催促激励的性质，
- 6、**一境性（ekaggatā）** = 令心专注安住于单一所缘之上的性质，= 安定不动的性质，= 令相应诸法不致散乱涣散的性质，
- 7、**命（jīvita）** = 于所缘中守护相应诸法的性质，（名命守护界，）
- 8、**作意（manasikāra）** = 令相应诸法转向并推送至所缘之上的性质，= 驱策的性质，= 将所缘纳入于心的性质，
- 9、**寻（vitakka）** = 将心（以及相应诸法）投置于所缘之上的性质，
- 10、**伺（vicāra）** = 反复地审察思量所缘 = 反复揉摩的性质，= 一再地取所缘的性质，
- 11、**胜解（adhimokkha）** = 对所缘作出（是眼明净界的）决断判定的性质，
- 12、**精进（vīriya）** = 为了知所缘而努力策励的性质，

[（精进）其实就是努力促使一切相应诸法生起（的性质），但由于「想要了知」的性质居于主导，故如此撰写。]

- 13、**喜（pīti）** = 喜爱所缘的性质，
- 14、**欲（chanda）** = 想要了知所缘的性质，
- 15、**信（saddhā）** = 对通达了知所缘的慧学（paññāsikkhā）= 慧之修行怀有信心的性质，

[戒学（sīlasikkhā）= 戒之修行，定学（samādhisikkhā）= 定之修行，慧学 = 慧之修行，如是三种学（sikkhā）是存在的。 
也称为教梵行（sāsanabrahmacariya）。 
在那三种学中，慧学也包含在内。 
通达照见眼明净界之究竟法（paramattha）所缘的性质，正是慧根（paññindriya）心所，归属于慧学之中。 
因此，对通达了知眼明净界所缘的慧学 = 慧之修行所怀的信心，也就是信。 
换一种说法，眼明净界含摄在缘生法（paṭiccasamuppanna）之聚、缘起法（paṭiccasamuppāda）之聚当中的六入处（saḷāyatana）名单之内。 
对因果关联的缘起法诸性质所怀的信心，也就是信。]

- 16、**念（sati）** = 于所缘中，令相应诸法不似葫芦瓢般浮起、而如石板般沉没的性质，= 令心于所缘中坚固牢定的性质，= 对所缘不忘失的性质，
- 17、**自重（hiri）** = 对「恶事不善法（akusala）＋ 恶行（duccarita）诸法」感到羞耻的性质，
- 18、**愧（ottappa）** = 对「恶事不善法＋恶行诸法」感到怖畏的性质，

[正因为对不善法＋恶行诸法懂得羞耻、懂得怖畏，才会像现在这样从事与善（kusala）相关的修习（bhāvanā）事业。 
因此，这自重、愧二法，无论是在如此通达照见眼明净界之究竟法性质、观修审察之时，也无论是在通达照见以那眼明净界为所缘而生起的诸名（nāma）究竟法、观修审察之时，都仅仅是朝前安住的性质而已。 
在从事这修习事业时，无论是在尚未振作精神、正在振作精神、还是已振作精神之时，于你这位瑜伽行者（yogāvacara）贤善个体（puggala）的相续（santāna）中，都仅仅是朝前安住的性质而已。 
在通达了知眼明净界之时，以及在通达照见那些通达了知眼明净界的诸名法之时，并不是处于「好羞耻啊、好怖畏啊」这般的状态。]

- 19、**无贪（alobha）** = 于所缘中，心不黏着、不贪恋的性质，= 不执取所缘为「我的」的性质， 
- 20、**无瞋（adosa）** = 于所缘中，心不刚硬、不粗暴的性质，= 不想毁坏所缘的性质，
- 21、**中舍性（tatramajjhattatā）** = 于所缘中，令心保持中道平衡的性质，= 对所缘作舍观（漠然旁观）的性质，
- 22、**身轻安（kāyapassaddhi）** = 于所缘中，诸心所平静安宁的性质，
- 23、**心轻安（cittapassaddhi）** = 于所缘中，心平静安宁的性质，
- 24、**身轻快性（kāyalahutā）** = 于所缘中，诸心所轻快敏捷的性质，
- 25、**心轻快性（cittalahutā）** = 于所缘中，心轻快敏捷的性质，
- 26、**身柔软性（kāyamudutā）** = 于所缘中，诸心所柔软的性质，
- 27、**心柔软性（cittamudutā）** = 于所缘中，心柔软的性质，
- 28、**身适业性（kāyakammaññatā）** = 于所缘中，诸心所适于运作的性质，= 便于观照所缘、匀称合宜的性质，
- 29、**心适业性（cittakammaññatā）** = 于所缘中，心适于运作的性质，= 便于观照所缘、匀称合宜的性质，

[这是在观照眼明净界之时、以及在观照那些以眼明净界为所缘的诸名法之时。
能够轻而易举地观照眼明净界，正是这些适业性（kammaññatā）心所的效能。 
在摄受、观修眼明净界的修习中，正是那适于运作的性质。 
对于再度摄受那些以眼明净界为所缘而生起的诸名法，也请照此同样的方式记取。 
对于其余的诸究竟法，也请照此同样的方式理解。]

- 30、**身练达性（kāyapāguññatā）** = 于所缘中，诸心所娴熟练达的性质，= 熟练善巧的性质，= 无烦恼（kilesa）之疾患的性质，
- 31、**心练达性（cittapāguññatā）** = 于所缘中，心娴熟练达的性质，= 熟练善巧的性质，= 无烦恼之疾患的性质，
- 32、**身正直性（kāyujukatā）** = 于所缘中，诸心所正直的性质，= 远离诳（māyā）、谄（sāṭheyya）等歪曲的性质，
- 33、**心正直性（cittujukatā）** = 于所缘中，心正直的性质，= 远离诳、谄等歪曲的性质，
- 34、**慧（paññā）** = 通达照见眼明净界所缘的性质，

[在名为四谛正见（catusacca sammādiṭṭhi）的四种正见（sammādiṭṭhi）当中，依「dukkhe ñāṇaṃ」，通达了知苦谛（dukkhasacca）的正见也包含在内、为其一。 
依**saṃkhittena pañcupādānakkhandhā dukkhā**这一法之轮（dhammacakka）开示，执取蕴（upādānakkhandhā）（5）种便获得了「苦谛」这一名称。 
在那执取蕴（5）种当中，色蕴（rūpakkhandhā）也包含在内。 
在那色蕴当中，眼明净界也包含在内。
因此，通达了知眼明净界的慧根心所，也正是通达了知苦谛某一部分的正见智（ñāṇa）。]
