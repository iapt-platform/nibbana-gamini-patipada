### 初禅那名法（34）个

- 1. **识知之心（citta）** = 摄取入出息似相（ānāpānapaṭibhāganimitta）所缘的性质；<br>[依「vijānanaṃ ārammaṇassa upaladdhi（Mūlaṭī-1-87）」这句根本复注（Mūlaṭī）：所谓识知所缘，是指探取该所缘、执取所缘而得到它的性质。倘若无法执取所缘，便不能说识知了该所缘。]
- 2. 触（phassa） = 以触及入出息似相所缘的方式而生起的性质，（特相）= 使入出息似相所缘与识知之心相连结的性质，（作用）
- 3. **受（vedanā）** = 领受入出息似相所缘之滋味的性质（初禅那中为悦受〔somanassavedanā〕，）<br> [**注记** --- 请记住：在后面诸心所中说到「所缘」时，特别是指入出息似相这一所缘。]
- 4. **想（saññā）** = 记认所缘的性质，
- 5. **思（cetanā）** = 使相伴的心、心所 = 相应诸法（sampayutta）到达所缘之上而催促 = 激励它们的性质，
- 6. **一境性（ekaggatā）** = 心专注落于唯一所缘之上的性质，= 稳定安住的性质，= 使相应诸法不散乱、不涣散的性质，
- 7. **命（jīvita）** = 守护相应诸法的性质（= 守护名法寿命之界），
- 8. **作意（manasikāra）** = 使心（= 相应诸法）转向所缘一方而推送的性质，= 驱策的性质，= 将所缘作意于心的性质，
- 9. **寻（vitakka）** = 将心（= 相应诸法）朝向而安置于所缘之上的性质，= 思构的性质，
- 10. **伺（vicāra）** = 对所缘反复审察思量、揉捏玩味的性质，= 一再地执取所缘的性质，
- 11. **胜解（adhimokkha）** = 对所缘作出决断的性质，
- 12. **精进（vīriya）** = 为识知所缘（= 为使相应诸法生起）而努力策励的性质。 <br>[**注记** --- 由于这属于定学（samādhisikkhā）部分，故在建立定时、入禅那等至（jhānasamāpatti）时，特别是使修习之心平静地贴附、安住于入出息似相所缘之上而努力的性质。精进使相应诸法在所缘上稳固、持久而给予助力扶持——即执行策励（paggaha）的工作职责。]
- 13. **喜（pīti）** = 喜悦所缘的性质，
- 14. **欲（chanda）** = 想要识知所缘的性质，= 想要心于所缘中安定澄净 = 想要生起定 = 想要使相应诸法生起的性质，
- 15. **信（saddhā）** = 信受禅那定学（= 禅那之定的修行次第）的性质。 <br>[在信生起的（8）处当中，三学也一并含摄于其中。  信受禅那定学（= 禅那之定的修行次第），这也正是信。]
- 16. **念（sati）** = 于所缘中不使相应诸法像葫芦那样浮起，而使之像石板那样沉入的性质，= 对所缘不遗忘的性质，= 于所缘中心稳固牢靠的性质，
- 17. **自重（hiri）** = 对恶事、不善法、恶行感到羞耻的性质，
- 18. **愧（ottappa）** = 对恶事、不善法、恶行感到畏惧的性质， 

[这自重—愧二法，在禅那定之时，仅是朝前安住、维持住立的性质而已。 
特别是因为在本篇中正当以入出息似相为唯一所缘之时，也并非与不善、恶行正面迎击对峙之际的缘故。 
正是因为有了羞耻与畏惧，才得以圆满修习三学的殊胜之行。 
这羞耻与畏惧，正是在尚未入禅那前、入禅那后、正入禅那之时，于你这位瑜伽行者（yogāvacara）尊者的名相续之流中朝前安住着的。]

- 19. **无贪（alobha）** = 心于所缘中不黏著、不贪恋的性质，= 不执取所缘为「我的」的性质，
- 20. **无瞋（adosa）** = 心于所缘中不粗硬、不粗暴的性质，= 不想破坏所缘的性质，
- 21. **中舍性（tatramajjhattatā）** = 使心于所缘中保持中庸的性质，= 对所缘等舍的性质，
- 22. **身轻安（kāyapassaddhi）** = 诸心所于所缘中宁静清凉的性质，
- 23. **心轻安（cittapassaddhi）** = 心于所缘中宁静清凉的性质，
- 24. **身轻快性（kāyalahutā）** = 诸心所于所缘中迅捷轻盈的性质，
- 25. **心轻快性（cittalahutā）** = 心于所缘中迅捷轻盈的性质，
- 26. **身柔软性（kāyamudutā）** = 诸心所于所缘中柔软的性质，
- 27. **心柔软性（cittamudutā）** = 心于所缘中柔软的性质，
- 28. **身适业性（kāyakammaññatā）** = 诸心所于所缘中堪任的性质，= 观照所缘时匀称适宜的性质，
- 29. **心适业性（cittakammaññatā）** = 心于所缘中堪任的性质，= 观照所缘时匀称适宜的性质，
- 30. **身练达性（kāyapāguññatā）** = 诸心所于所缘中娴熟练习、精练的性质，= 熟练善巧的性质，= 无烦恼（kilesa）之病的性质，
- 31. **心练达性（cittapāguññatā）** = 心于所缘中娴熟练习、精练的性质，= 熟练善巧的性质，= 无烦恼之病的性质，
- 32. **身正直性（kāyujukatā）** = 诸心所于所缘中正直的性质，= 远离诳（māyā）、背叛（sāṭheyya）与迂曲弯绕的性质，
- 33. 心正直性（cittujukatā） = 心于所缘中正直的性质，= 远离诳、背叛与迂曲弯绕的性质，
- 34. **慧（paññā）** = 洞彻透视入出息似相所缘的性质，（这正是禅那正见〔jhānasammādiṭṭhi〕。）

这些便是以入出息似相所缘为所缘而生起的初禅那名法（34）个。 
在这（34）个当中，当能够在每一个速行心（javana）刹那中以智（ñāṇa）逐五个逐五个地分辨、摄受禅支时，其余的心＋心所诸法便应逐步逐步地增加、继续摄受。
