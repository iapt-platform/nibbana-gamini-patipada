### 义注(Aṭṭhakathā)的阐释

为了能准确无误地了知、理解上面这段巴利圣典，义注的注释师大长老如下面
那样作了阐释开示。

tattha **sarāga**nti aṭṭhavidhaṃ lobhasahagataṃ.
**vītarāga**nti lokiyakusalābyākataṃ.
idaṃ pana yasmā sammasanaṃ na dhammasamodhānaṃ, tasmā idha ekapadepi lokuttaraṃ na labbhati.
sesāni cattāri akusalacittāni neva purimapadaṃ, na pacchimapadaṃ bhajanti.
**sadosa**nti **dvividhaṃ** dosasahagataṃ.
**vītadosa**nti lokiyakusalābyākataṃ.
sesā dasākusalacittāni neva purimaṃ padaṃ, na pacchimaṃ padaṃ bhajanti.
**samoha**nti vicikicchāsahagatañceva uddhaccasahagatañcāti dvividhaṃ.
yasmā pana moho sabbākusalesu uppajjati, tasmā tānipi idha vaṭṭantiyeva.
imasmiṃ yeva hi duke dvādasākusalacittāni pariyādiṇṇānīti.
**vītamoha**nti lokiyakusalābyākataṃ.
**saṃkhitta**nti thinamiddhānupatitaṃ, etañhi saṃkuṭitacittaṃ nāma.
**vikkhitta**nti uddhaccasahagataṃ, etañhi pasaṭacittaṃ nāma.

**mahaggata**nti rūpārūpāvacaraṃ.
**amahaggata**nti kāmāvacaraṃ.
**sauttara**nti kāmāvacaraṃ.
**anuttara** nti rūpāvacarañca arūpāvacarañca.
tatrāpi sauttaraṃ rūpāvacaraṃ, anuttaraṃ arūpāvacarameva.
samāhitanti yassa appanāsamādhi upacārasamādhi vā atthi.
**asamāhita**nti ubhayasamādhivirahitaṃ.
**vimutta**nti tadaṅgavikkhambhanavimuttīhi vimuttaṃ.
**avimutta**nti ubhayavimuttivirahitaṃ.
samucchedapaṭippassaddhinissaraṇavimuttīnaṃ pana idha okāsova natthi. (M-A-1-284.)

- **1. 有贪心(sarāga citta) = 与贪(rāga)俱在之心** ---- 与贪(lobha)一同生起、在所缘上惯于贪着爱染的贪根心(lobhamūla citta)(8)种，称为有贪心。

- **2. 离贪心(vītarāga citta) = 离贪之心** ---- 世间善心(lokiya kusala citta)与无记心(abyākata citta)，称为离贪的离贪心。
就这「离贪心」而言，佛陀(Buddha)乃是以三种特相(lakkhaṇā)来提起、唯就应当以观(vipassanā)来修习观照的心而有意宣说的。并不是把凡称为离贪的离贪心的一切法都合计罗列出来。正因为佛陀只是指涉那些作为观智(vipassanā ñāṇa)所观照对象的诸心，所以在已述及、正述及的(16)种心当中，无论哪一种心里都取不到出世间心(lokuttara citta)，都不含摄出世间心。

**世间善心** ---- 若你这位仍只停留在三因(tihetuka)凡夫(puthujjana)一介凡人阶段的善男子，也曾获得(8)种等至(samāpatti)——那么在你的相续(santāna)中可能生起的诸世间善心便是 ----

- 1. 大善心 ---- 8 - 种
- 2. 色界善心(rūpāvacara kusala citta) ---- 5 - 种
- 3. 无色界善心(arūpāvacara kusala citta) ---- 4 - 种
- 全部合计 ---- 17 - 种

便只有这(17)种心生起。
假如你这位善男子只是获得了入出息(ānāpāna)第四禅那(jhāna)那样的程度，那么依四分法只能获得色界禅那(4)种，依五分法只能获得色界禅那(5)种。
因此，在你的相续中只有诸大善心与诸色界善心能够有机会生起。

**无记** ---- 既非善、也非不善(akusala)的世间果报(vipāka)、唯作(kiriyā)诸心，称为无记。
其中，在身为三因凡夫的你这位善男子的相续中能够获得、可能生起的诸无记心便是 ----

- 1. 称为五门转向(pañcadvārāvajjana)、意门转向(manodvārāvajjana)的无因(ahetuka)唯作心 ---- 2 - 种
- 2. 无因不善果报心 ---- 7 - 种
- 3. 无因善果报心 ---- 8 - 种
- 4. 大果报心(mahāvipāka citta) ---- 8 - 种
- 全部合计 ---- 25 - 种，即这些心。

在五门心路(pañcadvāravīthi)中 ---- 五门转向、眼识(cakkhuviññāṇa)（耳识、鼻识、舌识、身识）、领受(sampaṭicchana)、推度(santīraṇa)、彼所缘(tadārammaṇa)诸心生起。

在意门心路(manodvāravīthi)中 ---- 意门转向与彼所缘诸心生起。

其余剩下的 ----

- 1. 色界果报心 ---- 5 - 种
- 2. 无色界果报心 ---- 4 - 种
- 3. 生笑(hasituppāda)无因唯作心 ---- 1 - 种
- 4. 大唯作心(mahākiriyā citta) ---- 8 - 种
- 5. 色界唯作心 ---- 5 - 种
- 6. 无色界唯作心 ---- 4 - 种
- 全部合计 ---- 27 - 种

这(27)种果报、唯作心，则是在仍只身为三因凡夫的你这位善男子的相续中还不能有机会生起的诸心。

再者，瞋根心(dosamūla citta)两种、痴根心(mohamūla citta)两种，这四种心在有贪心、离贪心这两个词句中都不含摄。
然而，在你这位善男子本人应当修观的观智所观照的所缘清单之中，那四种心却仍然是含摄在内的。
因为佛陀接着以有瞋心、有痴心等等继续作了宣说。

- **3. 有瞋心(sadosa citta) = 与瞋(dosa)俱在之心** ---- 即与瞋一同生起的瞋根心两种。

- **4. 离瞋心(vītadosa citta) = 无瞋之心** ---- 世间善心与世间无记心，称为无瞋的离瞋心。（世间善心与世间无记心，请依上面所写的那样记住。）贪根心(8)种与痴根心(2)种——这(10)种不善心，在有瞋心、离瞋心这两种当中都不含摄。

- **5. 有痴心(samoha citta) = 与痴(moha)俱在之心** ---- 痴根心(2)种，称为与痴俱在的有痴心。
另一种说法——由于痴在一切不善心中都生起，所以全部(12)种不善心都称为有痴心。

- **6. 离痴心(vītamoha citta) = 无痴之心** ---- 世间善心与世间无记心，称为离痴心。（只需依上面所解说的那样记住。）

- **7. 收缩心(saṅkhitta citta) = 萎缩之心** ---- 心的呆滞＝心力不足(thina)，诸心所(cetasika)的呆滞＝睡眠(middha)——即随顺这两种法、从所缘退缩畏怯的那类心。

- 1. 贪根有行心(sasaṅkhārika citta) ---- 4 - 种
- 2. 瞋根有行心 ---- 1 - 种
- 全部合计 ---- 5 - 种

这(5)种心，即所谓的收缩心＝萎缩之心＝从所缘退缩之心。

- **8. 散乱心(vikkhitta citta) = 散逸之心** ---- 与掉举(uddhacca)一同生起的痴根心，因为在种种所缘上如同石块落在灰堆上那样散逸飘荡，所以称为散乱心。

- **9. 广大心(mahaggata citta) = 广大心** ----

  - (a) 因为具有能以抽离舍断(vikkhambhana pahāna)将诸烦恼(kilesa)抽离较长时间的力量，
  - (b) 因为具有广大宏伟的果报（利益），
  - (c) 因为在能够入定于那些广大禅那的善人们的相续中，那些广大禅那具有能以一小时、两小时，一天、两天等等长时间的名相续(nāma santati)之流而连续不断地生起的力量，
  - (d) 因为已达到宏伟崇高的状态，
  - (e) 换一种说法——因为是唯有借助宏伟崇高、广大的善欲(kusala chanda)界等力量才能获得、才能达到的修行，所以色界心、无色界心都称为广大心。(M-ṭī-1-372)

在仍只身为三因凡夫的你这位善男子的相续中，则只有称为色界善、无色界善的广大心(9)种（若已获得(8)种等至的话）才可能生起。

- **10. 非广大心(amahaggata citta) = 非广大的心 ----**

由于只是指涉那些作为观智所观照对象的诸心而宣说，所以所谓非广大的心，唯指欲界心(kāmāvacara citta)。
在那些欲界心中，生笑唯作心一种与大唯作心(8)种，由于是在诸阿拉汉(arahant)大德的相续中生起，所以在你这位瑜伽行者(yogāvacara)个体(puggala)的相续中 ----

- 1. 不善心 ---- 12 - 种
- 2. 无因心 ---- 17 - 种
- 3. 大善心 ---- 8 - 种
- 4. 大果报心 ---- 8 - 种
- 全部合计 ---- 45 - 种

便只有这(45)种欲界心才可能生起。

- **11. 有上心(sauttara citta) = 有比自己更胜妙之法的心 ----**

在作为观智所观照对象的诸世间心当中，称为广大的色界、无色界心，比欲界心更为超胜崇高。因此，把欲界心称为有上心＝有比自己更胜妙之法的心。

- **12. 无上心(anuttara citta) = 没有比自己更胜妙之法的心 ----**

在作为观智所观照对象的诸心当中，称为广大的色界心、无色界心，是最超胜、最崇高的诸心。
并不存在比那些广大心更为超胜崇高、而又作为观智所观照对象的世间心。因此，广大心便称为无上心。
而在那些广大心当中，无色界心又比色界心更为超胜崇高，因此色界心得到有上心之名，无色界心则又得到无上心之名。

- **13. 等持心(samāhita citta)** ---- 与所谓安止(appanā)禅那定或近行定(upacāra samādhi)之类某一种定(samādhi)一同生起的稳固之心＝有定之心，即近行定速行(javana)、安止定速行诸心。

- **14. 不等持心(asamāhita citta)** ---- 脱离所谓安止禅那定、近行定这两种定的不稳固之心＝无定之心，即脱离近行定、安止定的诸欲界心。

- **15. 解放心(vimutta citta)** = 从诸烦恼中解脱之心 ---- 欲界善心由于以彼分(tadaṅga)从诸烦恼中解脱，所以称为解放心。广大善心(9)种（＝色界善心(5)种、无色界善心(4)种）也同样，若入禅那一小时便整整一小时、入禅那两小时便整整两小时——如此等等能以抽离舍断将诸烦恼抽离较长时间，所以也是从诸烦恼中解脱的解放心。(M-ṭī-1-372)

- 16. 未解放心(avimutta citta) = 无论以彼分、还是以抽离(vikkhambhana)都未从诸烦恼中解脱的心 ---- 若单就你这位善男子而言 ----

- 1. 五门转向、意门转向，
- 2. 五识(pañcaviññāṇa)，
- 3. 领受，
- 4. 推度，
- 5. 确定(voṭṭhabbana)，
- 6. 不善速行，
- 7. 彼所缘诸心，即是这些。(M-ṭī-1-372)

这一部分，由于佛陀只是指涉那些作为观智所观照对象的诸心而宣说，所以 ----

- 1. 由于把诸烦恼无余地、连根拔断地断除，从而从诸烦恼中连根解脱出来的圣道心(ariyamagga citta)，即彻断解脱(samucchedavimutti)；
- 2. 将圣道法所已断除的诸烦恼之热恼火焰彻底止息、使之寂灭，从而从诸烦恼中解脱的果心(phala citta)，即止息解脱(paṭippassaddhivimutti)；
- 3. 作为从渴爱(taṇhā)中解脱之处（从诸烦恼中解脱之处）的涅槃(nibbāna)，即出离解脱(nissaraṇavimutti)——请记住：这里并非这三种解脱(vimutti)法的处所。(M-ṭī-1-372)

这正是《大念处经(Mahāsatipaṭṭhāna Sutta)》心随观(cittānupassanā)部分中，指示应当以观观照哪些心、或者说心＋心所＝名法的、指明观智所观照对象诸心的、佛陀所宣说的开示(desanā)。

在这篇开示中，佛陀也指示了应当以观来修习观照有贪心、有瞋心、有痴心这些不善心。
这一点，渴望希求涅槃的你这位善男子不应遗忘。

顶戴奉持这些指示，在本书中 ----

- 1. 含有善速行的五门心路、意门心路，
- 2. 含有不善速行的五门心路、意门心路 ----

若换一种说法，这各种各样的心路，是把安住于那些心路之内、于每一个心识刹那(cittakkhaṇa)每一个心识刹那中一同并列生起的名法之聚，即所谓名团、名块的种种名密集(nāmaghana)，以智(ñāṇa)加以破析摧破，从而使智见抵达究竟法(paramattha)——本书阐明了如此收摄修习观照的种种方法体系。

在这里，关于收摄修习观照不善速行心路的名法之聚这件事，某些善男子却又心里不能安、不能满意。
他们又发问道：“如果一直观照那些不善法，难道那些不善法不会重复地再生起吗？”

甚至当有人解说“佛陀本人在《大念处经》中也指示了应当以观修习观照诸不善心”之时，他们又辩解道 ---- “在《大念处经》中，佛陀关于应当以观修习观照诸不善法的指示，是仅在诸不善法自行自动地生起之时才指示观照的。
并不是指示专门去追着观照诸不善法” ---- 他们如此辩解。

在这里，为了渴求纯正之法、真实之法的你这位善净者，容我略作一些澄清与陈述。

在佛陀阿毗达摩(Abhidhamma)中，换一种说法，在究竟谛(paramattha sacca)的道理上，所谓“自行自动地”生起的法，根本是不可能存在的。
请阅读下面这篇开示。

ayoniso bhikkhave manasikaroto anuppannā ceva kāmacchando uppajjati, uppanno ca kāmacchando bhiyyobhāvāya vepullāya saṃvattati.
anuppanno ceva byāpādo uppajjati, uppanno ca byāpādo bhiyyobhāvāya vepullāya saṃvattati.
anuppannañceva thinamiddhaṃ uppajjati, uppannañca thinamiddhaṃ bhiyyobhāvāya vepullāya saṃvattati.
anuppannañceva uddhaccakukkuccaṃ uppajjati, uppannañca uddhaccakukkuccaṃ bhiyyobhāvāya vepullāya saṃvattati.
anuppannā ceva vicikicchā uppajjati, uppannā ca vicikicchā bhiyyobhāvāya vepullāya saṃvattatīti.
(Saṃ-3-83 - Ayonisomanasikārasutta.)

= 诸比库(bhikkhu) ……对于以不适当的方式惯于作意所缘、具有不如理作意(ayonisomanasikāra)的人 ----

- 1. 尚未生起的、对欲乐的欲求＝感官之欲(kāmacchanda)也生起了；已经生起的、对欲乐的欲求＝感官之欲，也会趋于超乎寻常地增盛、趋于广大。
- 2. 尚未生起的、欲求毁坏的心＝恶意(byāpāda)也生起了；已经生起的、欲求毁坏的心＝恶意，也会趋于超乎寻常地增盛、趋于广大。
- 3. 尚未生起的、心与心所的沉重呆滞＝昏沉睡眠(thinamiddha)也生起了；已经生起的、心与心所的沉重呆滞＝昏沉睡眠，也会趋于超乎寻常地增盛、趋于广大。
- 4. 尚未生起的、心的散逸与事后的追悔懊恼＝掉举追悔(uddhaccakukkucca)也生起了；已经生起的、心的散逸与事后的追悔懊恼＝掉举追悔，也会趋于超乎寻常地增盛、趋于广大。
- 5. 尚未生起的、无法辨别的犹疑猜疑＝疑(vicikicchā)也生起了；已经生起的、无法辨别的犹疑猜疑＝疑，也会趋于超乎寻常地增盛、趋于广大。(Saṃ-3-83)

依据这篇开示，**不如理作意**乃是一切不善法最切近的一个根本原因。
与一切名法相关的 ----

- 1. 有作为所依的依处色(vatthurūpa)，
- 2. 有可攀缘的所缘清楚显现 ----
- 3. 触(phassa)等诸相应(sampayutta)法给予助益等等——这些原因法也确实是存在的。[将在缘起(paṭiccasamuppāda)部分中清楚说明。在本名业处(kammaṭṭhāna)部分的(288-289-295)等处，以及(305)等处，也请翻阅参看。]

因此，在究竟谛的道理上，所谓“自行自动地生起的究竟法”根本是不可能存在的。
