## nidānakathā
## 世尊深深审察法之深奥

世尊自成佛之日——嘎宋(Kason)月满月的星期三——起，历经七七 = 七天七次 = (49)日，到达第(50)日、即瓦梭(Waso)月月初(6)日星期四的清晨，从坐落于「林轮」树(Buchanania latifolia)下的安居坐处起身之后，又前往那名为「阿阇波罗尼拘律陀(ajapālanigrodha)」的牧羊人榕树下，走近该阿阇波罗榕树下，结跏趺坐，安住修行。
那时，在已趣近耳目寂静之处、独自一人静居安住的世尊的心相续(santāna)中，生起了如此的心念——

“adhigato kho myāyaṃ dhammo gambhīro duddaso duranubodho santo paṇīto atakkāvacaro nipuṇo paṇḍitavedanīyo, ālayarāmā kho panāyaṃ pajā ālayaratā ālayasammuditā, ālayarāmāya kho pana pajāya ālayaratāya ālayasammuditāya duddasaṃ idaṃ ṭhānaṃ yadidaṃ idappaccayatā paṭiccasamuppādo, idampi kho ṭhānaṃ duddasaṃ yadidaṃ sabbasaṅkhārasamatho sabbūpadhipaṭinissaggo taṇhākkhayo virāgo nirodho nibbānaṃ. ahañceva kho pana dhammaṃ deseyyaṃ, pare ca me na ājāneyyuṃ, so mamassa kilamatho, sā mamassa vihesā”ti. (Vi-3-5. Dī-2-31.)

“以正等正觉(sammāsambodhi)的殊胜智，我佛亲自透彻通达、明明白白地了知见到的这四谛(sacca)法聚，如同承载着厚重大地的深广水层一般极其深奥；如同被大须弥山(Sineru)覆盖着的芥子一般极难看见；单凭轻易之力实在无法看见；犹如以分割了一百次的一根毛尾之尖，去正对准另一根毛尾之尖来刺、来触一般，极难了知；单凭轻易之力实在无法透彻了知。

我所透彻了知见到的这出世间(lokuttara)法，实在寂静安稳，实在殊胜微妙。
这四谛法，并非仅凭空想的思辨学者、逻辑推理者(takkī)们的寻思(vitakka)所能契入、涵泳的法；唯有以正见(sammādiṭṭhi)智慧才能契入、涵泳；实在微细幽微；它是唯有那些修习了名为**正行道(sammāpaṭipadā) = 趣向涅槃之行道(nibbānagāminipaṭipadā)**的八(8)支圣道(magga)之正行的具慧善士们才能了知见到的法。

这一切众生(satta)，沉迷于两种执著(ālaya)——即于(5)种所缘之欲德(kāmaguṇa)法的执著、名为欲执(kāmālaya)，以及惯于依恃享用那(5)种所缘之欲德法的爱执(taṇhālaya)——他们以那欲执、爱执二者而耽乐着；他们于那两种执著中欢喜、爱好而住；他们大执深执、极为耽著而住。
如此以两种执著而耽乐、欢喜、爱著而住的一切众生，对于这因与果相互关联、层层不断生起的**缘起(paṭiccasamuppāda)法**，实在极难了知见到。

由善巧娴熟的园丁精心栽培、悉心料理，花果盛开繁茂，林木花树等一应俱全的御苑之中，踏步进入的贤明国王，当他看见那开满各色花果、遍布花树林木、圆满具足的御苑时，因观赏那种种圆满、因领受那种种圆满的成就(sampatti)，便在御苑中大为欢娱而娱、大为喜乐而乐、大为爱著而著、大为欣悦而悦。
毫无厌倦。

正如这譬喻一般，这些众生也在名为轮回(saṃsāra)之苦的大苑之中，以那黏著依恃的五种欲德所耽乐的欲执、以那黏著依恃的爱所耽乐的爱执，这两种执著而大为耽乐而乐、大为欢娱而娱、大为爱著而著、大为耽著而著、大为欣悦而悦。

他们于轮回之中不能生厌，反而欢喜愉悦地生活着。
如此以两种执著而耽乐、欢喜、爱著而住的一切众生，对于这因与果相互关联、层层不断生起的这**缘起法**，实在极难了知见到。

至于那作为一切行(saṅkhāra)法之寂灭处的、作为将名为欲基质(kāmupadhi)、蕴基质(khandhupadhi)、烦恼基质(kilesupadhi)、行基质(abhisaṅkhārupadhi)——即苦之依处的四种再生基质(upadhi)悉数舍弃处与脱离处的、作为(108)种爱之尽灭处的、作为一千五百种烦恼(kilesa) = 贪(rāga)之脱离处的、作为一切苦之寂灭处的涅槃(nibbāna)胜法，则更加极难看见。

我佛若也宣说那样深奥的法，而诸根(indriya)未熟、不堪得度的天、人、梵天(brahmā)众生们又不能了知见到、不能领会我佛的那胜法，那么对于那些不能了知、不能领会、不堪得度的天、人、梵天众生宣说佛法，对我佛而言只不过是徒然疲累、困顿罢了。” ——

在世尊的心相续中，生起了如此的心念。
此外，在世尊的智(ñāṇa)中，这两首极为稀有奇妙、往昔未曾听闻的偈颂(gāthā)也清晰地显现出来——

kicchena me adhigataṃ, halaṃ dāni pakāsituṃ.
rāgadosaparetehi, nāyaṃ dhammo susambudho.

paṭisotagāmiṃ nipuṇaṃ, gambhīraṃ duddasaṃ aṇuṃ.
rāgarattā na dakkhanti, tamokhandhena āvuṭā.
(Vi-3-5-6. Dī-2-31.)

me = 是我佛。
kicchena = 藉由艰难地圆满修习、积集十种波罗蜜(pāramī)、三十种细分、三类行(cariyā)、五大舍离等等一切殊胜波罗蜜。
adhigataṃ = 已经证得、了知见到的。
imaṃ dhammaṃ = 这四谛之深法。
dāni = idāni = 于成佛后的如今、当下这时候。
pakāsituṃ = 为了向人、天、梵天众生清楚明白地宣说。
halaṃ = 时机未合、尚不适宜。
ayaṃ dhammo = 这四谛之深法。
rāgadosaparetehi = 被贪、瞋(dosa)炽盛地笼罩、逼恼着的那些人。
na susambudho = 不会明明白白、轻易地了知见到。

tamokhandhena = 名为无明(avijjā)的黑暗聚。
āvuṭā = 因将慧眼笼罩遮盖得毫无缝隙，
rāgarattā = 以欲贪(kāmarāga)、有贪(bhavarāga)、见贪(diṭṭhirāga)而贪染执著的天人众。
nipuṇaṃ = 极其微细幽微的。
gambhīraṃ = 如承载厚重大地的水层一般极其深奥的。
duddasaṃ = 如被大须弥山覆盖的芥子一般极难看见的。
aṇuṃ = 如微尘一般微细的。
paṭisotagāmiṃ = 逆着轮回之流、通向涅槃的名为四谛的善法。
na dakkhanti = 将不能看见。(Vi-3-5-6. Dī-2-31.)

世尊的四谛胜法，是如此地艰深、深奥。
在这般艰深、深奥的四谛之中，**缘起法**也包含在内。

正如在《谛相应(saccasaṃyutta)·尖顶屋经(kūṭāgārasutta)》等经(sutta)中，世尊亲自宣说：若不以正见智慧亲身现见、透彻地了知见到四谛胜法，便不能尽除轮回之苦；同样地，世尊也在**《大缘经(mahānidānasutta)》**(Dī-2-47)等经中亲口宣说：对于身为四谛之一部分的**缘起法**，若不以随觉智(anubodhañāṇa)、通达智(paṭivedhañāṇa)亲身现见、透彻地了知见到，便不能从轮回之苦中解脱。

无论多么难知、深奥，若不了知见到那缘起的种种本质法，便不能从轮回中解脱；因此，凡想从轮回中解脱的人，都必须努力去了知缘起的种种本质法。

在这样努力时——你这善士应当恭敬地把(7)种清净(visuddhi)的修行次第顶戴奉持、领受奉行。

- 1. 戒清净(sīlavisuddhi) = 努力使戒(sīla)清净。
- 2. 心清净(cittavisuddhi) = 为使心从盖(nīvaraṇa)的垢秽中洁净清净，努力去获得近行定(upacārasamādhi)或名为安止(appanā)的禅定(jhānasamādhi)中的任何一种。
- 3. 见清净(diṭṭhivisuddhi) = 为使对色、名的智见清净 = 使智见抵达究竟法(paramattha) = 努力去获得名色分别智(nāmarūpaparicchedañāṇa)。
- 4. 到那时才迈入度疑清净(kaṅkhāvitaraṇavisuddhi)的阶段。

倘若尚未圆满戒清净、心清净、见清净这些清净的修行次第 = 戒尚未清净、近行与安止两种定中的任何一种也尚未获得、也尚未把色名了知见到抵达究竟法，就去努力获取那名为度疑清净、具足能够洗净疑惑(vicikicchā)之法之圆满能力、能够统摄过去、未来、现在三时之因法的缘摄受智(paccayapariggahañāṇa)——即去努力透彻了知因果关联的缘起种种本质法，那么由于越阶躐等，便只会落得钵破身碎，只会徒耗蚕丝而织不成布匹。
想要获得成功，并不容易。

这是因为：唯有站立在名为戒的大地上，以在名为定的殊胜磨石上磨得极其锋利的、名为智的利剑加以劈破，方能透彻了知见到这缘起——轮回之轮的运转之相。
(Abhi-ṭ-2-189. Visuddhi-2-221.)

因此，愿一切渴求真实正法的善士、贤者们，能够以正见智慧亲身现见、透彻地了知见到世尊所宣说的**缘起教说(desanā)之观照面**，精勤修习、努力用功——

帕奥禅林西亚多
芝达拉山(cittalapabbata)寺 — 帕奥禅林
教历(sāsana) 2537 年，
缅历 1355 年，德保(Tabaung)月。
