### 根缘（indriya paccaya）

以能作主宰的状态、以对与自己相关的诸法作主人主宰的状态而能施予资助的、除女性根（itthindriya）与男性根（purisindriya）之外的（20）种根（indriya），名为**根缘**。

**（20）种根**

- 1. 眼根（cakkhundriya） = 眼净色（cakkhupasāda） = 眼的明净，
- 2. 耳根（sotindriya） = 耳净色（sotapasāda） = 耳的明净，
- 3. 鼻根（ghānindriya） = 鼻净色（ghānapasāda） = 鼻的明净，
- 4. 舌根（jivhindriya） = 舌净色（jivhāpasāda） = 舌的明净，
- 5. 身根（kāyindriya） = 身净色（kāyapasāda） = 身的明净，
- 6. 命根（jīvitindriya） = 色命根（rūpajīvita）＋名命根（nāmajīvita）——两者全部，
- 7. 意根（manindriya） = 一切心（citta），
- 8. 乐根（sukhindriya） = 与乐（sukha）俱行的身识（kāyaviññāṇa）相应的受（vedanā）（＝乐受），
- 9. 苦受根（dukkhindriya） = 与苦（dukkha）俱行的身识相应的受（＝苦受），
- 10. 悦根（somanassindriya） = 在（62）种悦（somanassa）俱行心中相应的悦受，
- 11. 忧根（domanassindriya） = 在两种瞋根（dosamūla）心中相应的受（＝忧（domanassa）受），
- 12. 舍受根（upekkhindriya） = 在（55）种舍（upekkhā）俱行心中相应的受（＝舍受），
- 13. 信根（saddhindriya） = 在美心（sobhana citta）中相应的信心所（saddhā cetasika），
- 14. 念根（satindriya） = 在美心中相应的念心所（sati cetasika），
- 15. 精进根（vīriyindriya） = 在精进所相应的（73）种心中相应的精进心所（vīriya cetasika），
- 16. 定根（samādhindriya） = 在除去与精进不相应的（16）种心、以及疑（vicikicchā）俱行心之外的其余（72）种心中相应的一境性心所（ekaggatā cetasika），
- 17. 慧根（paññindriya） = 在（47）种三因（tihetuka）心中相应的慧（paññā），
- 18. 未知当知根（anaññātaññassāmītindriya） = 在入流道（sotāpattimagga）心中相应的慧，
- 19. 已知根（aññindriya） = 在上三道、下三果中相应的慧，
- 20. 具知根（aññātāvindriya） = 在阿拉汉果（arahatta phala）中相应的慧，

以上就是堪能成为根缘的（20）种根。

cakkhundriyaṃ cakkhuviññāṇadhātuyā, sota, ghāna, jivhā, kāyindriyaṃ kāyaviññāṇadhātuyā taṃsampayuttakānañca dhammānaṃ indriyapaccayena paccayo.

rūpajīvitindriyaṃ kaṭattārūpānaṃ indriyapaccayena paccayo. arūpino indriyā sampayuttakānaṃ dhammānaṃ taṃsamuṭṭhānānañca rūpānaṃ indriyapaccayena paccayo. (Paṭṭhāna-1-7,8.)

paṭisandhikkhaṇe vipākābyākatā indriyā sampayuttakānaṃ khandhānaṃ kaṭattā ca rūpānaṃ indriyapaccayena paccayo. (Paṭṭhāna-1-157.)

**arūpino indriyā**ti ettha arūpajīvitindriyampi saṅgahitaṃ. (Abhi-A-3-378.)

**依处前生根（vatthu purejātindriya）**

属于中等寿量（majjhimāyuka）、与过去有分（atīta bhavaṅga）同一生起（uppāda）刹那而生起的眼、耳、鼻、舌、身这（5）种根，唯独对依止它们而生起的各自名法，以依处前生根缘力（vatthu purejātindriya paccaya satti）施予资助。

- 1. 眼根对眼识界（cakkhuviññāṇa dhātu）与相应（sampayutta）法众 -
- 2. 耳根对耳识界与相应法众 -
- 3. 鼻根对鼻识界与相应法众 -
- 4. 舌根对舌识界与相应法众 -
- 5. 身根对身识界与相应法众 -

以依处前生根缘力施予资助。

那些作为所依止处的依处（vatthu）色，在五识（pañcaviññāṇa）与相应法众尚未生起之前，与作为倒数第四个心的过去有分同一生起刹那而预先生起在前，并且又是各自五识与相应法众所依止的依处色，因此名为依处前生（vatthu purejāta）。
那些得名为依处前生的依处色，对依止它们而生起的各自各自的名法众，以能作主宰的状态、以作主人主宰的状态而能施予资助。
因此它们名为依处前生根缘法。
那些缘法从生起直到坏灭（bhaṅga）为止，都以根缘力资助诸缘生（paccayuppanna）法。
请理解：如果没有眼依处（cakkhuvatthu），眼识与相应法众就不可能生起。

因为眼依处生起，所以眼识、受蕴（vedanākkhandha）生起。

眼依处是因法，眼识、受蕴是果法——正是以这样等等方式而在前面已经列示过的那些观照片段。

### 色命根

- 6. 色命根对与自己一同生起的、同一色聚（kalāpa）内的诸业生色（kammaja rūpa），以根缘力施予资助。
[如果是像眼十法聚那样的十法聚（dasaka kalāpa），命根就在住时刹那（ṭhiti khaṇa）以根缘力资助除自己以外其余（9）种同聚业生色；如果是像命根九法聚（jīvitanavaka kalāpa）那样的九法聚（navaka kalāpa），命根就在住时刹那以根缘力资助除自己以外其余（8）种同聚业生色。（Abhi-A-3-379。）]

### 俱生根（sahajātindriya）

- 7. 包含名命根在内的诸名根，对与自己各自相应的诸法，对因自己而生起的结生（paṭisandhi）业生色（＝业所造色 kaṭattā rūpa），以及对诸心生色（cittasamuṭṭhāna rūpa），都以俱生根缘力施予资助。

在诸名根缘法以根缘力资助相应法与其等起色（taṃsamuṭṭhāna rūpa）时，就「其等起色」这一项而言，不仅要算上心生色，还要把业所造色（＝结生业生色）也一并计入。
在《问分》（Pañhāvāra）巴利圣典中，佛陀这样宣说---

- 8. 在结生刹那，属于果报（vipāka）无记（abyākata）的诸名根缘法，对相应的诸名蕴，以及对诸业所造色，都以俱生根缘力施予资助。
（Paṭṭhāna-1-157。）

### 女性根 男性根

在具有女性根（＝女性色 itthibhāva rūpa）的女众相续中，会有纤细的手足等名为「特征」（liṅga）的东西，微笑的样子、欢笑的样子等名为「相」（nimitta）的东西，小女孩用小盘小簸箕等玩耍的方式等名为「行止」（kutta）的东西，以及女众行走的姿态、举止等名为「仪态」（ākappa）的东西生起。
在具有男性根（＝男性色 purisabhāva rūpa）的男众相续中，会有粗大的手足等特征，微笑的样子、欢笑的样子等相，男众的玩耍方式等行止，以及男众行走的姿态、举止等仪态生起。

女性根、男性根确实是女特征、男特征，女相、男相，女行止、男行止，女仪态、男仪态的种子，这是真实的；但是在羯罗蓝（kalala）清液、泡沫等阶段生起之时，那些女性根、男性根虽然明显存在，可是由于女特征、男特征、女相、男相等并不明显存在，所以那些女性根、男性根不能在那些女特征、男特征等之上散布根缘力。
它们同样也不能在女特征、男特征等以外其他的同聚业生色之上散布作为根缘的作用。
确实如此——所谓根缘，在它自身明显存在的刹那，对于那些各各不应分离、不能分离、并非分离而生起因而不可分割的（＝只是就色聚、名聚而言不可分割，但用智慧却能够一个一个地分别剖析而了知的）色法与名法，绝不可能有不能在其上散布根缘作用的情形。
因此，那些女性根、男性根不成为根缘法。（Abhi-A-3-378。）

虽然女性根、男性根如此不成为根缘，但这些女性根、男性根毕竟是那些女特征、男特征等的种子。
就那些女特征、男特征等而言，那些女性根、男性根依照经藏的教说方式（suttantika pariyāya＝经中所说的教示方法），确实归属于「性质上强而有力的所依止」即本性亲依止缘（pakatūpanissaya paccaya）。
因此应当了知：根缘法只是依（20）种根的力量而成立。（Abhi-A-3-378。）

这是名色资助名色的缘。

缘与缘生这两者，都纯粹只是现在的诸法。
