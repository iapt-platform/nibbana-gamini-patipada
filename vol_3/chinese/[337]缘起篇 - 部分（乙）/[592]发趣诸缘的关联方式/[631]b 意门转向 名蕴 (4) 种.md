### 意门转向(manodvārāvajjana) 名蕴(nāmakkhandhā) (4) 种

意门转向的(4)种名蕴这些缘生法(paccayuppannadhamma) -----

- 1. 俱生(sahajāta)类 --- 10、
- 2. 所缘(ārammaṇa)类 --- (1、4、) 6、
- 3. 无间(anantara)类 --- 5、
- 4. 依处(vatthu)类 --- 5、
- 5. 本性亲依止(pakatūpanissaya) --- 1、

由于这(22)种、或(25)种、或(27)种缘法，才得以生起、存在。

意门转向各个部分的(4)种名蕴这些缘生法 -----

- 1. (甲) 由于能够彼此相互给予助益的意门转向各个部分的名蕴缘法的**俱生、相互(aññamañña)、依止(nissaya)、相应(sampayutta)、有(atthi)、不离去(avigata)缘力(satti)，**
  - ( 乙 ) 由于能够给予相应诸蕴助益的、意门转向名蕴中所包含的思(cetanā)缘法的**俱生业(kamma)缘力，**
  - ( 丙 ) 由于触(phassa)、思、识(viññāṇa)这(3)种名食(āhāra)缘法的**食缘力，**
  - (丁) 由于命(jīvita)、心(citta)、受(vedanā)、精进(vīriya)、一境性(ekaggatā) ----- 这(5)种名根(indriya)缘法的**根缘力，**
  - ( 戊 ) 由于除去喜(pīti)之后的(4)支禅支(jhānaṅga)缘法的**禅(jhāna)缘力，(10)**。
- 2. 一般而言能够取所缘的意门转向的(4)种名蕴这些缘生法 -----
  - (甲) 有时一般而言所应取的心(89)、心所(52)、属于过去与未来的完成色(nipphannarūpa)(18)、属于过去、未来、现在的非完成色(anipphannarūpa)(10)、涅槃(nibbāna)、概念(paññatti) ----- 由于这(6)种所缘当中某一种所缘缘法的**所缘缘力，(1)**。
  - ( 乙 ) 有时一般而言所应取的现在的完成色(18) ----- 由于这(6)种所缘当中某一种所缘缘法的**所缘、前生(purejāta)、有、不离去缘力，(4)。**
  - ( 丙 ) 由于临终(maraṇāsanna)时一般而言所应取的、与从死心(cuti)往回数则为第(17)个的那个心的生刹那(uppādakkhaṇa)同时并起而生起的心所依处(hadayavatthu)缘法的**所缘、依止、前生、不相应(vippayutta)、有、不离去缘力，(6)**。 
(这是指依止那个心所依处而生起，又反过来取那个心所依处为所缘。)
- 3. 意门转向的(4)种名蕴这些缘生法，是由于中间没有其他(心)相隔而已经灭去的有分断(bhavaṅgupaccheda)、或自己之前的有分(bhavaṅga)名蕴缘法的**无间、等无间(samanantara)、强依止(upanissaya)、无有(natthi)、离去(vigata)缘力，(5)。**
- 4. 意门转向的(4)种名蕴这些缘生法，是由于与那有分断名蕴、或自己之前的有分名蕴的生刹那同时并起而生起的心所依处缘法的**依止、前生、不相应、有、不离去缘力，(5)。**
- 5. 意门转向的(4)种名蕴这些缘生法，是由于成为有力(balava)的 = 强而有力的心(89)、心所(52)、色(28)，以及应当成为缘的某些概念等缘法的**本性亲依止缘力，(1)。**

由于这(22)种、或(25)种、或(27)种因缘法共同围绕着给予助益，意门转向的(4)种名蕴这些缘生法才得以生起、存在。
