### 色界结生(rūpapaṭisandhi)名蕴(nāmakkhandhā) (4)种的生起方式

依五分法(pañcakanaya)，色界(rūpāvacara)结生(paṭisandhi)(5)种当中某一种色界结生的(4)种名蕴这些缘生法(paccayuppannadhamma) ---

- 1. 名(nāma)俱生(sahajāta)类 --- 13、
- 2. 色(rūpa)俱生类 --- 6、
- 3. 所缘(ārammaṇa)类 --- 1、
- 4. 无间(anantara)类 --- 5、
- 5. 异刹那业(nānākkhaṇikakamma)类 --- 2、

由于这(27)种因缘(paccaya)法，它们才得以生起并住立。

色界结生各个部分的(4)种名蕴这些缘生法 ----

- 1. (甲) 由于能够相互给予助益的色界结生名蕴缘法的**俱生、相互(aññamañña)、依止(nissaya)、果报(vipāka)、相应(sampayutta)、有(atthi)、不离去(avigata)缘力，**
  - ( 乙 ) 由于能够给予相应诸蕴助益的、那色界结生名蕴中所包含的无贪(alobha)、无嗔(adosa)、无痴(amoha)三因(hetu)缘法的**因缘力，**
  - ( 丙 ) 由于思(cetanā)缘法的**俱生业(kamma)缘力，**
  - (丁) 由于触(phassa)、思、识(viññāṇa)这(3)种名食(āhāra)缘法的**食缘力，**
  - ( 戊 ) 由于(8)种名根(indriya)缘法的**根缘力，**
  - ( 己 ) 若是初禅(paṭhamajhāna)结生 - 禅支(jhānaṅga)(5)种，若是第二禅结生 - 禅支(4)种，若是第三禅结生 - 禅支(3)种，若是第四禅结生 - 乐(sukha)、一境性(ekaggatā)禅支(2)种，若是第五禅结生 - 舍(upekkhā)、一境性禅支(2)种，这些缘法的**禅那(jhāna)缘力，**
  - (庚) 若是初禅结生 -- 慧(paññā)、寻(vitakka)、精进(vīriya)、念(sati)、一境性这(5)种道支(maggaṅga)，若是第二禅、第三禅、第四禅、第五禅结生当中的任一种 - 慧、精进、念、一境性这(4)种道支，这些缘法的**道(magga)缘力、(13)。**
- 2. 色界结生整组的(4)种名蕴这些缘生法，是由于与自身(色界结生)一同生起的心所依处(hadayavatthu)缘法的**俱生、相互、依止、不相应(vippayutta)、有、不离去缘力、(6)。**
- 3. **初禅结生**整组的(4)种名蕴这些缘生法 ----
  - (甲) 遍(kasiṇa)概念(paññatti)(10)种、
  - ( 乙 ) 不净(asubha)概念(10)种、
  - ( 丙 ) 作为身至念(kāyagatāsati)所缘的头发等身分(kāyakoṭṭhāsa)(= 32身分)概念、
  - (丁) 作为入出息念(ānāpānassati)所缘的入息、出息概念 = 入出息似相(paṭibhāganimitta)所缘、
  - ( 戊 ) 作为慈(mettā)所缘的一切快乐(sukhita)、受苦(dukkhita)有情(satta)概念、
  - ( 己 ) 作为悲(karuṇā)所缘的一切受苦有情概念、
  - (庚) 作为随喜(muditā)所缘的一切快乐有情概念、

是由于这(25)种概念、业相(kammanimitta)当中某一种概念、业相所缘缘法的**所缘缘力、(1)。**

**第二禅、第三禅、第四禅结生**整组的(4)种名蕴这些缘生法 ----

- (甲) 遍概念(10)种、
- ( 乙 ) 作为入出息念所缘的入息、出息概念 = 入出息似相所缘、
- ( 丙 ) 作为慈所缘的一切快乐、受苦有情概念、
- (丁) 作为悲所缘的一切受苦有情概念、
- ( 戊 ) 作为随喜所缘的一切快乐有情概念、

是由于这(14)种概念业相当中某一种概念、业相缘法的**所缘缘力、(1)。**

**第五禅结生**整组的(4)种名蕴这些缘生法 ----

- (甲) 遍概念(10)种、
- ( 乙 ) 作为入出息念所缘的入息、出息概念 = 入出息似相所缘、
- ( 丙 ) 作为舍所缘的一切快乐、受苦有情概念、

是由于这(12)种概念、业相当中某一种概念、业相缘法的**所缘缘力、(1)。**

- 4. 色界结生整组的(4)种名蕴这些缘生法，是由于已经灭去的(9)种五蕴有(pañcavokāra)三因死心(cuti)当中某一种死心名蕴缘法的**无间、等无间(samanantara)、强依止(upanissaya)、无有(natthi)、离去(vigata)缘力、(5)。**
- 5. 色界结生整组的(4)种名蕴这些缘生法，是由于过去的(5)种色界善业当中(相应的)某一种缘法的**异刹那业、本性亲依止(pakatūpanissaya)缘力、(2)。**

(初禅善业令初禅结生生起 ---- 如此等等，请按适当的情形理解。)

由于这(27)种因缘法共同给予助益，它们才得以生起并住立。

现在接下来呈现无色(arūpa)结生与无想有情天(asaññasatta)结生的发趣(paṭṭhāna)缘关联方式这一部分。 
过去的轮回(saṃsāra)极为漫长；若在整个过去轮回中发现自己曾在无色界或无想有情天结生住立，就按照下面的方式观照发趣缘的关联方式。 
对于一位已经获得这样的缘摄受(paccayapariggaha)正见(sammādiṭṭhi)智(ñāṇa)之见、已经具足正见智之见、已经在教法(sāsanā)中扎根而不会脱离教法的瑜伽行者(yogī)善人来说，未来出现无色结生与无想有情天结生是极为稀有的。
