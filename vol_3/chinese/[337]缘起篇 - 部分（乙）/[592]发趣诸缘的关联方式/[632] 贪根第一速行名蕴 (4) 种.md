### 贪根(lobhamūla) 第一速行(paṭhamajavana) 名蕴(nāmakkhandhā) (4) 种

贪根第一速行(4)种名蕴这些缘生法(paccayuppannadhamma) -----

- 1. 俱生(sahajāta)类 --- 13、
- 2. 所缘(ārammaṇa)类 ---1、4、6、3、6、8、
- 3. 无间(anantara)类 --- 5、6、
- 4. 依处(vatthu)类 --- 5、
- 5. 本性亲依止(pakatūpanissaya) --- 1、

- (甲) 有时(25)种
- ( 乙 ) 有时(28)种
- ( 丙 ) 有时(30)种
- (丁) 有时在获得主导(adhipati)缘(paccaya)之时(27)种
- ( 戊 ) 有时在获得主导缘之时(30)种
- ( 己 ) 有时在获得主导缘之时(32)种

若是第二速行等，再加上重复(āsevana)缘，则由于这(26、29、31、28、31、33。)种因缘法共同围绕着给予助益，它们才得以生起并住立。

贪根第一速行各个部分的(4)种名蕴这些缘生法 ----

- 1. (甲) 由于能够相互给予助益的贪根第一速行各个部分的名蕴缘法(paccayadhamma)的**俱生、相互(aññamañña)、依止(nissaya)、相应(sampayutta)、有(atthi)、不离去(avigata)缘力(satti)，(6)。**
  - ( 乙 ) 由于能够给予相应诸蕴助益的、贪根第一速行名蕴中所包含的贪(lobha)、痴(moha)这(2)种因(hetu)缘法的**因缘力，**
  - ( 丙 ) 由于欲(chanda)、精进(vīriya)、心(citta)(3)种当中任何一种缘法的**主导缘力，**
  - (丁) 由于思(cetanā)缘法的俱生**业(kamma)缘力，**
  - ( 戊 ) 由于触(phassa)、思、识(viññāṇa)这(3)种名(nāma)食(āhāra)缘法的**食缘力，**
  - ( 己 ) 由于命(jīvita)、心、受(vedanā)、精进、一境性(ekaggatā)这(5)种名根(indriya)缘法的**根缘力，**
  - (庚) 若是悦(somanassa)俱的贪速行(javana) ----- (5)支禅支(jhānaṅga)；若是舍(upekkhā)俱的贪速行 ---- 除去喜(pīti)的(4)支禅支，由于这些缘法的**禅那(jhāna)缘力，**
  - ( 辛 ) 若是邪见相应(diṭṭhigatasampayutta)的贪速行 --- 寻(vitakka)、精进、一境性、见(diṭṭhi) - (4)支道支(maggaṅga)；若是邪见不相应(diṭṭhigatavippayutta)的贪速行 ---- 寻、精进、一境性 - (3)支道支，由于这些缘法的**道(magga)缘力，(13)。**
- 2. 一般而言能够取所缘的贪根第一速行(4)种名蕴这些缘生法-
  - (甲) 有时一般而言所应取的世间(lokiya)心(81)、心所(cetasika)(52)、属于过去与未来的完成色(nipphannarūpa)(18)、属于三时的非完成色(anipphannarūpa)(10)、概念(paññatti) ---- 由于这(6)种所缘当中某一种所缘缘法的**所缘缘力，(1)。**
  - ( 乙 ) 有时一般而言所应取的现在的完成色(18) ---- 由于这(6)种所缘当中某一种所缘缘法的**所缘、前生(purejāta)、有、不离去缘力，(4)。**
  - ( 丙 ) 由于临终(maraṇāsanna)时一般而言所应取的、与从死心(cuti)往回数则为第(17)个的那个心的生刹那(uppādakkhaṇa)同时并起而生起的心所依处(hadayavatthu)缘法的**所缘、依止、前生、不相应(vippayutta)、有、不离去缘力，(6)。**

以**珍重**的方式能够取所缘的贪根第一速行(4)种名蕴这些缘生法 ----

- (甲) 有时以珍重的方式所应取的、除去(2)个嗔根(dosamūla)心、(2)个痴根(mohamūla)心、苦俱(dukkhasahagata)身识(kāyaviññāṇa)的世间心(76)，除去嗔(dosa)、嫉(issā)、悭(macchariya)、恶作(kukkucca)、疑(vicikicchā)的心所(47)、属于过去与未来的完成色(18) ----- 由于这(6)种所缘当中某一种所缘缘法的**所缘、主导、强依止(upanissaya)缘力，(3)。**
- ( 乙 ) 有时以珍重的方式所应取的现在的完成色(18) ----- 由于这(6)种所缘当中某一种所缘缘法的**所缘、主导、强依止、前生、有、不离去缘力，(6)。**
- ( 丙 ) 由于临终时以珍重的方式所应取的、与从死心往回数则为第(17)个的那个心的生刹那同时并起而生起的心所依处缘法的**所缘、主导、依止、强依止、前生、不相应、有、不离去缘力，(8)。**
