### 二因(dvihetuka)结生(paṭisandhi)名蕴(nāmakkhandhā) (4)种

(大果报(mahāvipāka)当中不与智(ñāṇa)相应的智不相应(ñāṇavippayutta)悦(somanassa)有行(sasaṅkhārika)、无行(asaṅkhārika)，舍(upekkhā)有行、无行这样的)二因结生的(4)种名蕴这些缘生法(paccayuppannadhamma) ----

- 1. 名(nāma)俱生(sahajāta)类 --- 13、
- 2. 色(rūpa)俱生类 --- 6、
- 3. 所缘(ārammaṇa)类 --- 1、
- 4. 无间(anantara)类 --- 5、
- 5. 异刹那业(nānākkhaṇikakamma)类 --- 2、

由于这(27)种因缘(paccaya)法，它们才得以生起并住立。

二因结生各个部分的(4)种名蕴这些缘生法 -----

- 1. (甲) 由于能够相互给予助益的二因结生各个部分的名蕴缘法的**俱生、相互(aññamañña)、依止(nissaya)、果报(vipāka)、相应(sampayutta)、有(atthi)、不离去(avigata)缘力，(7)。**
  - ( 乙 ) 由于能够给予相应诸蕴助益的、那二因结生名蕴中所包含的无贪(alobha)、无嗔(adosa)这(2)种因(hetu)缘法的**因缘力，**
  - ( 丙 ) 由于思(cetanā)缘法的俱生**业(kamma)缘力，**
  - (丁) 由于触(phassa)、思、识(viññāṇa)这(3)种名食(āhāra)缘法的**食缘力，**
  - ( 戊 ) 由于除去慧(paññā)之后的(7)种名根(indriya)缘法的**根缘力，**
  - ( 己 ) 若是悦二因结生 - 则为寻(vitakka)、伺(vicāra)、喜(pīti)、乐(sukha)、一境性(ekaggatā)这(5)种禅支(jhānaṅga)；若是舍二因结生 - 则为除去喜之后的(4)种禅支，由于这些缘法的**禅那(jhāna)缘力，**
  - (庚) 由于寻、精进(vīriya)、念(sati)、一境性这(4)种道支(maggaṅga)缘法的**道(magga)缘力，(13)。**
- 2. 二因结生整组的(4)种名蕴这些缘生法，是由于与自己(二因结生名蕴)一同生起的心所依处(hadayavatthu)缘法的**俱生、相互、依止、不相应(vippayutta)、有、不离去缘力，(6)。**
- 3. 二因结生整组的(4)种名蕴这些缘生法，是由于业、业相(kammanimitta)、趣相(gatinimitta)这(3)者当中某一种所缘缘法的**所缘缘力，(1)。**
- 4. 二因结生整组的(4)种名蕴这些缘生法，是由于已经灭去的色界死心(cuti)(5)、欲界死心(10)、合计(15)种死心当中某一种死心名蕴缘法的**无间、等无间(samanantara)、强依止(upanissaya)、无有(natthi)、离去(vigata)缘力，(5)。**
- 5. 二因结生整组的(4)种名蕴这些缘生法，是由于过去的、相应的某一种三因(tihetuka)下劣(omaka)、二因殊胜(ukkaṭṭha)大善(mahākusala)业缘法的**异刹那业、本性亲依止(pakatūpanissaya)缘力，(2)。**

由于这(27)种因缘法共同围绕着给予助益，它们才得以生起并住立。

**应当记取的事项**

如果你这位善人发现自己在过去某一世中曾经结生为欲界三因结生，那么就按照上面所讲述的欲界三因结生同样地观照。 
如果发现在未来也将会结生为欲界三因结生，也请以同样的方法观照。

如果你这位善人以智照见自己曾经结生为色界结生(rūpapaṭisandhi)，或者在未来也将会结生为色界结生，那么为了让智能够熟练地领会那色界结生得以生起时发趣诸缘(paṭṭhānapaccaya)给予助益的方式与情形，以下继续加以说明。
