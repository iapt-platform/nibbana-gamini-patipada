### 三因(tihetuka)结生(paṭisandhi)业生色(kammajarūpa) = 色蕴(rūpakkhandhā) (29)

首先，你——善男子，对于由无明(avijjā)、爱(taṇhā)、取(upādāna)、行(saṅkhāra)、业(kamma)这些过去的因法而使现在的结生五蕴(khandhā)生起的方式，以及由现在的诸因法而使那些结生蕴生起的方式，特别是称为业生色(30)的色蕴生起的方式，都要按照缘起(paṭiccasamuppāda)第五种方法的观照段中所写的那样，努力用智(ñāṇa)见到它。
只有这样用智见到了果法由因法而生起的方式之后，才可以进一步观照下面所阐述的诸因法与诸果法之间发趣(paṭṭhāna)诸缘(paccaya)的关联方式这一义理，直到用智见到它。
请用智去审察。
如果还不能用智观见果法由因法而生起的方式，那么对于发趣诸缘的关联也将无法真正领会。

业生色 ---- 除心所依处(hadayavatthu)之外的(29)种欲界三因结生业生色这些缘生法(paccayuppannadhamma) ----

- 1. 名(nāma)俱生(sahajāta)类 --- 12、
- 2. 色俱生类 --- 5、
- 3. 后生(pacchājāta)类 --- 4、
- 4. 色命根(rūpajīvitindriya)类 --- 3、
- 5. 异刹那业(nānākkhaṇikakamma)类 --- 1、

由于这(25)种因缘法共同给予助益，它们才得以生起并住立。

**生起并住立的方式如下**

- 1. (甲) 除心所依处之外的(29)种欲界三因结生业生色这些缘生法，是由于相应的欲界三因结生名法组(若是悦(somanassa)则为34，若是舍(upekkhā)则为33)这整组名蕴(nāmakkhandhā)缘法(paccayadhamma)的**俱生、依止(nissaya)、果报(vipāka)、不相应(vippayutta)、有(atthi)、不离去(avigata)缘力(paccayasatti)。**
  - ( 乙 ) 由于结生名法组中所包含的无贪(alobha)、无嗔(adosa)、无痴(amoha)这(3)种因(hetu)缘法的**因缘力，**
  - ( 丙 ) 由于结生名法组中所包含的思(cetanā)缘法的**俱生业缘力，**
  - (丁) 由于结生名法组中所包含的触(phassa)、思、识(viññāṇa)缘法的**食(āhāra)缘力，**
  - ( 戊 ) 由于结生名法组中所包含的命(jīvita)、心(citta)、受(vedanā)(悦受或舍受)、信(saddhā)、精进(vīriya)、念(sati)、一境性(ekaggatā)、慧(paññā)这称为(8)种名根(indriya)的缘法的**根缘力，**
  - ( 己 ) 若是与悦俱行的结生一同生起的业生色 ---- 则由寻(vitakka)、伺(vicāra)、喜(pīti)、乐(sukha)(受)、一境性这称为(5)种禅支(jhānaṅga)的缘法；若是与舍俱行的结生一同生起的业生色 ---- 则由寻、伺、舍(受)、一境性这称为(4)种禅支的缘法的**禅那缘力，**
  - (庚) 也由于慧、寻、精进、念、一境性这称为(5)种道支(maggaṅga)的缘法的**道缘力**。(**名俱生类 - 12**)
- 2. 也由于(3)种色聚(kalāpa) = (30)种色，(若除去心所依处则为29种)这些色当中，同一色聚内成组的(4)大种(mahābhūta)缘法各自相应地给予助益的**俱生、相互(aññamañña)、依止、有、不离去缘力**，(**色俱生类 - 5**)
- 3. 也由于随后生起的第一个有分(bhavaṅga)名蕴缘法的**后生、不相应、有、不离去缘力**，(**后生类 - 4**)
- 4. 也由于同一色聚中的色命根缘法的色命根、**色命根有、色命根不离去缘力**，(**色命根类 - 3**)
- 5. 也由于你这位善男子自己在某一过去世中所培育的、被无明、爱、取这些烦恼轮转(kilesavaṭṭa)所围绕的、称为行-业的业轮转(kammavaṭṭa) = 相应的某一种欲界善业(kāmakusalakamma)缘法的**异刹那业缘力**，(**异刹那业类 - 1**)

由于这(25)种缘法给予助益的诸缘力，那(29)种结生业生色法才得以生起并住立。
请仔细地对照观照，直到用智见到它。
你自己就能领会：发趣的开示(desanā)对于你这位善男子的缘摄受智(paccayapariggahañāṇa)，是如何、以何种方式在给予助益的。
