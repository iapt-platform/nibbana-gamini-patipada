### 有分(bhavaṅga)名蕴(nāmakkhandhā) (4) 种

欲界(kāma)三因(tihetuka)有分(34、33)的(4)种名蕴这些缘生法(paccayuppannadhamma) ----

- 1. 名(nāma)俱生(sahajāta)类 --- 13、
- 2. 所缘(ārammaṇa)类 --- 1、
- 3. 无间(anantara)类 --- 5、
- 4. 依处(vatthu)类 --- 5、
- 5. 异刹那业(nānākkhaṇikakamma)类 --- 2、

由于这(26)种缘法(paccayadhamma)，才得以生起、存在。

欲界三因有分(34、33)整组成分的(4)种名蕴这些缘生法 ----

- 1. (甲) 能够彼此相互给予助益的欲界三因有分(34、33)各个部分的名蕴缘法的**俱生、相互(aññamañña)、依止(nissaya)、果报(vipāka)、相应(sampayutta)、有(atthi)、不离去(avigata)缘力(satti)，**
  - [**注意** ---- 请留意「触(phassa)(= 33)是因法、受蕴(vedanākkhandhā)是果法」等等的观照角度。]
  - ( 乙 ) 能够给予相应诸蕴助益的、欲界三因有分(34、33)名蕴中所包含的无贪(alobha)、无嗔(adosa)、无痴(amoha)这(3)种因(hetu)缘法的**因缘力，**
  - ( 丙 ) 思(cetanā)缘法的**俱生业(kamma)缘力，**
  - (丁) 触、思、识(viññāṇa)这(3)种名食(āhāra)缘法的**食缘力，**
  - ( 戊 ) 名根(8)种缘法的**根(indriya)缘力，**
  - ( 己 ) 若是悦(somanassa)有分 ---- 寻(vitakka)、伺(vicāra)、喜(pīti)、乐(sukha)、一境性(ekaggatā) - 禅支(jhānaṅga)(5)种；若是舍(upekkhā)有分 ---- 寻、伺、舍、一境性禅支(4)种缘法的**禅(jhāna)缘力，**
  - (庚) 除去远离(virati)之后的道支(maggaṅga)(5)种缘法的**道(magga)缘力、(13)**。
- 2. 业(kamma)-业相(kammanimitta)-趣相(gatinimitta)这三者当中某一种所缘缘法的**所缘缘力，** (1)。
- 3. (甲) 当[有分]紧接在结生(paṭisandhi)之后生起时，已经灭去的欲界三因结生名蕴、
  - ( 乙 ) 当紧接在有分之后生起时，已经灭去的欲界三因有分名蕴、
  - ( 丙 ) 当紧接在确定(vuṭṭhāpana)之后生起时，已经灭去的确定名蕴、
  - (丁) 当紧接在速行(javana)之后生起时，已经灭去的最后一个速行的名蕴、
  - (戊) 当紧接在彼所缘(tadārammaṇa)之后生起时，已经灭去的第二个彼所缘名蕴——这些缘法的**无间、等无间(samanantara)、强依止(upanissaya)、无有(natthi)、离去(vigata)缘力、(5)**。
- 4. (甲) 那些有分名蕴当紧接在结生之后生起时(意思是指第一个有分。)，与欲界三因结生一同生起的心所依处(hadayavatthu)、
  - ( 乙 ) 当紧接在有分之后生起时(意思是指在有分之后生起的有分 = 第二个有分等等。)，与前前的欲界三因有分名蕴一同生起的心所依处、
  - ( 丙 ) 当紧接在确定之后生起时，与确定名蕴一同生起的心所依处、
  - (丁) 当紧接在速行之后生起时，与最后一个速行名蕴一同生起的心所依处、
  - ( 戊 ) 当紧接在彼所缘之后生起时，与第二个彼所缘名蕴一同生起的心所依处、
  - ( 己 ) 在临死(maraṇāsanna)之时，从死心(cuti)往回数第(17)个心，与该心一同生起的心所依处缘法的**依止、前生(purejāta)、不相应(vippayutta)、有、不离去缘力、(5)。**
- 5. 过去的、相应的某一种三因殊胜(ukkaṭṭha)欲界善业(kāmakusalakamma)缘法的**异刹那业、本性亲依止(pakatūpanissaya)缘力、(2)**。

由于这(26)种因缘力(paccayasatti)共同围绕着给予助益，才得以生起、存在。

[**注意** ---- 从第一个有分开始的(15)次或(16)次有分之后所生起的意门转向(manodvārāvajjana)、以及有分爱着(bhavanikantika)贪(lobha)速行的(5)蕴生起、存在的方式，可以参照后文将要写出的意门转向、贪速行(5)蕴而了知。]
