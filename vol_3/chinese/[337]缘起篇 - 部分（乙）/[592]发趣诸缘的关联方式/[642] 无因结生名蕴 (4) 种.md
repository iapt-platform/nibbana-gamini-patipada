### 无因(ahetuka)结生(paṭisandhi)名蕴(nāmakkhandhā) (4)种

不善果报(akusalavipāka)舍(upekkhā)推度(santīraṇa)(=苦界(apāya)结生)与善果报(kusalavipāka)舍推度
(=善趣(sugati)无因结生)这两种无因结生的(4)种名蕴这些缘生法(paccayuppannadhamma) ----

- 1. 名(nāma)俱生(sahajāta)类 --- 11、
- 2. 色(rūpa)俱生类 --- 6、
- 3. 所缘(ārammaṇa)类 --- 1、
- 4. 无间(anantara)类 --- 5、
- 5. 异刹那业(nānākkhaṇikakamma)类 --- 2、

由于这(25)种因缘(paccaya)法，它们才得以生起并住立。 
(由于这两种结生的发趣诸缘关联方式相同，所以合并起来书写呈现。 
观照的时候，则要按照在那些生存地中实际发生的情形，一种一种分开来观照。)

(2)个无因结生心(citta)、除去欲(chanda)、喜(pīti)、精进(vīriya)的同他(aññasamāna)心所(cetasika)(10)个、(心+心所=名法-11) 各个部分的(4)种名蕴这些缘生法 ----

- 1. (甲) 由于能够相互给予助益的无因结生各个部分的名蕴缘法的**俱生、相互(aññamañña)、依止(nissaya)、果报(vipāka)、相应(sampayutta)、有(atthi)、不离去(avigata)缘力，**
  - ( 乙 ) 由于能够给予相应诸蕴助益的、那无因结生名蕴中所包含的思(cetanā)缘法的**俱生业(kamma)缘力，**
  - ( 丙 ) 由于触(phassa)、思、识(viññāṇa)这(3)种名食(āhāra)缘法的**食缘力，**
  - (丁) 由于命(jīvita)、心、受(vedanā)这(3)种名根(indriya)缘法的**根缘力，**
  - ( 戊 ) 由于除去喜之后的禅支(jhānaṅga)(4)种缘法的**禅那(jhāna)缘力、(11)**。
- 2. 无因结生整组的(4)种名蕴这些缘生法，是由于与无因结生名蕴一同生起的心所依处(hadayavatthu)缘法的**俱生、相互、依止、不相应(vippayutta)、有、不离去缘力、(6)**。
- 3. 无因结生整组的(4)种名蕴这些缘生法，是由于业、业相(kammanimitta)、趣相(gatinimitta)这(3)者当中某一种缘法的**所缘缘力、(1)。**
- 4. 无因结生整组的(4)种名蕴这些缘生法，是由于已经灭去的(10)种欲界死心(cuti)当中某一种死心名蕴缘法的**无间、等无间(samanantara)、强依止(upanissaya)、无有(natthi)、离去(vigata)缘力、(5)。**
- 5. (甲) 恶趣(duggati)无因结生整组的(4)种名蕴这些缘生法，是由于过去的、除去掉举(uddhacca)思之后的(11)种不善业当中某一种缘法的**异刹那业、本性亲依止(pakatūpanissaya)缘力、(2)。**
  - ( 乙 ) 善趣无因结生整组的(4)种名蕴这些缘生法，是由于过去的二因下劣=(低劣的、不与智(ñāṇa)相应的智不相应(ñāṇavippayutta))欲界善业(4)种=(悦(somanassa)有行(sasaṅkhārika)，无行(asaṅkhārika)，舍有行、无行)当中相应的某一种善业缘法的**异刹那业、本性亲依止缘力、(2)。**

由于这(25)种因缘法共同给予助益，它们才得以生起并住立。
