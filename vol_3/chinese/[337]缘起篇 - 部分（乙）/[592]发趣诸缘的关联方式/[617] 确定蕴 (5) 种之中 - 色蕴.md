### 确定(voṭṭhabbana)蕴 (5) 种之中 - 色蕴(rūpakkhandhā)

与确定名蕴(nāmakkhandhā)的生(uppāda)-住(ṭhiti)-坏灭(bhaṅga)刹那(khaṇa)同时并行而生起的那些**转起(pavatti)业生色(kammajarūpa)、时节生色(utujarūpa)、食生色(āhārajarūpa)**，请比照在领受(sampaṭicchana)一节中已经说明过的那些来观照。

**心生色(cittajarūpa)** ---- 由确定名蕴而生起的心生色这些缘生法(paccayuppannadhamma) ----

- 1. 名(nāma)俱生(sahajāta)类 --- 9、
- 2. 色(rūpa)俱生类 --- 5、
- 3. 后生(pacchājāta)类 --- 4、
- 4. 色食(rūpāhāra)类 --- 3、

由于这(21)种因缘法，它们才得以生起并住立。

由确定名蕴而生起的心生色这些缘生法 -----

- 1. (甲) 由于确定(名法 - 12)整组名蕴缘法(paccayadhamma)的**俱生、依止(nissaya)、不相应(vippayutta)、有(atthi)、不离去(avigata)缘力(paccayasatti)，**
  - ( 乙 ) 由于该确定名法组中所包含的思(cetanā)缘法的**俱生业(kamma)缘力，**
  - ( 丙 ) 由于触(phassa)、思、识(viññāṇa)缘法的**食(āhāra)缘力，**
  - (丁) 由于命(jīvita)、心(citta)、受(vedanā)、精进(vīriya)、一境性(ekaggatā) - (5)种名根(indriya)缘法的**根缘力，**
  - ( 戊 ) 由于除喜(pīti)之外的(4)种禅支(jhānaṅga)缘法的**禅那(jhāna)缘力，(9)**。
- 2. 由于同一色聚(kalāpa)内成组的(4)大种(mahābhūta)缘法的 yathāraha = 各自相应地给予助益的**俱生、相互(aññamañña)、依止、有、不离去缘力，(5)**。
- 3. 由于后生 = 随后生起的第一速行(javana)(或者，若确定之后落入有分(bhavaṅga)，则为第一有分)名蕴缘法的**后生、不相应、有、不离去缘力，(4)**。
- 4. 由于同一色聚内以及不同色聚中的四因生食素(catusamuṭṭhānikaojā)缘法的**色食、色食有、色食不离去缘力，(3)**。

由于这(21)种因缘法 = 诸缘力共同给予助益，它们才得以生起并住立。
