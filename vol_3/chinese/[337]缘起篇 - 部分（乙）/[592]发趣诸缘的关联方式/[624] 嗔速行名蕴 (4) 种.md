### 嗔速行(dosajavana) 名蕴(nāmakkhandhā) (4) 种

[嗔(dosa)、嗔+嫉(issā)、嗔+悭(macchariya)、嗔+恶作(kukkucca)，此嗔组的全部都包含在内。 
心(citta)、心所(cetasika)的数量，请依照在名业处(nāmakammaṭṭhāna)表中所书写陈述的那样，适当地计数。]

嗔根二(dosamūladve) 名蕴(4)种这些缘生法(paccayuppannadhamma) ----

- 1. 俱生(sahajāta)类 --- 13、
- 2. 所缘(ārammaṇa)类 --- 4、(担任主导(adhipati)作用时 - 5)
- 3. 无间(anantara)类 --- 5、(若加入重复(āsevana)则 - 6)
- 4. 依处(vatthu)类 --- 5、
- 5. 本性亲依止(pakatūpanissaya) --- 1、

由于这(28)种因缘(paccaya)法，它们才得以生起并住立。

嗔根二第一速行(paṭhamajavana)各个部分的(4)种名蕴这些缘生法 -----

- 1. (甲) 由于能够相互给予助益的嗔根(dosamūla)各个部分的名蕴缘法(paccayadhamma)的**俱生、相互(aññamañña)、依止(nissaya)、相应(sampayutta)、有(atthi)、不离去(avigata)缘力(paccayasatti)，(6)。**
  - ( 乙 ) 由于能够给予相应诸蕴助益的、嗔根名蕴中所包含的嗔、痴(moha) ----- 这(2)种因(hetu)缘法的**因缘力，**
  - ( 丙 ) 由于欲(chanda)、精进(vīriya)、心 ----- (3)种主导法自体当中任何一种缘法的**主导缘力。**
  - (丁) 由于思(cetanā)缘法的**俱生业(kamma)缘力**，
  - ( 戊 ) 由于触(phassa)、思、识(viññāṇa) - (3)种名(nāma)食(āhāra)缘法的**食缘力，**
  - ( 己 ) 由于命(jīvita)、心、受(vedanā)、精进、一境性(ekaggatā) - (5)种名根(indriya)缘法的**根缘力，**
  - (庚) 由于除去喜(pīti)的(4)支禅支(jhānaṅga)缘法的**禅那(jhāna)缘力，**
  - ( 辛 ) 由于寻(vitakka)、精进、一境性(3)支道支(maggaṅga)缘法的**道(magga)缘力，(13)**。
- 2. 一般而言能够取所缘的嗔根(4)种名蕴这些缘生法，是由于一般而言所应取的现在色所缘(声所缘……乃至……触所缘)缘法的**所缘、前生(purejāta)、有、不离去缘力，(4)**。 
(担任主导作用时若加入主导缘 - 5。)
- 3. 嗔根第一速行(4)种名蕴这些缘生法，是由于无有间隔而已经灭去的确定(voṭṭhabbana)名蕴缘法的**无间、等无间(samanantara)、强依止(upanissaya)、无有(natthi)、离去(vigata)缘力，** (5)。

[从第二速行开始直到第七速行都能获得**重复缘**，因此在第二速行等当中若再加上重复缘，则成为(6)种缘。]

- 4. 由于与确定名蕴的生起的刹那(uppādakkhaṇa)同时并起而生起的心所依处(hadayavatthu)，(临终(maraṇāsanna)时从死殁心(cuti)往回数，则是与第(17)个心的生起的刹那同时并起而生起的**心所依处**)缘法的**依止、前生、不相应(vippayutta)、有、不离去缘力，(5)**。

[第二速行名蕴依止第一速行的 ……乃至…… 第七速行名蕴依止第六速行的、与生起的刹那同时并起而生起的心所依处，它们各自如此依止。]

- 5. 由于成为有力(balava)的 = 强而有力的世间的(lokiya)心(81)，心所(52)，色(28)，以及应当成为缘的某些概念(paññatti)等缘法的**本性亲依止缘力，(1)**。

由于这(28)种[若是第二速行……乃至……第七速行名蕴，则是(29)种]因缘法共同给予助益，它们才得以生起并住立。
