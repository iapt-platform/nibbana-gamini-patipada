### 无色(arūpa)结生(paṭisandhi)名蕴(nāmakkhandhā) (4)种

无色结生(4)种，除去远离(virati)、无量(appamaññā)、寻(vitakka)、伺(vicāra)、喜(pīti)的心所(cetasika)三十(= 30)个，各各-
部分的名蕴这些缘生法(paccayuppannadhamma) ----

- 1. 俱生(sahajāta)类 --- 13、
- 2. 所缘(ārammaṇa)类 --- 1、
- 3. 无间(anantara)类 --- 5、
- 4. 异刹那业(nānākkhaṇikakamma)类 --- 2、

由于这(21)种因缘(paccaya)法，它们才得以生起并住立。

无色结生(4)种，除去远离、无量、寻、伺、喜的心所三十(30)个，各各部分的名蕴这些缘生法 ----

- 1. (甲) 由于能够相互给予助益的无色结生(4)种(观照时请分开观照。)、除去远离、无量、寻、伺、喜的心所三十(30)个，各各部分的名蕴这些缘法的**俱生、相互(aññamañña)、依止(nissaya)、果报(vipāka)、相应(sampayutta)、有(atthi)、不离去(avigata)缘力，**
  - ( 乙 ) 由于相应的无色结生中所包含的无贪(alobha)、无嗔(adosa)、无痴(amoha) - 这(3)种因(hetu)缘法的**因缘力，**
  - ( 丙 ) 由于思(cetanā)缘法的**俱生业(kamma)缘力，**
  - (丁) 由于触(phassa)、思、识(viññāṇa)这(3)种名食(āhāra)缘法的**食缘力，**
  - ( 戊 ) 由于(8)种名根(indriya)缘法的**根缘力，**
  - ( 己 ) 由于舍(upekkhā)、一境性(ekaggatā)这(2)种禅支(jhānaṅga)缘法的**禅那(jhāna)缘力，**
  - (庚) 由于慧(paññā)、精进(vīriya)、念(sati)、一境性这(4)种道支(maggaṅga)缘法的**道(magga)缘力、(13)。**
- 2. (甲) 若是空无边处(ākāsānañcāyatana)结生，则是在除去空遍(ākāsakasiṇa)之外的(9)种遍(kasiṇa)当中，移开某一种遍而得到的虚空概念(paññatti)业相(kammanimitta)、
  - ( 乙 ) 若是识无边处(viññāṇañcāyatana)结生，则是称为过去的空无边处善的广大(mahaggata)业相、
  - ( 丙 ) 若是无所有处(ākiñcaññāyatana)结生，则是空无边处禅那的不存在，即无有概念(natthibhāvapaññatti)业相、
  - (丁) 若是非想非非想处(nevasaññānāsaññāyatana)结生，则是称为过去的无所有处善的广大业相，由于这些缘法的**所缘缘力、(1)。**
- 3. (甲) 若是空无边处结生，则是(9)种五蕴有(pañcavokāra)三因(tihetuka)死心(cuti)、空无边处死心、
  - ( 乙 ) 若是识无边处结生，则是(9)种五蕴有三因死心、空无边处死心、识无边处死心、
  - ( 丙 ) 若是无所有处结生，则是(9)种五蕴有三因死心、空无边处死心、识无边处死心、无所有处死心、
  - (丁) 若是非想非非想处结生，则是十三 = (13)种三因死心名蕴，由于这些缘法的**无间、等无间(samanantara)、强依止(upanissaya)、无有(natthi)、离去(vigata)缘力、(5)**。(只挑选曾经发生过的某一种死心来观照。)
- 4. 由于过去的无色善业(相应的无色善业)(4)种缘法的**异刹那业、本性亲依止(pakatūpanissaya)缘力、(2)。**

由于这(21)种因缘法共同给予助益，它们才得以生起并住立。
