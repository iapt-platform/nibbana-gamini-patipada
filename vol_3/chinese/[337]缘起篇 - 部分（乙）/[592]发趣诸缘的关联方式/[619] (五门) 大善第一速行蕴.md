### (五门(pañcadvārika))大善(mahākusala)第一速行(javana)蕴(khandhā) (5) 种 大善第一速行 - 色蕴(rūpakkhandhā)

与大善第一速行名蕴(nāmakkhandhā)的生(uppāda)-住(ṭhiti)-坏灭(bhaṅga)刹那(khaṇa)同时并行而生起的那些**转起(pavatti)业生色(kammajarūpa)、时节生色(utujarūpa)、食生色(āhārajarūpa)**，请照上面已经说明过的那样去观照。

**心生色(cittajarūpa)** ----- 由大善第一速行而生起的心生色这些缘生法(paccayuppannadhamma) -----

- 1. 名(nāma)俱生(sahajāta)类 --- 12、
- 2. 色(rūpa)俱生类 --- 5、
- 3. 后生(pacchājāta)类 --- 4、
- 4. 色食(rūpāhāra)类 --- 3、

由于这(24)种因缘法，它们才得以生起并住立。

- 1. (甲) 由大善第一速行而生起的心生色这些缘生法，是由于大善第一速行(34、33、33、32)整组名蕴缘法(paccayadhamma)的**俱生、依止(nissaya)、不相应(vippayutta)、有(atthi)、不离去(avigata)缘力(satti)，**
  - ( 乙 ) 若是由二因(dvihetuka)大善速行心所生起的心生色 ---- 该二因大善名法之聚(33、32)中所含的无贪(alobha)、无嗔(adosa)，若是由三因(tihetuka)大善速行心所生起的心生色 ---- 该三因大善名法之聚(34、33)中所含的无贪、无嗔、无痴(amoha) ---- 由于这(2)种、(3)种因(hetu)缘法的**因缘力，**
  - ( 丙 ) 若是由二因大善速行心所生起的心生色 ---- 该二因大善名法之聚中所含的欲(chanda)、精进(vīriya)、心(citta)，若是由三因大善速行心所生起的心生色 ---- 该三因大善名法之聚中所含的欲、精进、心、思维(vīmaṃsā) ----- 由于这称为主导(adhipati)法体的(3)种、(4)种当中任何一种缘法的**主导缘力，**
  - (丁) 由于该大善第一速行名法之聚中所含的思(cetanā)缘法的**俱生业(kamma)缘力，**
  - ( 戊 ) 由于触(phassa)、思、识(viññāṇa)缘法的**食(āhāra)缘力，**
  - ( 己 ) 若是由二因大善速行心所生起的心生色 ---- 除慧(paññā)之外的名根(indriya)(7)种，若是由三因大善速行心所生起的心生色 ---- 名根(8)种，由于这些缘法的**根缘力，**
  - (庚) 若是由与悦(somanassa)俱的大善速行心所生起的心生色 ---- 禅支(jhānaṅga)(5)种，若是由与舍(upekkhā)俱的大善速行心所生起的心生色 ---- 除喜(pīti)之外的禅支(4)种，由于这些缘法的**禅那(jhāna)缘力，**
  - ( 辛 ) 若是由二因大善速行心所生起的心生色 --- 寻(vitakka)、精进、念(sati)、一境性(ekaggatā) - 道支(maggaṅga)(4)种，若是由三因大善速行心所生起的心生色 ---- 慧、寻、精进、念、一境性 - 道支(5)种，由于这些缘法的**道(magga)缘力，(12)**。
- 2. 由于同一色聚(kalāpa)内整组的大种(mahābhūta)(4)种缘法的 yathāraha = 随其适宜的**俱生、相互(aññamañña)、依止、有、不离去缘力，(5)**。
- 3. 由于后生 = 随后生起的大善第二速行名蕴缘法的**后生、不相应、有、不离去缘力，(4)**。

[若是由第二速行心所生起的心生色 ----- 后生为第三速行。 
若是由第三速行心所生起的心生色 ----- 后生为第四速行。若是由第四速行心所生起的心生色 - 后生为第五速行。 
若是由第五速行心所生起的心生色 ----- 后生为第六速行。 
若是由第六速行心所生起的心生色 ----- 后生为第七速行。 
若是由第七速行心所生起的心生色 ----- 由于后生的第一彼所缘(tadārammaṇa)名蕴缘法的后生、不相应、有、不离去缘力。
请依此类推地领会。 
在每一处都请以同样的方式记取。]

- 4. 由于同一色聚内以及不同色聚中的四因生食素(catusamuṭṭhānikaojā)缘法的**色食、色食有、色食不离去缘力，(3)**。

由于这(24)种因缘法共同围绕着给予助益，它们才得以生起并住立。
