### 意门(manodvārika) 大善(mahākusala) 第一速行(paṭhamajavana) 名蕴(nāmakkhandhā) (4) 种

(大善第一速行色蕴(rūpakkhandhā)、第二速行色蕴等等，与五门(pañcadvārika)大善第一速行色蕴、第二速行色蕴等等相同。)

大善第一速行的(4)种名蕴这些缘生法(paccayuppannadhamma) -----

- 1. 俱生(sahajāta)类 --- 13、
- 2. 所缘(ārammaṇa)类 --- 1、4、6、3、
- 3. 无间(anantara)类 --- 5、
- 4. 依处(vatthu)类 --- 5、
- 5. 本性亲依止(pakatūpanissaya) --- 1、

有时由于这(25)种，有时(28)种，有时(30)种，有时(27)种因缘(paccaya)法，它们才得以生起并住立。

大善第一速行各个部分的(4)种名蕴这些缘生法 -----

- 1. (甲) 由于能够相互给予助益的大善第一速行各个部分的名蕴缘法(paccayadhamma)的**俱生、相互(aññamañña)、依止(nissaya)、相应(sampayutta)、有(atthi)、不离去(avigata)缘力(satti)，**
  - ( 乙 ) 由于能够给予相应诸蕴助益的、大善第一速行名蕴中所包含的——若是二因(dvihetuka)善(kusala)(4)个 ----- 无贪(alobha)、无嗔(adosa)；若是三因(tihetuka)善(4)个 ----- 无贪、无嗔、无痴(amoha) ----- 这(2)种、(3)种因(hetu)缘法的**因缘力，**
  - ( 丙 ) 若是二因善(4)个 ----- 欲(chanda)、精进(vīriya)、心(citta)；若是三因善(4)个 ----- 欲、精进、心、思维(vīmaṃsā)，由于这(3)种、(4)种当中任何一种缘法的**主导(adhipati)缘力，**
  - (丁) 由于思(cetanā)缘法的**俱生业(kamma)缘力，**
  - ( 戊 ) 由于触(phassa)、思、识(viññāṇa)这(3)种名(nāma)食(āhāra)缘法的**食缘力，**
  - ( 己 ) 若是二因善(4)个 ---- 除去慧(paññā)的(7)种名根(indriya)；若是三因善(4)个 - 命(jīvita)、心、受(vedanā)、信(saddhā)、精进、念(sati)、一境性(ekaggatā)、慧 - (8)种名根，由于这些缘法的**根缘力，**
  - (庚) 若是悦(somanassa)俱的第一速行 ----- (5)支禅支(jhānaṅga)；若是舍(upekkhā)俱的第一速行 ----- 除去喜(pīti)的(4)支禅支，由于这些缘法的**禅那(jhāna)缘力，**
  - ( 辛 ) 若是二因大善第一速行 ----- 除去慧的(7)支道支(maggaṅga)；若是三因大善第一速行 --- 慧、寻(vitakka)、正语(sammāvācā)、正业(sammākammanta)、正命(sammāājīva)、精进、念、一境性 - (8)支道支，由于这些缘法的**道(magga)缘力，(13)。**
- 2. 一般而言能够取所缘的大善智不相应(ñāṇavippayutta)第一速行的(4)种名蕴这些缘生法 -----
  - (甲) 有时一般而言所应取的世间(lokiya)心(81)、心所(52)、属于过去与未来的完成色(nipphannarūpa)(18)、属于过去、未来、现在三时的非完成色(anipphannarūpa)(10)、概念(paññatti)，由于这(6)种所缘当中某一种所缘缘法的**所缘缘力，(1)。**
  - ( 乙 ) 有时一般而言所应取的现在的完成色(18) ----- 由于这(6)种所缘当中某一种所缘缘法的**所缘、前生(purejāta)、有、不离去缘力，(4)。**
  - ( 丙 ) 由于临终(maraṇāsanna)时一般而言所应取的、与从死心(cuti)往回数则为第(17)个的那个心的生刹那(uppādakkhaṇa)同时并起而生起的心所依处(hadayavatthu)缘法的**所缘、依止、前生、不相应(vippayutta)、有、不离去缘力，(6)。**

一般而言能够取所缘的大善智相应(ñāṇasampayutta)第一速行的(4)种名蕴这些缘生法 -----

- (甲) 有时一般而言所应取的、除去阿拉汉(arahant)道(magga)与阿拉汉果(phala)的心(87)、心所(52)、属于过去与未来的完成色(18)、属于过去、未来、现在三时的非完成色(10)、概念 ----- 由于这(6)种所缘当中某一种所缘缘法的**所缘缘力，(1)。**
  - ( 乙 ) 有时一般而言所应取的现在的完成色(18)缘法的**所缘、前生、有、不离去缘力，(4)。**
  - ( 丙 ) 由于临终时一般而言所应取的、与从死心往回数则为第(17)个的那个心的生刹那同时并起而生起的心所依处缘法的**所缘、依止、前生、不相应、有、不离去缘力，(6)。**

以珍重的方式能够取所缘的大善智不相应第一速行的(4)种名蕴这些缘生法，是由于以珍重的方式所应取的(17)种世间善的名蕴法所缘缘法的**所缘、主导、强依止(upanissaya)缘力，(3)。**

以**珍重**的方式能够取所缘的大善智相应第一速行的(4)种名蕴这些缘生法 ----- 由于以珍重的方式所应取的、除去阿拉汉道的善心(20)、下面的(3)个果、涅槃(nibbāna) ----- 这些法所缘缘法的**所缘、主导、强依止缘力，(3)。**

- 3. 欲界(kāmāvacara)大善第一速行的(4)种名蕴这些缘生法 ----- 是由于中间没有其他(心)相隔而已经灭去的意门转向(manodvārāvajjana)的(4)种名蕴缘法的**无间、等无间(samanantara)、强依止、无有(natthi)、离去(vigata)缘力，(5)。**

[第二速行的(4)种名蕴这些缘生法，是由于中间没有其他(心)相隔而已经灭去的第一速行名蕴缘法的**无间、等无间、强依止、重复(āsevana)、无有、离去缘力，(6)**。请如此领会：乃至第七速行，都同样能够获得前前速行以重复缘力所给予的助益。]

- 4. 欲界大善第一速行的(4)种名蕴这些缘生法 ----- 是由于与意门转向名蕴的生刹那同时并起而生起的心所依处缘法的**依止、前生、不相应、有、不离去缘力，(5)。**

- 5. 大善第一速行的(4)种名蕴这些缘生法 ----- 是由于成为有力(balava)的 = 强而有力的、除去阿拉汉道与阿拉汉果的心(87)、心所(52)、色(28)，以及应当成为缘的某些概念等缘法的**本性亲依止缘力，(1)。**

有时由于这(25)种、有时(28)种、有时(30)种、有时在获得主导缘之时的(27)种因缘法共同围绕着给予助益，它们才得以生起并住立。
[如果缘生法是第二速行……乃至……第七速行的大善名蕴 ----- 则在无间类中再加上重复缘，就能获得有时(26)种、有时(29)种、有时(31)种、有时在获得主导缘之时(28)种的缘法。]
