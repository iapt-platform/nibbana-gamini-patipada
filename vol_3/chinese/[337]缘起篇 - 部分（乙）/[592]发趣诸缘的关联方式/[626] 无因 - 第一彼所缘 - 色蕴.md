**无因(ahetuka) 第一彼所缘(tadārammaṇa) 蕴 (5) 种之中**
### 无因 第一彼所缘 色蕴(rūpakkhandhā)

与无因第一彼所缘名蕴(nāmakkhandhā)的生(uppāda)-住(ṭhiti)-坏灭(bhaṅga)刹那(khaṇa)同时并行而生起的那些**转起(pavatti)业生色(kammajarūpa)、时节生色(utujarūpa)、食生色(āhārajarūpa)**，请照前面已经说明过的那样去记取、去观照。 
在此陈述稍有不同的、由无因第一彼所缘心而生起的心生色中发趣诸缘的关联方式。

**心生色(cittajarūpa)** ----- 由无因第一彼所缘心而生起的心生色这些缘生法(paccayuppannadhamma) -----

- 1. 名(nāma)俱生(sahajāta)类 --- 10、
- 2. 色(rūpa)俱生类 --- 5、
- 3. 后生(pacchājāta)类 --- 4、
- 4. 色食(rūpāhāra)类 --- 3、

由于这(22)种因缘法，它们才得以生起并住立。

由无因第一彼所缘心而生起的心生色这些缘生法 -----

- 1. (甲) 由于无因第一彼所缘整组名蕴缘法(paccayadhamma)的**俱生、依止(nissaya)、果报(vipāka)、不相应(vippayutta)、有(atthi)、不离去(avigata)缘力(paccayasatti)，**
  - ( 乙 ) 由于该彼所缘名法组中所包含的思(cetanā)缘法的**俱生业(kamma)缘力**，
  - ( 丙 ) 由于触(phassa)、思、识(viññāṇa)缘法的**食(āhāra)缘力，**
  - (丁) 由于命(jīvita)、心(citta)、受(vedanā) - (3)种名根(indriya)缘法的**根缘力，**
  - ( 戊 ) 若是由与悦(somanassa)俱的无因第一彼所缘心而生起的心生色 ----- 禅支(jhānaṅga)(5)种，若是由与舍(upekkhā)俱的无因第一彼所缘心而生起的心生色 ----- 除喜(pīti)之外的禅支(4)种，由于这些缘法的**禅那(jhāna)缘力，(10)**。
- 2. 由于同一色聚(kalāpa)内成组的(心生)大种(mahābhūta)(4)种缘法的 yathāraha = 随其适宜的**俱生、相互(aññamañña)、依止、有、不离去缘力，(5)。**
- 3. 由于后生 = 随后生起的无因第二彼所缘名蕴(4)种缘法的**后生、不相应、有、不离去缘力，(4)。**
- 4. 由于同一色聚内以及不同色聚中的四因生食素(catusamuṭṭhānikaojā)缘法的**色食、色食有、色食不离去缘力，(3)。**

由于这(22)种因缘法共同围绕着给予助益，它们才得以生起并住立。

[**注** ----- 若是由无因第二彼所缘名蕴而生起的心生色，在后生类中，则是后生的第一有分(bhavaṅga)名蕴缘法的后生、不相应、有、不离去缘力 - 仅此一点不同，其余全部与由第一彼所缘名蕴而生起的心生色相同。]
