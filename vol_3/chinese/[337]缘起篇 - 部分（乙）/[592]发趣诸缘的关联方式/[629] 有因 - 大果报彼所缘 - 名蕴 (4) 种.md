### 有因(sahetuka) 大果报(mahāvipāka) 彼所缘(tadārammaṇa) - 名蕴(nāmakkhandhā) (4) 种

有因大果报彼所缘的(4)种名蕴这些缘生法(paccayuppannadhamma) -----

- 1. 俱生(sahajāta)类 --- 13、
- 2. 所缘(ārammaṇa)类 --- 4、
- 3. 无间(anantara)类 --- 5、
- 4. 依处(vatthu)类 --- 5、
- 5. 异刹那业(nānākkhaṇikakamma)类 --- 2、
- 6. 本性亲依止(pakatūpanissaya) --- 1、

由于这(30)种因缘法，它们才得以生起并住立。

大果报彼所缘各个部分的(4)种名蕴这些缘生法 -----

- 1. (甲) 由于能够相互给予助益的大果报彼所缘各个部分的名蕴缘法的**俱生、相互(aññamañña)、依止(nissaya)、果报(vipāka)、相应(sampayutta)、有(atthi)、不离去(avigata)缘力(paccayasatti)，**
  - ( 乙 ) 由于能够给予相应诸蕴助益的、那大果报彼所缘名蕴中所包含的 ----- 若是二因(dvihetuka)彼所缘，则为无贪(alobha)、无嗔(adosa)；若是三因(tihetuka)彼所缘，则为无贪、无嗔、无痴(amoha) ----- 这(2)种，(3)种因(hetu)缘法的**因缘力，**
  - ( 丙 ) 由于思(cetanā)缘法的**俱生业(kamma)缘力，**
  - (丁) 由于触(phassa)、思、识(viññāṇa) - (3)种名食(āhāra)缘法的**食缘力，**
  - ( 戊 ) 若是二因彼所缘，则为除去慧(paññā)的(7)种名根(indriya)；若是三因彼所缘，则为命(jīvita)、心(citta)、受(vedanā)、信(saddhā)、精进(vīriya)、念(sati)、一境性(ekaggatā)、慧 ----- (8)种名根，由于这些缘法的**根缘力，**
  - ( 己 ) 若是悦(somanassa)彼所缘，则为(5)支禅支(jhānaṅga)；若是舍(upekkhā)彼所缘，则为除去喜(pīti)的(4)支禅支，由于这些缘法的**禅那(jhāna)缘力，**
  - (庚) 若是二因彼所缘，则为寻(vitakka)、精进、念、一境性 - (4)支道支(maggaṅga)；若是三因彼所缘，则为慧、寻、精进、念、一境性 - (5)支道支，由于这些缘法的**道(magga)缘力，(13)**。
- 2. 一般而言能够取所缘的有因第一彼所缘的(4)种名蕴这些缘生法，是由于一般而言所应取的现在(paccuppanna)色所缘(声所缘……乃至……触所缘)缘法的**所缘、前生(purejāta)、有、不离去缘力，(4)。**
- 3. 有因第一彼所缘的(4)种名蕴这些缘生法，是由于中间没有其他(心)相隔而已经灭去的第七速行(javana)名蕴缘法的(若是第二彼所缘，则是由于中间没有其他(心)相隔而已经灭去的第一彼所缘名蕴缘法的)**无间、等无间(samanantara)、强依止(upanissaya)、无有(natthi)、离去(vigata)缘力，(5)。**
- 4. 由于与第七速行名蕴的生起的刹那(uppādakkhaṇa)同时并起而生起的心所依处(hadayavatthu)(若是第二彼所缘，则为与第一彼所缘的生起的刹那同时并起而生起的心所依处)这些缘法的**依止、前生、不相应(vippayutta)、有、不离去缘力，(5)。**
- 5. 由于相应的某一种过去的欲界善业(kāmakusalakamma)缘法的**异刹那业、本性亲依止缘力，(2)。**
- 6. 由于成为有力(balava)的 = 强而有力的心(89)，心所(52)，色(28)，以及应当成为缘的某些概念(paññatti)等缘法的**本性亲依止缘力，(1)。**

由于这(30)种因缘法的诸缘力共同围绕着给予助益，它们才得以生起并住立。
