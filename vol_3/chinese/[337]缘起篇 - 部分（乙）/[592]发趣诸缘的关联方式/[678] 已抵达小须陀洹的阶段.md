### 已抵达小须陀洹(cūḷasotāpanna)的阶段

Iminā pana ñāṇena samannāgato vipassako buddhasāsane laddhassāso laddhapatiṭṭho niyatagatiko cūḷasotāpanno nāma hoti.（清净道论,2,240。）

具足上面所说的如实智(yathābhūtañāṇa)、并且正在勤奋不懈地努力修习观(vipassanā)禅修业处(kammaṭṭhāna)的瑜伽行者(yogāvacara)善人，在一切知正等觉佛陀(Buddha)的教法(sāsana)之中，成为拥有已获得的安稳者、拥有已获得的立足处者、拥有决定的善趣(sugati)者，因此便称为小须陀洹 = 小小的须陀洹(sotāpanna)。（清净道论,2,240。）

若依不颠倒、真实无误的意义 —— 即究竟谛(paramatthasacca)来说，在佛陀的教法之中，安稳(assāsa) = 安乐之处，指的就是圣果(ariyaphala)法。 
立足处(patiṭṭhā) = 依靠安立之处，指的就是圣道(ariya magga)法。 
这位瑜伽行者虽然还未获得圣道圣果，但由于他已安住于作为获得那圣道圣果之因的行持与道迹(paṭipatti)之中，所以他就如同已经获得了安稳一样，也如同已经获得了立足处一样。因此才说他是 laddhassāsa = 拥有已获得的安稳者，laddhapatiṭṭha = 拥有已获得的立足处者。 
拥有毫不欠缺的度疑清净智(kaṅkhāvitaraṇavisuddhiñāṇa)之知见、并且正在努力修习观禅修业处的观行者(vipassaka)瑜伽行者，由于圆满具足了戒具足(sīlasampadā) = 戒(sīla)的圆满、定具足(samādhisampadā) = 定(samādhi)的圆满、慧具足(paññāsampadā) = 慧(paññā)的圆满，所以即使他还未能通达证知上位的殊胜圣法，也因为他的去处唯有善趣，才被解释为**决定趣(niyatagatika)** = 拥有决定的善趣者。 
也正因如此，他才称为小须陀洹 = 小小的须陀洹。 
的确如此 —— 应当知道：须陀洹圣者由于已用圣道法断除了一切会导致堕入恶趣(apāya)的烦恼(kilesa)，所以那些会导致堕入恶趣、恶生(duggati)的法已经灭尽；他没有堕落恶趣的可能，也没有溃散崩坏而堕落的可能；他的恶趣、恶生、堕处(vinipāta)这一大灾祸已经灭尽。（大义疏,2,385。）

**另一种说法** --- 由于他对色法与名法的智见已经清净到能够抵达究竟法(paramattha)的程度，所以这位瑜伽行者已经很好地获得了见清净(diṭṭhivisuddhi)的智见。 
由于这样很好地获得了见清净的智见，所以他是**laddhassāsa** = 在教法之中拥有已获得的安稳者。 
的确如此：借助能够清楚分别名色的名色分别智(nāmarūpaparicchedañāṇa)，他能够依照蕴(khandha)-处(āyatana)-界(dhātu)等究竟法各自真实无误的自身本质(sabhāva)特相(lakkhaṇa)、各自真实无误的自身作用与职责，好好地分别并记取这些法 = 也就是能够依照特相-作用(rasa)-现起(paccupaṭṭhāna)-近因(padaṭṭhāna)的方法，用智慧好好地把每一种色、名究竟法的成分研磨透彻；由此他在一切知正等觉佛陀的教法之中获得了与法相关的欣慰喜悦 = 喜(pīti)与悦(pāmojja)之法，所以他是**laddhassāsa** = 拥有已获得的安稳者。

由于很好地获得了**度疑清净智**，所以他是**laddhapatiṭṭha** = 在教法之中拥有已获得的立足处者。 
的确如此 --- 由于常见(sassata)、断见(uccheda)等邪见(micchādiṭṭhi)的荆棘已被那能够观照、能够通达了知连同因法在内的名色的智慧所镇伏碾碎，由于无因论(ahetuvāda) = 主张没有原因的学说、错因论(visamahetuvāda) = 主张有造物主等不相符原因的学说已被排除（= 由于那能够观照、能够通达了知连同因法在内的名色的智慧，已经把常见、断见等邪见的荆棘与绊脚石镇伏碾碎，并且已经把承认没有原因的 = 无因论、承认造物主等不相符原因的 = 错因论排除拔除干净）--- 由于他安住于如实了知：一切都只不过是由各自所属的、相应的无明(avijjā)-爱(taṇhā)-取(upādāna)-行(saṅkhāra)-业(kamma)等因法而生起的究竟法自性而已，因此这位在佛陀的教法之中拥有牢牢扎根、无法与教法分离的坚固信(saddhā)之法的人，就称为**laddhapatiṭṭha** = 拥有已获得的立足处者。（大义疏,2,385。）

他以能够分别记取名色的**名色差别智(nāmarūpavavatthānañāṇa)**通达苦谛(dukkhasacca)，以**法住智(dhammaṭṭhitiñāṇa)**通达集谛(samudayasacca)，又以那法住智之后分阶段的(观)智，即以观照名为苦谛、集谛的诸行法生起之后随即坏灭的性质并作意为无常(anicca)等的次第，来通达道谛(magga sacca)；他以这样殊胜的智慧（= 以名为法住的观智）通达了知之后，由于因法不断地生起，果报色法名法也就不断地生起——他了知了这不断生起的名色相续流的苦的实况之后，对于那作为不断生起的名色相续流之出离处的、由于因法的息灭而使果报名色相续流也息灭的所谓灭谛(nirodhasacca)（这将在生灭智的部分中显明），实实在在地拥有倾向、趣向于它的意欲与倾向(ajjhāsaya)之性；由于他仅仅以世间的观智就已经获得、已经了知了四圣谛(ariyasacca)，所以他既没有会投生到四恶趣地的可能，也就有了投生于须陀洹阶位的可能。 
因此才被解释为**决定趣**。 
也正因如此，他才得以称为**小须陀洹**。（大义疏,2,385。）

因此，在这教法之中，为了自己的、也为了他人的、直到道智果智与涅槃(nibbāna)为止的利益与福祉，也为了安乐幸福而正在修习努力的有智慧的善人，应当舍下除了以正见(sammādiṭṭhi)之智慧亲自现证通达因果关联 = 缘起(paṭiccasamuppāda)之法以外的其余一切事务；在名为缘行相(paccayākāra)的、极为深奥的因果关联即缘起法的种种差别之上，以怎样的方式努力修习才能凭智慧获得立足之处，就应当以那样的方式，具足念(sati)，具足慧眼与正知(sampajañña)之智，时时刻刻、一再地精勤努力。（阿毗达摩义注,2,189。清净道论,2,221。）
