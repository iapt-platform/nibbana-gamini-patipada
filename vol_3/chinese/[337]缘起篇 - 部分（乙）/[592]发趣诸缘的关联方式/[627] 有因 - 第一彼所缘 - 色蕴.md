### 有因(sahetuka) - 第一彼所缘(tadārammaṇa) - 色蕴(rūpakkhandhā)

在此接下来要写出并陈述有因彼所缘的色蕴。
所谓有因彼所缘，就是大果报(mahāvipāka)彼所缘(34、33、33、32)。
与有因第一彼所缘名蕴(nāmakkhandhā)的生(uppāda)-住(ṭhiti)-坏灭(bhaṅga)刹那同时并行而生起的那些转起(pavatti)业生色(kammajarūpa)、时节生色(utujarūpa)、食生色(āhārajarūpa)，请照已经说明过的那样去记取、去观照。

**心生色(cittajarūpa)** ----- 由有因第一彼所缘名蕴而生起的心生色这些缘生法(paccayuppannadhamma) -

- 1. 名(nāma)俱生(sahajāta)类 --- 12、
- 2. 色(rūpa)俱生类 --- 5、
- 3. 后生(pacchājāta)类 --- 4、
- 4. 色食(rūpāhāra)类 --- 3、

由于这(24)种因缘法，它们才得以生起并住立。

由有因第一彼所缘名蕴而生起的心生色这些缘生法 -----

- 1. (甲) 由于有因第一彼所缘整组名蕴缘法(paccayadhamma)的**俱生、依止(nissaya)、果报(vipāka)、不相应(vippayutta)、有(atthi)、不离去(avigata)缘力(satti)，**
  - ( 乙 ) 若是由二因(dvihetuka)彼所缘名蕴而生起的心生色 ----- 无贪(alobha)、无嗔(adosa)，若是由三因(tihetuka)彼所缘名蕴而生起的心生色 ----- 无贪、无嗔、无痴(amoha)，由于这(2)种、(3)种因(hetu)缘法的**因缘力，**
  - ( 丙 ) 由于该第一彼所缘名法之聚中所含的思(cetanā)缘法的**俱生业(kamma)缘力，**
  - (丁) 由于触(phassa)、思、识(viññāṇa)缘法的**食(āhāra)缘力，**
  - ( 戊 ) 若是由二因彼所缘名蕴而生起的心生色 ----- 除慧(paññā)之外的名根(indriya)(7)种，若是由三因彼所缘名蕴而生起的心生色 ----- 名根(8)种，由于这些缘法的**根缘力，**
  - ( 己 ) 若是由与悦(somanassa)俱的彼所缘名蕴而生起的心生色 ----- 禅支(jhānaṅga)(5)种，若是由与舍(upekkhā)俱的彼所缘名蕴而生起的心生色 ----- 除喜(pīti)之外的禅支(4)种，由于这些缘法的**禅那(jhāna)缘力，**
  - (庚) 若是由二因第一彼所缘名蕴而生起的心生色 ----- 寻(vitakka)、精进(vīriya)、念(sati)、一境性(ekaggatā) - 道支(maggaṅga)(4)种，若是由三因第一彼所缘名蕴而生起的心生色 ---- 慧、寻、精进、念、一境性 ----- 道支(5)种，由于这些缘法的道(magga)缘力，(12)。
- 2. 由于同一色聚(kalāpa)内整组的(心生)大种(mahābhūta)(4)种缘法的 yathāraha = 随其适宜的**俱生、相互(aññamañña)、依止、有、不离去缘力，(5)。**
- 3. 由于后生 = 随后生起的有因第二彼所缘名蕴(4)种缘法的**后生、不相应、有、不离去缘力，(4)。**
- 4. 由于同一色聚内以及不同色聚中的四因生食素(catusamuṭṭhānikaojā)缘法的**色食、色食有、色食不离去缘力，(3)。**

由于这(24)种因缘法共同围绕着给予助益，那些由有因第一彼所缘名蕴而生起的心生色缘生法才得以生起并住立。
(至于由第二彼所缘名蕴而生起的心生色中诸缘的关联方式，请依此类推地去观照。)
