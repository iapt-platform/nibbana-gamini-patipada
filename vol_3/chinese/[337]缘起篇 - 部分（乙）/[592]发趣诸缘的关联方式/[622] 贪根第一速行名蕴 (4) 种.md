### 贪根(lobhamūla) 第一速行(paṭhamajavana) 名蕴(nāmakkhandhā) (4) 种

[关于色蕴(rūpakkhandha)的观照段落，依循善(kusala)色蕴的观照段落就足以了知了。 
此处继续书写陈述在诸不善(akusala)速行(javana)中发趣诸缘(paṭṭhānapaccaya)的关联方式。]

(8)个贪根心(citta)的(4)种名蕴这些缘生法(paccayuppannadhamma) -----

- 1. 俱生(sahajāta)类 --- 13、
- 2. 所缘(ārammaṇa)类 --- 4、或 - 6、
- 3. 无间(anantara)类 --- 5、
- 4. 依处(vatthu)类 --- 5、
- 5. 本性亲依止(pakatūpanissaya) --- 1、

由于这(28)种或(30)种缘(paccaya)法，它们才得以生起并住立。

贪根第一速行各个部分的(4)种名蕴这些缘生法 ----

- 1. (甲) 由于能够相互给予助益的贪根第一速行各个部分的名蕴缘法(paccayadhamma)的**俱生、相互(aññamañña)、依止(nissaya)、相应(sampayutta)、有(atthi)、不离去(avigata)缘力(paccayasatti)，(6)**。
  - ( 乙 ) 由于能够给予相应诸蕴助益的、(8)个贪根心第一速行名蕴中所包含的贪(lobha)、痴(moha) ----- 这(2)种因(hetu)缘法的**因缘力，**
  - ( 丙 ) 由于欲(chanda)、精进(vīriya)、心(3)种当中任何一种缘法的**主导(adhipati)缘力，**
  - (丁) 由于思(cetanā)缘法的**俱生业(kamma)缘力，**
  - ( 戊 ) 由于触(phassa)、思、识(viññāṇa) - (3)种名(nāma)食(āhāra)缘法的**食缘力，**
  - ( 己 ) 由于命(jīvita)、心、受(vedanā)、精进、一境性(ekaggatā) - (5)种名根(indriya)缘法的**根缘力，**
  - (庚) 由于寻(vitakka)、伺(vicāra)、喜(pīti)、受、一境性(5)支禅支(jhānaṅga)缘法的**禅那(jhāna)缘力，**
  - ( 辛 ) 若是(4)个贪根邪见相应(diṭṭhigatasampayutta)心 ---- 寻、精进、一境性、见(diṭṭhi)(4)支道支(maggaṅga)；若是(4)个贪根邪见不相应(diṭṭhigatavippayutta)心 ---- 寻、精进、一境性(3)支道支，由于这些缘法的**道(magga)缘力，(13)**。
- 2. 一般而言能够取所缘的贪根第一速行(4)种名蕴这些缘生法，是由于一般而言所应取的现在色所缘(声所缘……乃至……触所缘)缘法的**所缘、前生(purejāta)、有、不离去缘力。(4)**。

如果是以珍重的方式能够取所缘的贪根名蕴 ---- 那么，以珍重的方式能够取所缘的贪根(4)种名蕴这些缘生法，是由于以珍重的方式所应取的现在色所缘(声所缘……乃至……触所缘)缘法的**所缘、主导、强依止(upanissaya)、前生、有、不离去缘力，(6)**。

- 3. 贪根(4)种名蕴这些缘生法，是由于无有间隔而已经灭去的确定(voṭṭhabbana)名蕴缘法的**无间、等无间(samanantara)、强依止、无有(natthi)、离去(vigata)缘力，(5)**。

[若缘生法是贪根第二速行名蕴 ---- 则是由于无有间隔而已经灭去的第一速行名蕴缘法的**无间、等无间、强依止、重复(āsevana)、无有、离去缘力**，(6)。 
请如此等等地领会：直到第七速行为止，前前速行给予助益的方式。]

- 4. 由于与确定名蕴的生起的刹那(uppādakkhaṇa)同时并起而生起的心所依处(hadayavatthu)(临终(maraṇāsanna)时从死心(cuti)往回数，则是与第(17)个心的生起的刹那同时并起而生起的心所依处)缘法的**依止、前生、不相应(vippayutta)、有、不离去缘力，(5)**。 
(若是第二速行 --- 则是与第一速行的生起的刹那同时并起而生起的心所依处 --- 请如此等等地领会。)
- 5. 由于成为有力(balava)的 = 强而有力的世间的(lokiya)心(81)、心所(cetasika)(52)、色(28)，以及应当成为缘的某些概念(paññatti)等缘法的本性亲依止缘力，(1)。

由于这(28)种或(30)种因缘法共同给予助益，它们才得以生起并住立。

[**注** ---- 从第二速行到第七速行都能获得重复缘，因此若再加上重复缘，则对于第二速行名蕴等而言，将由(29)种或(31)种缘力给予助益。]
