### 色(rūpa)界有分(bhavaṅga)名蕴(nāmakkhandhā)

色界有分(5)个，除去远离(virati)之后的心所(cetasika)(35)个，各个部分的名蕴这些缘生法(paccayuppannadhamma) -----

- 1. 俱生(sahajāta)类 --- 13、
- 2. 所缘(ārammaṇa)类 --- 1、
- 3. 无间(anantara)类 --- 5、
- 4. 依处(vatthu)类 --- 5、
- 5. 异刹那业(nānākkhaṇikakamma)类 --- 2、

由于这(26)种缘力(paccayasatti)，才得以生起、存在。

色界有分(5)个，除去远离之后的心所(35)个，各个部分的名蕴这些缘生法 --

- 1. (甲)能够彼此相互给予助益的色界有分(5)个、心所(35)个，各个部分的名蕴这些缘法，随其相应而有的**俱生、相互(aññamañña)、依止(nissaya)、果报(vipāka)、相应(sampayutta)、有(atthi)、不离去(avigata)缘力，**
  - ( 乙 )色界有分中所包含的无贪(alobha)、无嗔(adosa)、无痴(amoha) --- 这(3)种因(hetu)缘法的**因缘力，**
  - ( 丙 )思(cetanā)缘法的**俱生业(kamma)缘力，**
  - (丁)触(phassa)、思、识(viññāṇa)这(3)种名食(āhāra)缘法的**食缘力，**
  - ( 戊 )(8)种名根(indriya)缘法的**根缘力，**
  - ( 己 )若是初禅(paṭhamajhāna)有分 -- 寻(vitakka)、伺(vicāra)、喜(pīti)、乐(sukha)、一境性(ekaggatā) -- **禅支(jhānaṅga)(5)种，** 若是第二禅有分 -- 伺、喜、乐、一境性 -- 禅支(4)种，若是第三禅有分 -- 喜、乐、一境性 -- 禅支(3)种，若是第四禅有分 -- 乐、一境性 -- 禅支(2)种，若是第五禅有分 - - 舍(upekkhā)、一境性 -- 禅支(2)种，这些缘法的禅那(jhāna)缘力，
  - (庚)若是初禅有分 -- 慧(paññā)、寻、精进(vīriya)、念(sati)、一境性 -- 道支(maggaṅga)(5)种，若是第二禅、第三禅、第四禅、第五禅有分 -- 慧、精进、念、一境性道支(4)种，这些缘法的**道(magga)缘力、(13)。**
- 2. 若是初禅有分 ---
  - (甲)遍(kasiṇa)概念(paññatti)(10)种、
  - ( 乙 )不净(asubha)概念(10)种、
  - ( 丙 )作为身至念(kāyagatāsati)所缘的头发等身分(kāyakoṭṭhāsa)概念(= 32身分概念)、
  - (丁)作为入出息念(ānāpānassati)所缘的入息、出息概念 = 入出息似相(paṭibhāganimitta)所缘、
  - ( 戊 )作为慈爱(mettā)所缘的一切快乐(sukhita)、受苦(dukkhita)有情(satta)概念、
  - ( 己 )作为悲悯(karuṇā)所缘的一切受苦有情概念、
  - (庚)作为随喜(muditā)所缘的一切快乐有情概念、

这(25)种概念、业相(kammanimitta)当中某一种概念业相 ---

若是第二禅、第三禅、第四禅有分当中的任一种 ---

- (甲) 遍概念(10)种、
- ( 乙 ) 作为入出息念所缘的入息、出息概念 = 入出息似相所缘、
- ( 丙 ) 作为慈爱所缘的一切快乐、受苦有情概念、
- (丁) 作为悲悯所缘的一切受苦有情概念、
- ( 戊 ) 作为随喜所缘的一切快乐有情概念、

这(14)种概念、业相当中某一种概念业相 ----

若是第五禅有分 ---

- (甲) 遍概念(10)种、
- ( 乙 ) 作为入出息念所缘的入息、出息概念 = 入出息似相所缘、
- ( 丙 ) 作为舍所缘的一切快乐、受苦有情概念、

这(12)种概念、业相当中某一种概念、业相缘法的**所缘缘力、(1)。**

- 3. (甲) 当紧接在结生(paṭisandhi)之后生起时，结生名蕴、
  - ( 乙 ) 当紧接在有分之后生起时，有分名蕴、
  - ( 丙 ) 当紧接在确定(vuṭṭhāpana)之后生起时，确定名蕴、
  - (丁) 当紧接在速行(javana)之后生起时，最后一个速行的名蕴 ---

这些缘法的**无间、等无间(samanantara)、强依止(upanissaya)、无有(natthi)、离去(vigata)缘力、(5)。** (色界地中不会有彼所缘(tadārammaṇa)，)

- 4. 与以结生为首的前前诸心一同生起的心所依处(hadayavatthu)，[在临终(maraṇāsanna)之时，从死心(cuti)往回数第(17)个心，与该心一同生起的心所依处]这些缘法的**依止、前生(purejāta)、不相应(vippayutta)、有、不离去缘力 、(5)。**
- 5. 过去的(5)种色界善业(rūpakusalakamma)当中相应的某一种色界善业缘法的异刹那业、本性亲依止(pakatūpanissaya)缘力 、(2)。

由于这(26)种因缘法共同围绕着给予助益，才得以生起、存在。(请分开观照。)
