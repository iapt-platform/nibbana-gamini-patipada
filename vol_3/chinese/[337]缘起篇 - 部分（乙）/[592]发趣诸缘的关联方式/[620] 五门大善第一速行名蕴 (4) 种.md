### 五门(pañcadvārika) 大善(mahākusala) 第一速行(paṭhamajavana) 名蕴(nāmakkhandhā) (4) 种

(8)个大善速行(javana)心(citta)各个部分的(4)种名蕴这些缘生法(paccayuppannadhamma) -----

- 1. 俱生(sahajāta)类 --- 13、
- 2. 所缘(ārammaṇa)类 --- 4、(6)
- 3. 无间(anantara)类 --- 5、(6)
- 4. 依处(vatthu)类 --- 5、
- 5. 本性亲依止(pakatūpanissaya) --- 1、

由于这(28)种因缘(paccaya)法，它们才得以生起并住立。

大善第一速行(8)种各个部分的(4)种名蕴这些缘生法 -----

- 1. (甲) 由于能够相互给予助益的大善第一速行各个部分的名蕴缘法(paccayadhamma)的**俱生、相互(aññamañña)、依止(nissaya)、相应(sampayutta)、有(atthi)、不离去(avigata)缘力(paccayasatti)，**
  - ( 乙 ) 由于能够给予相应诸蕴助益的、那大善心名蕴中所包含的——若是二因(dvihetuka)善(kusala)(4)个 ---- 无贪(alobha)、无嗔(adosa)；若是三因(tihetuka)善(4)个 ---- 无贪、无嗔、无痴(amoha) ---- 这(2)种、(3)种因(hetu)缘法的**因缘力，**
  - ( 丙 ) 若是二因善(4)个 ---- 欲(chanda)、精进(vīriya)、心；若是三因善(4)个 ---- 欲、精进、心、思维(vīmaṃsā)，由于这(3)种、(4)种当中任何一种缘法的**主导(adhipati)缘力，**
  - (丁) 由于思(cetanā)缘法的**俱生业(kamma)缘力，**
  - ( 戊 ) 由于触(phassa)、思、识(viññāṇa) - (3)种名(nāma)食(āhāra)缘法的**食缘力，**
  - ( 己 ) 若是二因善(4)个 --- 除去慧(paññā)的(7)种名根(indriya)；若是三因善(4)个 - 命(jīvita)、心、受(vedanā)、信(saddhā)、精进、念(sati)、一境性(ekaggatā)、慧 - (8)种名根，由于这些缘法的**根缘力，**
  - (庚) 若是悦(somanassa)俱大善心(4)个 ---- (5)支禅支(jhānaṅga)；若是舍(upekkhā)俱大善心(4)个 ---- 除去喜(pīti)的(4)支禅支，由于这些缘法的**禅那(jhāna)缘力，**
  - ( 辛 ) 若是二因大善(4)个 ---- 除去慧的(7)支道支(maggaṅga)，若是三因大善(4)个 --- 慧(＝正见(sammādiṭṭhi))，寻(vitakka)(＝正思惟(sammāsaṅkappa))，正语(sammāvācā)，正业(sammākammanta)，正命(sammāājīva)，精进(＝正精进(sammāvāyāma))，念(＝正念(sammāsati))，一境性(＝正定(sammāsamādhi)) ----- (8)支道支，由于这些缘法的**道(magga)缘力，(13)**。
- 2. 一般而言能够取所缘的大善的(4)种名蕴这些缘生法，是由于一般而言所应取的现在色所缘(声所缘……乃至……触所缘)缘法的**所缘、前生(purejāta)、有、不离去缘力**，(4)；有时能够以珍重的方式取所缘的大善智相应(ñāṇasampayutta)第一速行的(4)种名蕴这些缘生法，是由于有时所应以珍重的方式取的现在色所缘缘法的**所缘、主导、强依止(upanissaya)、前生、有、不离去缘力，(6)。**
- 3. 大善第一速行的(4)种名蕴这些缘生法，是由于确定(voṭṭhabbana)的(4)种名蕴缘法的**无间、等无间(samanantara)、强依止、无有(natthi)、离去(vigata)缘力，(5)。**

[对于大善第二速行的(4)种名蕴这些缘生法，大善第一速行的(4)种名蕴缘法以无间、等无间、强依止、重复(āsevana)、无有、离去诸缘力给予助益。
请如此等等地领会：前前心刹那(cittakkhaṇa)中的(4)种名蕴缘法，是如何以无间等诸缘力，给予后后心刹那中的(4)种名蕴这些缘生法助益的。]

- 4. 由于与确定名蕴的生起的刹那(uppādakkhaṇa)同时并起而生起的心所依处(hadayavatthu)(临终(maraṇāsanna)时从死心(cuti)往回数则为第(17)个的那个心的生起的刹那同时并起而生起的心所依处)这些缘法的**依止、前生、不相应(vippayutta)、有、不离去缘力，(5)**。
- 5. 由于成为有力(balava)的、除去阿拉汉(arahant)道(magga)与阿拉汉果(phala)的心(87)、心所(52)、色(28)，以及应当成为缘的某些概念(paññatti)等缘法的**本性亲依止缘力，(1)**。

由于这(28)种(有时 - 30种)因缘法共同给予助益，它们才得以生起并住立。

[**注** ----- 从第二速行到第七速行都能获得**重复缘力(āsevanapaccayasatti)**。 
因此，在第二速行……乃至……第七速行中，若在无间类里再加上重复缘(1)种，就成为**无间、等无间、强依止、重复、无有、离去缘力**这(6)种。 
因此，全部合计则成为(29)种缘力。 
有时在执行主导作用之时，则成为(31)种。]
