### 有分(bhavaṅga)心生色(cittajarūpa)的生起与存在方式

有分心生色缘生法(paccayuppannadhamma)们 ----

- 1. 名(nāma)俱生(sahajāta)类 --- 12、
- 2. 色(rūpa)俱生类 --- 5、
- 3. 后生(pacchājāta)类 --- 4、
- 4. 色食(rūpaāhāra)类 --- 3、

由于这(24)种缘法(paccayadhamma)共同围绕着给予助益，才得以生起、存在。

有分心生色缘生法们 ----

- 1. (甲) 有分名法(34、33)全部成分——名蕴(nāmakkhandha)(4)种缘法的**俱生、依止(nissaya)、果报(vipāka)、不相应(vippayutta)、有(atthi)、不离去(avigata)缘力(satti)，**
  - ( 乙 ) 该有分名法之聚中所包含的无贪(alobha)、无嗔(adosa)、无痴(amoha)缘法的**因(hetu)缘力，**
  - ( 丙 ) 思(cetanā)缘法的**俱生业(kamma)缘力，**
  - ( 丁 ) 触(phassa)、思、识(viññāṇa)缘法的**食(āhāra)缘力，**
  - ( 戊 ) 命(jīvita)、心、受(vedanā)、信(saddhā)、精进(vīriya)、念(sati)、一境性(ekaggatā)、慧(paññā)这(8)种名根缘法的**根(indriya)缘力，**
  - ( 己 ) 若是由与悦(somanassa)俱的欲(kāma)界三因(tihetuka)有分心所生起的心生色 ---- 寻(vitakka)、伺(vicāra)、喜(pīti)、(悦)受、一境性这(5)种禅支(jhānaṅga)，若是由与舍(upekkhā)俱的欲界三因有分心所生起的心生色 ---- 寻、伺、(舍)受、一境性这(4)种禅支缘法的**禅(jhāna)缘力，**
  - (庚) 慧、寻、精进、念、一境性这(5)种道支(maggaṅga)缘法的**道(magga)缘力，(12)**。
- 2. 同一色聚(kalāpa)中全部成分的大种(mahābhūta)(4)种缘法随其适宜的**俱生、相互(aññamañña)、依止、有、不离去缘力，(5)**。
- 3. 在后后生起的心、心所——名蕴缘法的**后生、不相应、有、不离去缘力，(4)**。
- 4. 存在于同一色聚与不同色聚中的四因生食素(catusamuṭṭhānikaojā)缘法的**色食、色食有、色食不离去缘力，(3)**。

由于这(24)种因缘法共同围绕着给予助益，才得以生起、存在。
