### 二、由于俱生识(sahajātaviññāṇa)而俱生名色(nāmarūpa)生起的一些观照方式

在 Viññāṇapaccayā nāmarūpaṃ 之中，如果就「识(viññāṇa)」一词取过去的业识(kammaviññāṇa)之义，那么就「名色」所包含的名法而言，就要摄取果报识(vipākaviññāṇa)的心(citta)+心所(cetasika)=全部名法。
如果就「识」一词，取与现在这一世所摄的、作为果的名法同时并行生起的俱生识之义，那么就作为果的名而言，只应摄取与那俱生识相应(sampayutta)的心所。 
就作为果的色法而言，依主要法(padhāna naya)只应摄取心生色(cittajarūpa)。 
而依不可相离的不相离法(avinābhāva naya)，则可以把四种等起色(catusamuṭṭhānika rūpa)全部收摄进来修观(vipassanā)。 
这一部分所宣说的是：在一个心刹那(cittakkhaṇa)之内同时并行生起的心与心所当中，心对心所以及对心生色作出资助的情形。 
因此，在俱生识这一部分，不要只摄取果报识，而要把善(kusala)、不善(akusala)、果报、唯作(kiriyā)这一切识都摄取进来，就名而言，也请随其所应地把相应的心所全部摄取进来。 
再者，由于五识(pañcaviññāṇa)不能令色(rūpa)生起，所以请记住：由于五识只有名生起。 
首先，请以智(ñāṇa)观照，直至亲见在一个心刹那之内一同生起的心、心所与诸心生色。 
在其中，由于识这一了知之心的领导而使相应的诸心所名法生起的情形，以及由于那些心与心所而使诸心生色生起的情形，请再一次以智反复观照，直至亲见。 
当你以智眼亲自了知见到时，请按照下面的方式收摄因法与果法。

- 一、由于结生(paṭisandhi)识生起，结生名色生起。
  - 结生识是因法，结生名色是果法。
(名 = 心所 - 33。色 = 业生色(kammajarūpa) - 30。)
- 二、由于有分(bhavaṅga)识生起，有分名色生起。
  - 有分识是因法，有分名色是果法。
(名 = 心所 - 33。色 = 心生色。)
- 三、由于死殁(cuti)识生起，死殁名生起。
  - 死殁识是因法，死殁名是果法。
(在不同的说法中，死殁心也能令心生色生起。)

以上是在离路心(vīthimutta)当中的观照片段。 
在心路心(vīthicitta)当中的观照片段如下。

- 一、由于五门转向(pañcadvārāvajjana)识生起，五门转向名色生起。
  - 五门转向识是因法，五门转向名色是果法。
(名 = 心所 - 10。色 = 心生色。)
- 二、由于眼识(cakkhuviññāṇa)生起，眼识名生起。
  - 眼识是因法，眼识名是果法。
(名 = 心所 - 7。)

在耳识(sotaviññāṇa)、鼻识(ghānaviññāṇa)、舌识(jivhāviññāṇa)、身识(kāyaviññāṇa)当中也请照同样的方式观照。

- 三、由于领受(sampaṭicchana)识生起，领受名色生起。
  - 领受识是因法，领受名色是果法。
(名 = 心所 - 10。色 = 心生色。)
- 四、由于推度(santīraṇa)识生起，推度名色生起。
  - 推度识是因法，推度名色是果法。
(名 = 11 或者 - 10。色 = 心生色。)
- 五、由于确定(voṭṭhabbana)识生起，确定名色生起。
  - 确定识是因法，确定名色是果法。
(名 = 心所 - 11。色 = 心生色。)
- 六、由于速行(javana)识生起，速行名色生起。
  - 速行识是因法，速行名色是果法。
(名 = 请随其所应地摄取相应的诸心所。色 = 心生色。)
- 七、由于彼所缘(tadārammaṇa)识生起，彼所缘名色生起。
  - 彼所缘识是因法，彼所缘名色是果法。
(名 = 请随其所应地摄取相应的心所。色 = 心生色。)

请在全部六条线上，把好的一组与不好的一组都毫无遗漏地观照。 
请收摄因法与果法。 
请按照名业处(nāmakammaṭṭhāna)部分诸表中所列出的那样，在推度、速行、彼所缘当中随其所应地摄取相应心所的数目。 
请在速行处观照七次、在彼所缘处观照两次，直至把每一格都观照周全。 
请按照表格观照，以便在每一个心刹那都能收摄因与果。
