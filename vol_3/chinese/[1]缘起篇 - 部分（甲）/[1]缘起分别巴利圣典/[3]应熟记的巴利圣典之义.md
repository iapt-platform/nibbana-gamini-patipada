### 应熟记的巴利圣典之义

- 1。avijjāpaccayā = 由于在四谛上不知、错知的无明(avijjā)这一因法明显存在故。saṅkhārā = 培育、促成现前之事与轮回之事者 = 即诸行(saṅkhāra)。sambhavanti = 便明显地生起。
- 2。saṅkhārapaccayā = 由于那培育、促成现前之事与轮回之事的行——这一因法明显存在故。viññāṇaṃ = 是业识(kammaviññāṇa)，另一说，是果报识(vipākaviññāṇa)。sambhavati = 便明显地生起。
- 3。（甲）viññāṇapaccayā = 由于那业识这一因法明显存在故。 
nāmarūpaṃ = 是果报名法、业生色(kammajarūpa)法。 
sambhavati = 便明显地生起。
    -（乙）另一说 ----- viññāṇapaccayā = 由于果报识这一因法明显存在故。
nāmarūpaṃ = 是果报心所名、果报心生色(cittajarūpa)。 
sambhavati = 便明显地生起。
- 4。nāmarūpapaccayā = 由于那名色(nāmarūpa)这一因法明显存在故。saḷāyatanaṃ = 是内在的六处(saḷāyatana)。sambhavati = 便明显地生起。
- 5。saḷāyatanapaccayā = 由于那内在的六处这一因法明显存在故。phasso = 是六种触(phassa)。sambhavati = 便明显地生起。
- 6。phassapaccayā = 由于那六种触这一因法明显存在故。vedanā = 是六种受(vedanā)。sambhavati = 便明显地生起。
- 7。vedanāpaccayā = 由于那六种受这一因法明显存在故。taṇhā = 是六种爱(taṇhā)。sambhavati = 便明显地生起。
- 8。taṇhāpaccayā = 由于那六种爱这一因法明显存在故。upādānaṃ = 是四种执取的取(upādāna)。sambhavati = 便明显地生起。
- 9。upādānapaccayā = 由于那四种执取的取这一因法明显存在故。bhavo = 是业有(kammabhava)、生有(upapattibhava)。sambhavati = 便明显地生起。
- 10。bhavapaccayā = 由于那业有这一因法明显存在故。jāti = 是结生(paṭisandhi)安立的生(jāti)法。sambhavati = 便明显地生起。
- 11。jātipaccayā = 由于那结生安立的生这一因法明显存在故。jarā maraṇaṃ = 衰老（老 jarā）、死亡（死 maraṇa）；soka parideva dukkha domanassupāyāsā = 忧愁（愁 soka）、悲泣（悲 parideva）、身苦（苦 dukkha）、心苦（忧 domanassa）、强烈热恼（恼 upāyāsa）诸法。sambhavanti = 便明显地生起。

evaṃ = 如是。 
kevalassa = 不与安乐相杂、纯然的。 
etassa dukkhakkhandhassa = 这苦团、苦聚之。 
samudayo = 生起之因。 
另一说 ---- samudayo = 生起。 
hoti = 便生起而来。

tattha = 在那以「avijjāpaccayā saṅkhārā」等起始的巴利圣典中。 
avijjā = 所谓无明者。 
katamā = 是什么呢？

- 1。dukkhe = 于苦谛(dukkhasacca)法上。aññāṇaṃ = 无知，以及。
- 2。dukkhasamudaye = 于苦之生起因的集谛(samudayasacca)法上。aññāṇaṃ = 无知，以及。
- 3。dukkhanirodhe = 于苦之息灭处的灭谛(nirodhasacca)法上。aññāṇaṃ = 无知，以及。
- 4。dukkhanirodhagāminiyā paṭipadāya = 于导向苦之息灭处涅槃(nibbāna)、清净高尚的行道(paṭipadā)即道谛(maggasacca)法上。<br>aññāṇaṃ = 无知，以及。

ayaṃ = 把这不知。 
avijjā = 称为无明。 
vuccati = 被称说。

tattha = 在那巴利圣典中。

- 3。āneñjābhisaṅkhāro = 不动行(āneñjābhisaṅkhāra)，以及。
- 4。kāyasaṅkhāro = 身行(kāyasaṅkhāra)，以及。
- 5。vacīsaṅkhāro = 语行(vacīsaṅkhāra)，以及。
- 6。cittasaṅkhāro = 心行(cittasaṅkhāra)而已。

- 1。tattha = 在那些行当中。 
puññābhisaṅkhāro = 所谓福行者。 
katamo = 是什么呢？
dānamayā = 布施(dāna)所成的。 
sīlamayā = 持戒(sīla)所成的。 
bhāvanāmayā = 由（所谓遍作修(parikammabhāvanā)、近行修(upacārabhāvanā)、观修(vipassanābhāvanā)的）修习(bhāvanā)所成的。 
kāmāvacarā = 属于欲界(kāmāvacara)地的。
yā kusalā cetanā = 凡是那大善(mahākusala)思(cetanā)，以及。 
（此处并非指一切观业(vipassanākamma)，而仅指能令有(bhava)生起的观修。） 
bhāvanāmayā = 由止修(samathabhāvanā)所成的。 
另一说，由安止修(appanābhāvanā)所成的。 
rūpāvacarā = 属于色界(rūpāvacara)地的。yā kusalā cetanā = 凡是那色界善思，以及。 
atthi = 存在。 
ayaṃ = 把这欲界善思、色界善思。 
puññābhisaṅkhāro = 称为福行。 
vuccati = 被称说。
[ 大善(8)种、色界善(5)种。合计(13)种而已。]

āneñjābhisaṅkhāro = 称为不动行。

- 4。tattha = 在那些行当中。 
kāyasaṅkhāro = 所谓身行者。 
katamo = 是什么呢？
kāyasañcetanā = 于身门(kāyadvāra)生起的(8)种欲善(kāmakusala)思、(12)种不善
思。 
kāyasaṅkhāro = 名为身行。(8+12=20)。

- 5。vacīsañcetanā = 于语门(vacīdvāra)生起的(8)种欲善思、(12)种不善
思。 
vacīsaṅkhāro = 名为语行。(20)。

- 6。manosañcetanā = 不令二种表色(viññattirūpa)生起（＝不令身表色、语表色二种生起）而全部生起的[ (12)种不善思、(8)种欲善思、(5)种色善思、(4)种无色善思 ]缺一的(30)种思。 
cittasaṅkhāro = 名为心行。(29)。

ime = 把这些行。 
avijjāpaccayā saṅkhārā = 称为由名为无明之因而生起的诸行。 
vuccanti = 被称说。
