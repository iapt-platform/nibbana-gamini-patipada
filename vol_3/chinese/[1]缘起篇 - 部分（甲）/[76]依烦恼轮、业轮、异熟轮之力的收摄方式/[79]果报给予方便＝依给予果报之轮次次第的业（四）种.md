### 果报给予方便(pākadānapariyāya) = 依给予果报的轮次、次第，业(四)种

- 1. 重业(garukaṃ) = 重大的业，
- 2. 多作业(bahulakaṃ) = (习行业(āciṇṇakaṃ)) = 已多次造作、多次串习的业，
- 3. 临死业(āsannakaṃ) = 在临死时造作、忆念的业，
- 4. 业所造业(kaṭattākaṃ) = 仅仅是已造作而已的业 ----

如此，依给予果报的轮次、次第，业分为四种。

- 1. **重业** ---- tattha kusalaṃ vā hotu akusalaṃ vā, garukāgarukesu yaṃ garukaṃ mātughātādikammaṃ vā mahaggatakammaṃ vā, tadeva paṭhamaṃ vipaccati. (Visuddhi, 2, 236.)

**yaṃ garuka**nti yaṃ akusalaṃ mahāsāvajjaṃ kusalaṃ mahānubhāvaṃ kammaṃ. (Mahāṭī, 2, 377.)

在那四种业当中，无论是善(kusala)，还是不善(akusala)，在重业(garukakamma)、非重业(agarukakamma)当中 = 在重大的业、不重大的业当中，在不善方面，有杀害母亲 = 弑母业(mātughātakakamma)等五无间业(pañcānantariyakamma)，以及直到临死也不舍弃的定邪见(niyatamicchādiṭṭhi)业。
在善方面，有威力大的广大业(mahaggatakamma) = 禅那善(jhānakusala)。
那些业便是重业。
在不善方面，唯有那些罪过极大的重业才最先给予果报。
在善方面也是如此，唯有那名为重业、威力极大的广大业才最先给予果报，使果报生起。(Visuddhi, 2, 236.)

- 2. **多作业** ---- tathā bahulābahulesupi **yaṃ bahulaṃ** hoti susīlyaṃ vā. dussīlyaṃ vā. tadeva paṭhamaṃ vipaccati. (Visuddhi, 2, 236.)

在多次造作、多次串习的多作业(bahulakamma)，与非多次造作、非多次串习的非多作业(abahulakamma)当中，也有善戒(susīlya) = 善的行为，或恶戒(dussīlya) = 不善的行为、多次造作多次串习的业存在，唯有那多作业 = 习行业(āciṇṇakamma)才最先使果报生起。最先给予果报。

- 3. **临死业** ---- **yadāsannaṃ** nāma maraṇakāle anussaritakammaṃ. yañhi āsannamaraṇo anussarituṃ sakkoti, teneva upapajjati. (Visuddhi, 2, 236.)

**maraṇakāle anussarita**nti paribyattabhāvena maraṇassa āsannakāle anussaritaṃ. āsannakāle kate vattabbameva natthīti hi vuttaṃ. (Mahāṭī, 2, 377.)

在临死时反复忆念的业名为临死业。
至于临死时紧邻着造作的业被称为临死业一事，就已无需赘言了。
若临近死亡、具有死亡之法的有情(satta)，在那临死、临命终(maraṇāsanna)之时，能够反复忆念所造作、所忆念的业，那么唯有那业才使果报生起。
由于在临死、临命终之时，那是作为临死速行(maraṇāsannajavana)的所缘而清清楚楚显现的那类业，因此临死速行才能反复忆念那业。
(Visuddhi, 2, 236. Mahāṭī, 2, 377.)

- 4. **业所造业** ---- etehi pana tīhi muttaṃ punappunaṃ laddhāsevanaṃ kaṭattā vā pana kammaṃ nāma hoti, tesaṃ abhāve taṃ paṭisandhiṃ ākaḍḍhati. (Visuddhi, 2, 236.)

除重业、多作业、临死业这三种之外，反复多次获得、具有重复缘(āsevanapaccaya)的、无论是在此生、还是在过去许多生中所造作的、仅仅是已造作而已的业，名为业所造业。
当上述重业等三种业不存在时，这业所造业便牵引结生(paṭisandhi)的果报。
使结生的果报生起。

paṭisandhijanakavasena hi garukādikammacatukkaṃ vuttaṃ. (Mahāṭī, 2, 377.)

这名为重业、多作业、临死业、业所造业的业四法(kammacatukka)，是依能给予结生果报的令生业(janakakamma)之力而作的解说。

[**注** ---- 在《摄阿毗达摩义论》(Saṅgaha)中，则作重业、临死业、习行业、业所造业，把临死业放在第2位、把习行业放在第3位。
在《清净之道》(Visuddhimagga)中，则把习行业放在第2位、把临死业放在第3位。
全部都是合乎道理的。]
