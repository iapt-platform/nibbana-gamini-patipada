### 近行禅(upacārajhāna)

Tassevaṃ vāyamamānassa nacireneva dhātuppabhedāvabhāsanapaññāpariggahito sabhāvadhammārammaṇattā appanaṃ appatto upacāramatto samādhi uppajjati. (Visuddhi. 1. 347.)

Evaṃ pana vīriyasamataṃ yojetvā tasmiṃ yeva lakkhaṇe manasikāraṃ pavattentassa yadā saddhādīni indriyāni laddhasamatāni suvisadāni pavattanti, tadā asaddhiyādīnaṃ dūrībhāvena sātisayaṃ thāmappattehi sattahi balehi laddhūpatthambhāni vitakkādīni jhānaṅgāni paṭutarāni hutvā pātubhavanti, tesaṃ ujuvipaccanīkatāya nīvaraṇāni vikkhambhitāniyeva honti saddhiṃ tadekaṭṭhehi pāpadhammehi. 
Ettāvatā cānena upacārajjhānaṃ samadhigataṃ hoti dhātulakkhaṇārammaṇaṃ. 
Tena vuttaṃ **“punappunaṃ pathavīdhātu āpodhātūti. pa** **. upacāramatto samādhi uppajjatī”**ti. (Mahāṭī. 1. 435.)

上述义注(aṭṭhakathā)与复注(ṭīkā)所要表达的含义是这样的。

为了如实了知四大界(dhātu)的自性相(sabhāva lakkhaṇa)而努力用功的精进(vīriya)、为了让修习之心平静地贴住并安住在四大界自性相所缘上而努力用功的精进，以及修习之心平静地贴住安住在四大界自性相所缘上的这种定(samādhi)，都是存在的。 
把精进与定这两者调配得均等、使它们并行生起，并且在那四大界的自性相所缘上一再地生起作意(manasikāra)的瑜伽行者(yogāvacara)比库(bhikkhu)的相续(santāna)中，当那样的时候 ---- 

- 1. 对于以四大界为所缘而建立定的定学 = 定的修行次第，以及洞察了知四大界各自本有自性相的慧学 = 慧的修行次第，也就是界业处(dhātukammaṭṭhāna)修习(bhāvanā)这项工作，怀有信心的信(saddhā)之法，即信根(saddhindriya)， 
- 2. 为了了知四大界自性相所缘而努力用功、为了让修习之心平静地贴住并安住在四大界自性相所缘上而努力用功的精进之法，即精进根(vīriyindriya)， 
- 3. 一再再三地只忆持、只记取四大界自性相所缘的念(sati)之法，即念根(satindriya)，
- 4. 心安定地住立在四大界自性相所缘上的定之法，即定根(samādhindriya)，
- 5. 把四大界各自的自性相分别剖析而洞察了知的慧(paññā)之法，即慧根(paññindriya) ----

这(五)根彼此互不超越，具有应当获得的均等；并且十分清净明晰。那时，由于不信、懈怠、失念、心散乱、不能如实洞察了知四大界自性相的愚痴等这些对立之法已经远离，因而达到了极为强盛的状态、具足了力量的 ----

- 1. 忆念、记取四大界的自性相，一再再三地忆持着的念觉支(satisambojjhaṅga)，
- 2. 探究、思择、审察四大界的自性相，透彻地了知着的择法觉支(dhammavicayasambojjhaṅga)，
- 3. 为了在四大界的自性相所缘上生起择法(为了生起相应法聚)、特别是为了生起平静地贴住安住的定而努力用功的精进觉支(vīriyasambojjhaṅga)， 
 - 4. 修习之心在四大界自性相所缘上明净欢喜的喜觉支(pītisambojjhaṅga)，
- 5. 修习之心与心所在四大界自性相所缘上寂静清凉的轻安觉支(passaddhisambojjhaṅga)，
- 6. 修习之心在四大界自性相所缘上平静地贴住安住这一性质的定觉支(samādhisambojjhaṅga)，
- 7. 使修习之心在四大界自性相所缘上既不偏向振奋、也不偏向退缩，而保持均衡这一性质的舍觉支(upekkhāsambojjhaṅga) ----

由于这念、择法、精进、喜、轻安、定、舍这(七)种力量强大的觉支(bojjhaṅga)给予了支持与扶助，由于得到了那些强大力量的支持与扶助 ----

- 1. 寻(vitakka) = 把心投向、安置到四大界自性相所缘上的性质，
- 2. 伺(vicāra) = 对四大界的自性相所缘一再再三地审察思惟的性质，
- 3. 喜(pīti) = 对四大界自性相所缘感到欢喜的性质，
- 4. 乐(sukha) = 安乐地领受四大界自性相所缘之滋味的性质，
- 5. 一境性(ekaggatā) = 心落入并安定住立在四大界自性相所缘这唯一之处的性质 - 这样的

这(五)禅支(jhānaṅga)变得格外敏锐，因而明显地显现出来。

- 1. 对诸欲乐的希求贪爱，即欲贪(kāmarāga)，也就是欲贪盖(kāmacchandanīvaraṇa)，
- 2. 对有情与诸行(saṅkhāra)想要破坏、想要毁灭，心刚硬粗暴的瞋(dosa)，也就是瞋恚盖(byāpādanīvaraṇa)，
- 3. 心与心所昏沉迟钝的昏沉睡眠盖(thinamiddhanīvaraṇa)，
- 4. (一)心散乱的掉举(uddhacca)，(二)对已经造作的不善法、恶行，以及未能造作、未能修习的善法、善行，事后一再懊恼追悔的追悔(kukkucca)，也就是掉举追悔盖(uddhaccakukkuccanīvaraṇa)，
- 5. 对于依界业处之路、以四大界的自性相为所缘而建立起来的、以等同近行(sadisūpacāra)而得名为近行定(upacārasamādhi)的定学 = 定的修行次第，以及洞察了知四大界自性相的慧学 = 慧的修行次第，心里这样那样地猜疑不定的疑盖(vicikicchānīvaraṇa)，也就是 ----

能够阻挡、遮蔽修习之心的相续，使它无法走上修习轨道的这(五)种盖(nīvaraṇa)法，与寻、伺、喜、乐、一境性这(五)禅支是直接、正面对立的。 
由于这(五)种盖法是那(五)禅支的直接、正面对立面，所以当诸禅支变得极为敏锐锋利、明显地显现出来时，诸盖法就必定被剥离，它们会离去。 
不只是诸盖法，连那些与诸盖法同处一处、同时并存相应的不善法，也一并被剥离开去。 
以这样的程度，这位瑜伽行者就圆满地获得了以四大界自性相为所缘的近行禅。因此，在(Visuddhi. 1. 347.)的义注中 ----

「乃至几百次、几千次、几十万次，一遍又一遍地，以地界(pathavīdhātu)、水界(āpodhātu)、火界(tejodhātu)、风界(vāyodhātu)这样的方式，仅仅就界的本质而言，就非有情而言，就非命我(jīvaatta)而言 ----

- 1. 应当思惟 = 应当好好地一再再三地纳入心中。
- 2. 应当作意 = 应当以一再再三地培育的方式，把界的自性相安置在心中。
- 3. 应当一个一个、逐一地专注观照 = 应当以修习所成的智眼，把界的自性相本身一层一层、一再再三地思惟而加以观照。

以上述这些方式精进用功、并且善于在修习之事上相应契合的那位瑜伽行者比库的相续中，就在不久的时间之内，便生起了这样的定：由于它所缘取的，是被那能够把地界、水界、火界、风界各自本有自性相的种种差别清晰地彰显出来、照亮出来的慧，即具有如同油灯般照明作用的慧，从四周摄取住的深奥究竟法(paramatthadhamma)本质力用这一自性法(sabhāvadhamma)，因此它达不到名为安止(appanā)的广大禅 = 达不到安止定的阶段，只是近行(upacāra)而已，是所谓 sikhāppatta = 已达至顶峰的欲界定(kāmāvacarasamādhi)」——(义注)是这样解释的。 
这就是上述义注、复注这些文句所要表达的含义。
