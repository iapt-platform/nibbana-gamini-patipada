### 心生色聚(cittaja rūpa kalāpa) (八) 类

- 1. **心生纯八法聚(cittaja suddhaṭṭhaka kalāpa)** = 由于心而生起的、单纯的八法聚 = 以食素(ojā)为第(8)个法的色聚。(就是存在于(6)门与某些身分(koṭṭhāsa)之中的食素为第八的色。)
- 2. **身表九法聚(kāyaviññatti navaka kalāpa)** = 以身表(kāyaviññatti)色为第(9)个法的色聚。(8+身表 = 9。)
- 3. **轻快性等十一法聚(lahutādekādasaka kalāpa)** = 以轻快性(lahutā)等为第(11)个法的色聚。(8+轻快性+柔软性(mudutā)+适业性(kammaññatā) = 11。)
- 4. **身表轻快性等十二法聚(kāyaviññatti lahutādi dvādasaka kalāpa)** = 以身表、轻快性等为第(12)个法的色聚。(8+身表+轻快性+柔软性+适业性 = 12。)
- 5. **语表十法聚(vacīviññatti dasaka kalāpa)** = 以语表(vacīviññatti)为第(10)个法的色聚。(8+声音(sadda)+语表 = 10。)
- 6. **语表声轻快性等十三法聚(vacīviññatti sadda lahutādi terasaka kalāpa)** = 以语表、声音、轻快性等为第(13)个法的色聚。(8+语表+声音+轻快性+柔软性+适业性 = 13。)
- 7. **(入息-出息)心生声九法聚(assāsa-passāsa cittaja saddanavaka kalāpa)** = 以由(入息-出息)之心而生起的声音为第(9)个法的色聚 (8+声音 = 9。)
- 8. **(入息-出息)声轻快性等十二法聚(assāsa-passāsa sadda lahutādi dvādasaka kalāpa)** = 以(入息-出息)的声音、轻快性等为第(12)个法的色聚 (8+声音+轻快性+柔软性+适业性 = 12。)

在名为《摄阿毗达摩义论》(Abhidhammatthasaṅgaha)的摄要典籍里，只列出了从第(1)项到第(6)项的(6)类心生色聚。但是在《清净道论》义注中则说 --- **Assāsapassāsā cittasamuṭṭhānāva**。(清净道论、1、346。) 
= 由于已经这样解释：入息-出息只是心生(cittasamuṭṭhāna)色而已，所以入息-出息正是心生色。

Tathā cittaje assāsapassāsakoṭṭhāsepi ojaṭṭhamakañceva saddo cāti nava. (清净道论、2、223。)

依照上面这段《清净道论》义注，入息-出息身分只不过是以声音为第(9)个法的声九法聚(saddanavaka kalāpa)诸色的集合体而已。 
诸位尊贵的阿阇黎又有这样的看法：那入息-出息身分应当有两种。 
有时候呼吸得很好，轻快敏捷，平顺细滑，匀称合宜。 
有时候呼吸又会变得不好，没有轻快敏捷，没有平顺细滑，没有匀称合宜。 
因此在入息-出息之中，就分成了含有与不含有轻快性+柔软性+适业性诸色的两种。 
因此心生色聚就成为(8)类。

想要观照修习这些色聚的瑜伽行者(yogāvacara)，如果已经把上面所说的、存在于(6)门(42)身分之中的诸色法摄取完毕，那就更好。 
至少必须是已经把存在于(6)门之中的诸真实色摄取完毕的人。 
只有在把诸真实色观照修习、摄取到智的见解抵达究竟法(paramattha)之后，要摄取诸假色、或者是与诸假色混杂在一起的诸色聚，才会容易。

- 1. **心生纯八法聚** ---- 就照着在(6)门(42)身分之中观照摄取心生色的方法那样，请观察由于依止心所依处色(hadaya vatthu)而生起的心，使得诸心生的食素为第八的色不断地生起的情形，直到以智见到为止，并且观照修习、摄取。
- 2. **身表九法聚** ---- 请把心专注在有分(bhavaṅga)意明净上，试着把一根食指弯曲起来，试着把它伸直。请观察由于想要弯曲的心、想要伸直的心等等各别的心，每一个心都使得许许多多的色聚生起显现，直到以智见到为止。当见到那些心生色聚遍布到全身的时候，请观察、请观照那些心生色一直遍布到正在弯曲的食指为止的情形，直到以智见到。这时将不再见到食指，而只会见到色聚的微粒。请在那正在做弯曲、伸直动作的食指上继续观照，直到以智见到在那许许多多的色聚之中、唯有由于想要弯曲、想要伸直的心而生起显现的那些心生色。那些色聚正是食素为第八的色聚。请继续摄取，直到以智见到与那(8)种色在一起的、随着想要弯曲、想要伸直的心而一同生起的弯曲的姿态、伸直的姿态这些色(= 诸身表色)。(8+身表 = 9) 这些就是身表九法聚的诸色法。
- 3. **轻快性等十一法聚** ---- 请观察上面所说的诸心生食素为第八的色，直到见到为止。请观察、请摄取，直到以智见到有时候在那些色之中也混杂含有轻快敏捷 = 轻快性，柔软细嫩 = 柔软性，匀称合宜 = 适业性 --- 这些假色。
- 4. **身表轻快性等十二法聚** ---- 请重新观照上面所说的身表九法聚。有时候弯曲、伸直的时候有轻快敏捷，有柔软细嫩，弯曲、伸直的时候有匀称合宜。那时候轻快性-柔软性-适业性就含在其中。有时候如果不是这样，那(3)种色就不含在其中。那(3)种色不含在其中的时候，就成为**身表九法聚**；那(3)种色含在其中的时候，就成为**身表轻快性等十二法聚**。在其余的弯曲、伸直、行走等等种种身体姿态之中，也请照同样的方法观照。在**威仪路(iriyāpatha)观照区块**、**正知(sampajañña)观照区块**之中 --- 这两种色聚是特别重要的。在后面的部分，还会再解说威仪路观照区块与正知观照区块。
- 5. **语表十法聚(语表声十法聚)** ---- 你这位善男子禅修者，请把心专注在有分意明净界上，用很轻很小的声音试着念诵 **(ka-kha)**。请观照由于想要念诵 ka-kha 的心、正在念诵的心，使得诸心生食素为第八的色前后相接、连续不断、大量地生起的情形，直到以智见到为止。由于 ka-kha 是在喉部这个处所生起的字母，所以请观照诸食素为第八的色一直遍布到那些字母生起之处、也就是喉部的情形，直到见到为止。在喉部，有以相续(santati)之流的方式不断生起的身十法聚等等诸色聚。当那些心生食素为第八的色之中所含的地界(pathavī dhātu)，借助风界(vāyo dhātu)的帮助，在喉部撞击到存在于喉中的身十法聚等等之中所含的诸业生地界的时候，声音就发出来了。而正在说 ka-kha 的口部姿态、也就是语表，也是存在着的。因此(8+声音+语表 = 10)，就成为语表十法聚。在其余的字母上，也请照同样的方法，跟随到所念诵的那些字母各自的生起之处，这样观照观察。
- 6. **语表声轻快性等十三法聚** ---- 有时候，为了发出 ka-kha 等等的语音而念诵的时候，是轻快敏捷的，是平顺细滑的，是匀称合宜的，这时候轻快性、柔软性、适业性也就含在其中了。就成为语表声轻快性等十三法聚。有时候如果不敏捷利落、不平顺细滑、不匀称合宜，那么轻快性、柔软性、适业性就不再含在其中了。那时候就成为语表十法聚。

在各种声音生起、各种字母生起的处所，以相续之流的方式不断生起的诸业生色聚之中所含的诸业生地界，就像**木墩**一样。 
一直遍布到各种声音生起、各种字母生起的处所、以相续之流的方式散布生起的许许多多心生色聚之中所含的诸地界，就像**木槌**一样。 
**用木槌敲打木墩的那种动作姿态，与语表**相似。 
那语表，是由于想要发出各种字母之声的心所产生的风界，才得以生起的。 
那风界则是由于心而生起的。 
因此，由于那些由心而生起的风界的自性力量、能量特别强盛的色法之聚 = 色聚之聚遍布到全身，语音才得以生起。 
应当观照，直到以智见到为止。

- 7. **入出息 - 心生声九法聚** ---- 请观照由于依止心所依处色而生起的诸心，使得入息与出息生起的情形，换句话说，是名为入息、出息的诸声九法聚色法生起的情形，直到以智见到为止。请先观照存在并生起于呼吸通道之内的气息，直到见到为止。当借助定的光线能量见到那气息的时候，请在那气息之内观照四大界，直到见到为止。如果能够在那入息、出息之内观照四大界直到见到，那么随着定力增强，就会同时开始见到色聚的微粒。如果以智分别剖析地观照那些色聚微粒 --- 就能够见到连同呼吸之声在内的(9)种色究竟法。所谓呼吸之声，就是存在于那呼吸通道之中的诸色聚的地界，与那些心生色聚的地界互相撞击而发出的声音。请观照由于心而使诸食素为第八的色在呼吸的气息之中生起的情形，诸地界互相撞击而发出声音的情形，以及在每一个色聚之内都各有连同声音在内的(9)种色法自性的情形，直到见到为止。 

假如虽然贯注地以智观照存在于呼吸通道之中的入息、出息之内、以相续之流的方式生起的四大界，直到见到，却还没有见到色聚的微粒、仍然是一团一块的话，那么只要能够贯注地观照空界(ākāsadhātu)直到见到，就能够容易地见到色聚的微粒。 
而光线能量的帮助则是非常需要的。

有时候呼吸是轻轻快快、敏捷利落、平顺细滑、匀称合宜的，呼吸得很好。 
轻快性-柔软性-适业性含在其中。 
有时候呼吸会变得憋闷，变得沉重粗糙，呼吸会变得不匀称。 
轻快性-柔软性-适业性就不含在其中。 
这就成为入出息心生声轻快性等十二法聚与入出息心生声九法聚。

在这些色法之中，身表、语表、轻快性、柔软性、适业性以及空界都只是假色而已。 
它们是不适合用观(vipassanā)来观照的色。 
但是《清净道论》义注第二册第(225)页中指示：在名色分别智(nāmarūpaparicchedañāṇa)的阶段，也要把那些假色一并混合起来摄取。
