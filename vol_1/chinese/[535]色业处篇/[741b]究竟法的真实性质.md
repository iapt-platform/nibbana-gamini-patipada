### 究竟法(paramattha)的真实性质

诸究竟法的寿命时间极其极其短暂，因此它们并不具有能够从一个地方移动到另一个地方的力量。 
它们只是在生起的那个地方就当下坏灭的法(dhamma)的自然现象而已。 
因此，能够向前搬运的那些色(rūpa)法，其实并不是真的在搬运；被搬运的那些色法，其实也并不是真的被搬运。 
由于风界(vāyodhātu)与表(viññatti)色的力量，那些前后相续、一次又一次重新、一层又一层不断生起的色法，只不过是在一个又一个新的地方转换着，一次又一次重新、一层又一层地不断生起而已。 
像这样不在原先生起的地方再次生起，而是移到一个又一个新的地方生起，这正是由于风界与表色的力量才发生的。 
因此才解释说：以向前搬运的行相而生起，就被称为「走」。

- 一、**能够搬运的色**，
- 二、**被搬运的色** ----

正在修观这个威仪(iriyāpatha)观照项的瑜伽行者(yogāvacara)善人，需要能够分辨着修观、分辨着了知能够搬运的色与被搬运的色。

Cittakiriyavāyodhātuvipphārena sakalakāyassa purato abhinīhāro gamananti vuccati —— 如同上文所引述的那样，由于义注(aṭṭhakathā)是这样解说的 ----

- 一、由于想走的心而生起的风界，其自然的力量特别强盛，以色聚(rūpakalāpa)的形态遍布全身而生起的 ---- 身表九法聚(kāyaviññattinavaka kalāpa)、身表轻快性等十二法聚(kāyaviññattilahutādi dvādasaka kalāpa) - 这样的两种色聚，每一种色聚之中都有数量众多的色聚，这些色聚的总集 = 色法的总集，就是能够搬运的那些色法。
- 二、存在于(六)门(dvāra)、(四十二)部分(koṭṭhāsa)之中的 ----
   - (甲) 业(kamma)生色，
   - ( 乙 ) 心生色，
   - ( 丙 ) 时节(utu)生色，
   - (丁) 食(āhāra)生色——这些就是被搬运的那些色法。
