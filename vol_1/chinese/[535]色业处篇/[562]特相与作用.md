### 特相(lakkhaṇa)与作用(rasa)

在上面已经说明过的《清净道论》义注的界业处(dhātukammaṭṭhāna)略说法的修习方式 = 修习方法(bhāvanānaya)的第一法、第二法当中 ----

- 1. 在地界(pathavīdhātu)当中 ---- (甲) thaddhabhāva = 坚硬的性质，<br>( 乙 ) kharabhāva = 粗糙的性质，
- 2. 在水界(āpodhātu)当中 ---- (甲) dravabhāva = 流泻的性质，<br> ( 乙 ) ābandhanabhāva = 黏结的性质，
- 3. 在火界(tejodhātu)当中 ---- (甲) uṇhabhāva = 炎热的性质，<br>( 乙 ) paripācanabhāva = 使之成熟的性质，
- 4. 在风界(vāyodhātu)当中 ---- (甲) vitthambhanabhāva = 支持的性质，<br>( 乙 ) samudīraṇabhāva = 推动的性质 ----

像这样，在每一界当中都各说明了两种。 
这项说明，大复注(mahāṭīkā)的大长老按照下面的方式作了解释与开示。

- 1. (甲) thaddhabhāva = 坚硬的性质，是 - 地界的自性相(sabhāva lakkhaṇa)，<br>( 乙 ) kharabhāva = 粗糙的性质，是 - 现起的行相(upaṭṭhānākāra) = 作用职能，
- 2. (甲) dravabhāva = 流泻的性质，是 - 水界的自性相<br>( 乙 ) ābandhanabhāva = 黏结的性质，是 - 现起的行相 = 作用职能
- 3. (甲) uṇhabhāva = 炎热的性质，是 - 火界的自性相<br>( 乙 ) paripācanabhāva = 使之成熟的性质，是 - 现起的行相 = 作用职能
- 4. (甲) vitthambhanabhāva = 支持的性质，是 - 风界的自性相<br>( 乙 ) samudīraṇabhāva = 推动的性质，是 - 现起的行相 = 作用职能

就这样各别地作了解释开示。(Mahāṭī, 1, 433.)
