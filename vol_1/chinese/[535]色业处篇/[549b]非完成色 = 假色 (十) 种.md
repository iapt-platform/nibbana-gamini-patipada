### 非完成色(anipphanna rūpa) = 假色 (十) 种

**限界色(pariccheda rūpa) (一) 种**

- 1、**空界(ākāsadhātu)** ---- 它是为了使诸色聚(kalāpa)彼此互不混杂而能够加以分隔的、作为分隔诸色聚之因的、诸色聚之间的间隙。这个空界由于是分隔诸色聚的原因，所以也称为限界色。

**表色(viññatti rūpa) (二) 种**

- 1、**身表(kāyaviññatti)** = 以身体使人了知的身体动作，
- 2、**语表(vacīviññatti)** = 以口(= 以话语的声音)使人了知的口的动作，

**表** --- 能够把自己内心的意向与意欲让他人了知、可以使他人知道的那种特殊动作，就称为表色。 
**身表**是指把自己内心的意向与意欲以身体使他人了知的动作，例如挥手示意来招呼等等。 ။ **语表**是指以口(= 以话语的声音)把自己内心的意向与意欲使他人了知的动作。 
例如 - 说"来吧"这样以口(= 以话语的声音)来招呼的那一类。

在挥手示意的时候，他人之所以能够了知自己想要让对方前来的那种内心的意向与意欲，是那挥手招呼之中所包含的身表色的能力。 
在发出"来吧"这个声音的时候，他人之所以能够了知自己想要让对方前来的那种内心的意向与意欲，应当记住，这是那个声音中所包含的语表色的能力。 ။ 
有这样的说法：在无生命的物体的动摇之中之所以不能这样了知，是因为那些表色在无生命物体的动摇之中并不存在。 
身表、语表这两种色是由于心才生起的，而无生命的物体之中没有心，所以那些表色不能够存在于无生命的色法之中。

**变化色(vikāra rūpa) (五) 种**

- 1、**轻快性(lahutā)** = (甲) 由心所生的诸色的轻快状态，
    - ( 乙 ) 由时节 = 季节(utu)所生的诸色的轻快状态，
    - ( 丙 ) 由食(āhāra)所生的诸色的轻快状态，
- 2、**柔软性(mudutā)** = (甲) 由心所生的诸色的柔软状态，
    - ( 乙 ) 由时节所生的诸色的柔软状态，
    - ( 丙 ) 由食所生的诸色的柔软状态，
- 3、**适业性(kammaññatā)** = (甲) 由心所生的诸色在作业上的良好堪任状态，
    - ( 乙 ) 由时节所生的诸色在作业上的良好堪任状态，
    - ( 丙 ) 由食所生的诸色在作业上的良好堪任状态，

这轻快性、柔软性、适业性 - 三种色，加上表色两种，合起来这五种色就称为变化色。 
意思是说，它们是各种特别不同的动作状态之色。
