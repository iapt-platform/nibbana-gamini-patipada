### 明净界 (六) 种

- 1. 眼净色(cakkhupasāda) = 眼的明净，
- 2. 耳净色(sotapasāda) = 耳的明净，
- 3. 鼻净色(ghānapasāda) = 鼻的明净，
- 4. 舌净色(jivhāpasāda) = 舌的明净，
- 5. 身净色(kāyapasāda) = 身的明净——像这样，色明净界共有 (五) 种。
- 6. 意明净界(manopasāda)——像这样，名明净界只有一种。

全部合起来，明净界共有 (六) 种。 
其中，身明净界是遍布于全身各处而存在的。 
在凡是能够知道触的每一个部位，都有身明净界存在着。 
这是因为能够知道触的身识(kāyaviññāṇa)心，只能依靠身明净界才得以生起。 
包括身明净界在内的 (五) 种色明净界，由于还没有见到空界(ākāsadhātu)，在还没有见到诸色聚(kalāpa)之前，会一直被看成好像是连成一整片的，所以才会把诸明净界见成一团一块、一整片的样子。

Cakkhādipañcavidhaṃ rūpādīnaṃ gahaṇapaccayabhāvena ādāsatalaṃ viya vippasannattā **pasādarūpaṃ**. (Visuddhi, 2, 81.)

依照这段义注的解释，眼净色等这 (五) 种净色，作为能够取得色所缘等各自相应所缘的所依原因，由于像**镜面一样**格外明净，因而获得了**净色(pasādarūpa)**这个名称。(Visuddhi, 2, 81.)

当凭借因摄取观照存在于那明净团块、明净面上的四大界而修习的、与修习(bhāvanā)定(samādhi)相应之智所产生的光线，在那明净面上贯注专注地观照空界直到见到之时，一见到名为诸色聚之间隙孔隙的空界，与此同时，也就会开始见到诸色聚了。

在诸名法当中，有分(bhavaṅga) = 意明净界也同样具有 pabhassara = 闪闪发亮、光芒熠熠而照耀着的光明，处于明净洁白的状态；关于这一点 ---- **Pabhassaramidaṃ bhikkhave cittaṃ,** (Aṃ, 1, 9.) = **诸比库……这有分心闪闪发亮、光芒熠熠地照耀着 = 洁** **白** - 佛陀在《增支部》(Aṅguttara)一集(Ekakanipāta)的《愿求品》(Paṇihitaacchavagga)、《弹指品》(Accharāsaṅghātavagga)中作了如是开示。 
在这里，也是因为在有分心中远离了贪(rāga)、瞋(dosa)、痴(moha)等使心污浊的随烦恼(upakkilesa)诸垢秽而得以清净，佛陀才针对这洁白的样子而作了上面这段圣言的开示。 
所要表达的意思是：在有分心中并没有光线，只是由于远离了垢秽而处于明净清净的状态罢了。 
但是，由于有分心而生起的诸心生食素第八色(cittajaojaṭṭhamakarūpa)中所含的颜色界(vaṇṇadhātu)色所缘(rūpārammaṇa)，以及由存在于每一个心生色聚中的火界(tejodhātu) = 季节(utu)而生起的诸季节生食素第八色(utujaojaṭṭhamakarūpa)中所含的颜色界 = 色所缘，则是与有分心相应之智的威力大就照耀得大、智的威力小就照耀得小，确实是在照耀着的。

《根本复注》(1, 125.)中 ---- Sabhāvo vāyaṃ cittassa paṇḍaratā. 
(1, 95.)中 ---- Atha vā sabbampi cittaṃ sabhāvato paṇḍarameva = **一切心就其本然自性而言都是洁白的** - 像这样解说了它是洁白的、是清净的道理。

Javanakkhaṇe rajjanadussanamuyhanasabhāvānaṃ lobhasahagatādīnaṃ cittānaṃ vasena uppannehi āgantukehi upakkilesehi pakatiparisuddhampi bhavaṅgacittaṃ upakkiliṭṭhaṃ nāma hotīti. (Aṃ, ṭṭha, 1, 46.)

由于门(dvāra)与所缘的相遇撞击，有分流断绝，诸心路(vīthi)心的相续生起；在速行(javana)刹那，凭借那些具有贪着所缘、瞋恨所缘、迷惑所缘之性质的、与贪(lobha)相应而生起的心、与瞋相应而生起的心、与痴相应而生起的心等等诸心的力量而生起的、属于客人的随烦恼诸垢秽，使得本来就是自性洁白清净的有分心成了被污染的了。(Aṃ, ṭṭha, 1, 46.)
