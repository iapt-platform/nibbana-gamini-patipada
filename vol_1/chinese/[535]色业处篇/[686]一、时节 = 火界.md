### 一、时节(utu) = 火界(tejodhātu)

Tattha **utu** nāma catusamuṭṭhānā tejodhātu, uṇhautusītautūti evaṃ panesa duvidho hoti. (Visuddhi, 2, 251.)

在那(五)种之中，凡是由业、心、时节、食这(四)种因法而明显生起的业生色聚(kammaja kalāpa)、心生色聚(cittaja kalāpa)、时节生色聚(utuja kalāpa)、食生色聚(āhāraja kalāpa)，在每一个色聚之中所含的火界，就名为**时节**。 
这个时节有两种：热时节(uṇha utu) = 炎热的时节，冷时节(sīta utu) = 寒冷的时节。(Visuddhi, 2, 251.)

由于业等起的时节等所有(四)种时节，都具有能够令时节生色(utuja rūpa)生起的能力，所以安住在每一个四等起(catusamuṭṭhāna)色聚之中的火界都名为时节 ---- 这是义注(aṭṭhakathā)的西亚多所作的开示。 
这个时节，虽然就其身为火界这一点而言并没有什么差别，但是依着「锐利的状态、迟钝的状态」这样的锐(tikkha)-钝(manda)的殊胜功德差异 ----

- 一、把锐利的 tikkha - 火界称为热时节，
- 二、把迟钝的 manda - 火界称为冷时节 ----

由于是这样称呼的，所以才产生了这样两种的区分差别。(Mahāṭī, 2, 404.) 
在《大复注》(Mahāṭīkā)第二册(108-109)之中，也作了如下的解说。

地(pathavī)、火(tejo)、风(vāyo)这(三)种界的聚合，名为触(phoṭṭhabba)。 
在这个触所缘(phoṭṭhabbārammaṇa)之中，为什么不把水界(āpodhātu)取进来呢？冷的自性法难道不是可以碰触而取得的吗？那个冷的自性法难道不正是水界吗？假若有人这样发问。 
冷的自性法可以碰触而取、能够碰触而取 = 只要碰触试验一下就能知道 ---- 这确实是真的；虽然确实如此，但那个冷的自性法并不是水界。若是这样，那么那个冷的自性法究竟是什么呢？假若有人这样发问 ---- 那只是火界而已。

确实如此 ---- 当热的自性法变得迟钝时，或者说在迟钝的热的自性法之中，「凉」这样的了知就生起了。 
确实如此，名为「凉」的某一种功德性质根本就是不存在的。 
(意思是说：凉只是火界的功德性质而已，并不是除火界之外其他某一种究竟法(paramattha)的功德性质。)

然而实际上，当纯粹的热的自性法的迟钝状态 = 力量微弱的状态明显现起时，「这是冷的自性法」这样的认定就生起了。 
这一层含义应当如何了知呢？假若有人这样发问 ---- 请记住：「凉」这样的了知，就像对此岸与彼岸的了知一样；因为它具有不稳固的性质之故。

假设有一条从北向南流的河，这条河有东岸与西岸这两个岸。 
在那里，对于站在东岸的人来说，东岸就是**「此岸」**，西岸就是**「彼岸」**。 
反过来，对于站在西岸的人来说，西岸成了**「此岸」**，而东岸又成了**「彼** **岸」**。 
所以，此岸、彼岸这些名言(vohāra)并不是恒常稳固的名言。 
同样地，热的自性、凉的自性这些法也不是恒常稳固的法。

让我们把它显明出来 ---- 在极其炎热的夏季，在烈日之下待过之后走进树荫里来的人们，(在树荫之中)会生起「凉」这样的了知。 
但是，从极为凉爽的地下室里(从洞穴里)上来的人们，就在那同一处树荫之地，反而会生起「热」这样的了知。 
所以，热与凉的自性法并不是能够永远固定地加以确定的名言。

还有值得一说的过失 ---- 假若冷的自性法就是水界，那么在同一个色聚之中，热的自性法与冷的自性法就会一同被得到；然而这是得不到的。 
因此，冷的自性法不是水界。 
应当这样了知。 
(意思是说：四大界是这样的不相离色(avinibbhoga rūpa) ---- 它们只有在一个色聚之中共同结合在一起生起的常法，而没有一个一个分开单独生起的常法。假若把水界认定为冷的自性法，那么话就说成了：冷的自性法水界与热的自性法火界在一个色聚之中同时并存地生起。在一个色聚之中，热与凉是没有同时生起的常法的。然而水界与火界，在一个色聚之中却是有同时生起的常法的。所以说：由此就能了知冷的自性法不是水界。)

以上所说的这段话，是为了那些希求、接受大种色(bhūta rūpa)四大界具有不可各别地一个一个分开而生起的性质的诸位善人们而作的解答。 
但是，对于那些不希求、不接受的人们来说，只要看到四大界在一个色聚之中各自执行、成办自己所应负责的本分工作，从而成立了它们具有随顺相合地生起的性质，那么这段话同样也就是解答。

有些阿阇梨说：「冷的自性法是风界(vāyodhātu)的自性相(sabhāva lakkhaṇa)」；对于那些阿阇梨来说，以上所说的这段话同样也就是解答。 
让我们把它显明出来：假若冷的自性法是风界，那么在一个色聚之中，就应当能够得到与热的自性法在一起的冷的自性法；然而这是得不到的。 
因此应当了知：冷的自性法不是风界。 
(热的自性法与冷的自性法在一个色聚之中虽然是得不到、不可能同时得到的，但是火界与风界在一个色聚之中却是同时生起着的不相离法。所以说：由此就能了知冷的自性法不是风界。)

再者，有些阿阇梨持有这样的见解主张：流动的自性法就是水界；那个流动性也是可以碰触而取得的、碰触了就能得到、能够得到的。对于那些阿阇梨，应当这样对他们说：「认为流动的自性法也是可以碰触而得到的这种主张，就像认为形状是可以碰触而得到的那种认定一样，仅仅是诸位尊者的一种主观认定 = 增上慢(adhimāna)的心态而已」——应当这样对他们说。 
确实如此 ---- 古时的诸位大阿阇梨曾经这样宣说过。

“Dravatā sahavuttīni, tīṇi bhūtāni samphusaṃ.

‘Dravataṃ samphusāmī’ti, lokoyamabhimaññati.

Phusaṃ bhūtāni saṇṭhānaṃ, manasā gaṇhate yathā.

‘Paccakkhato phusāmī’ti, ñātabbā dravatā tathā”ti. (Mahāṭī, 2, 109.)

这一切众生，在碰触到与流动的自性法一同生起的、被称为地、火、风的(三)种大种(mahābhūta)时，便这样思量认定：我碰触到了流动的自性法。

就像碰触到诸大种的人以心执取「我是现前地碰触到了形状」一样，对于流动的自性法也应当这样了知。(Mahāṭī, 2, 108-109.)
