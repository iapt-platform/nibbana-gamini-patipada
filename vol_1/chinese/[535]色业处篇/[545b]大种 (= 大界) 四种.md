### 四种大种(mahābhūta) (= 大界)

#### 1. 地界(pathavīdhātu)

| 重地(garupathavī)组 | 轻地(lahupathavī)组 |
| ---------------- | --------------- |
| 1. 坚硬 ...的性质，  | 2. 柔软 ...的性质， |
| 3. 粗糙 ...的性质， | 4. 细滑 ...的性质， |
| 5. 沉重 ...的性质，  | 6. 轻盈 ...的性质， |

Katamaṃ taṃ rūpaṃ phoṭṭhabbāyatanaṃ. Pathavīdhātu tejodhātu vāyodhātu kakkhaḷaṃ mudukaṃ saṇhaṃ pharusaṃ garukaṃ lahukaṃ ...(《阿毗达摩》1、170。《法集论》巴利圣典)

Ettha ca “kakkhaḷaṃ mudukaṃ saṇhaṃ pharusaṃ (sukhasamphassaṃ dukkhasamphassaṃ) garukaṃ lahuka”nti padehi pathavīdhātu eva bhājitā. (《阿毗达摩》注、1、368、段-647。)

- 1. **kakkhaḷa**nti thaddhaṃ = 坚硬 - 的性质，
- 2. **muduka**nti athaddhaṃ = 柔软 - 的性质，
- 3. **pharusa**nti kharaṃ = 粗糙 - 的性质，
- 4. **saṇha**nti maṭṭhaṃ = 细滑 - 的性质，
- 5. **garuka**nti bhāriyaṃ = 沉重 - 的性质，
- 6. **lahuka**nti abhāriyaṃ, sallahukanti attho = 轻盈 - 的性质， (《阿毗达摩》注、1、368。)

#### 2. 水界(āpodhātu)

- 1. dravabhāva = paggharaṇalakkhaṇa = 流泻的性质，
- 2. ābandhanabhāva = ābandhanalakkhaṇa = 黏结的性质，

#### 3. 火界(tejodhātu)

- 1. (甲) uṇhabhāva = uṇhatejo = 炎热的性质，<br>( 乙 ) sītabhāva = sītatejo = 寒冷的性质，
- 2. paripācanabhāva = 使之成熟的性质，

#### 4. 风界(vāyodhātu)

- 1. vitthambhanabhāva = 支撑的性质，
- 2. samudīraṇabhāva = 推动的性质，
