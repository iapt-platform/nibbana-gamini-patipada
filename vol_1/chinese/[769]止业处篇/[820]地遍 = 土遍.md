### 地遍(pathavīkasiṇa) = 土遍

- 1. 已经制作整治成遍轮的土地，

- 2. 还没有制作整治成遍轮的、自然原本的打稻谷的晒场等等的土地，

- 3. 只是有界限范围的土地，

- 4. 并不是没有界限范围的土地，

- 5. 具有小簸箕 = 小托盘、小米筛那么大分量的土地，

- 6. 具有锅盖、罐盖那么大分量的土地 ---在这些土地上都能够取得地遍的相(nimitta)。(《清净道论》(Visuddhimagga)，1，120。)

Tattha yena atītabhavepi sāsane vā isipabbajjāya vā pabbajitvā pathavīkasiṇe catukka-pañcakajjhānāni nibbattitapubbāni, evarūpassa puññavato upanissayasampannassa akatāya pathaviyā kasita-ṭhāne vā khalamaṇḍale vā nimittaṃ uppajjati. (《清净道论》，1，120。)

某一位瑜伽行者(yogāvacara)在过去的往昔诸世当中，或者在佛陀的教法(sāsana)之内，或者在仙人出家(isipabbajjā)的身分之中曾经出过家，并且曾经在地遍上令四分法禅(catukkajjhāna)、五分法禅(pañcakajjhāna)生起过；对于这样一位具有由修习(bhāvanā)而生起的善业功德、巴拉密(pāramī)、福资粮(puññasambhāra)的积聚，具备了强而有力的修习善业这一所依强依止(upanissaya)的尊贵瑜伽行者来说，就像菩萨(bodhisatta)哈提巴喇(Hatthipāla)公子只是看着还没有制作整治成遍轮的恒河(Gaṅgā)水流，就能够轻易地取得水遍(āpokasiṇa)的相一样(《本生》义注，4，483。) -- 同样地，如果在还没有制作整治成遍轮的、自然原本的土地上，或者在犁田耕作的地方，或者在打稻谷的晒场圆场上取遍作相(parikammanimitta)，作「pathavī pathavī = 地、地」这样念诵作意，那么就能够从那遍作相在一刹那之间转变为取相(uggahanimitta)，而获得取相。(《清净道论》，1，120。)

依照上面这些指示，你这位善人如果也想要在地遍上取相，那么请在一处平坦的、没有草、树叶、石子等等过失的自然原本的大地上，或者用木棍、或者用某一件器物，画出一个圆形的图样。 
从小簸箕 = 小托盘、小米筛那么大的分量开始，随你这位善人的意愿想做多大的分量都可以。 
Aruṇavaṇṇāya mattikāya kasiṇaṃ kātabbaṃ. (《清净道论》，1，120。)
依照《清净道论》义注(aṭṭhakathā)这句指示，用来制作遍的那片土地的颜色，应当是不太黑、不太白，带着适度的红色 = 朝霞色(aruṇavaṇṇa)的土色。 
请注视着那个土地的圆轮 ----

pathavī pathavī pathavī = 地、地、地，请这样作意。

请把眼睛一开一闭地做，试着取相看看。 
假如相还是不清楚明显，那么请再一次把入出息念定(ānāpānassatisamādhi)建立起来，直到达到第四禅(catutthajjhāna)为止；或者请把定建立起来，直到达到白遍(odātakasiṇa)第四禅定为止。 
请借助由于那第四禅定而生起的光明的帮助，遥遥地注视自己所制作整治的那个地遍轮的相，作「pathavī pathavī pathavī = 地、地、地」这样作意。 
如果能够像用平常的肉眼看见那样取得了相，就可以到自己喜欢的地方去坐了。 
在这样坐着的时候，也请把自己已经获得的第四禅定再一次建立起来；当光明的能量闪闪发亮、明晃晃地照耀起来的时候，请借助那光明的帮助，再一次遥遥地缘取那地遍相为所缘。 
如果再一次缘取遍轮相为所缘而获得了，那么请一再反复地修习那地遍相。

Na vaṇṇo paccavekkhitabbo, na lakkhaṇaṃ manasikātabbaṃ. 
Api ca vaṇṇaṃ amuñcitvā nissayasavaṇṇaṃ katvā ussadavasena paññattidhamme cittaṃ paṭṭhapetvā manasikātabbaṃ. (《清净道论》，1，121-122。)

在这样作意地遍相的时候，对于安住在那地遍轮上的、与朝霞色相同的颜色色彩，也不应当用意识(manoviññāṇa)去省察、不应当去作意。 
对于那地遍轮所安住的大地的坚硬相(thaddhalakkhaṇa) = 坚硬这一地界(pathavīdhātu)的相，也不应当去作意。
确实应当这样：不放开颜色色彩，而是把那颜色色彩做成与它自己的颜色色彩所依止的地遍轮相同的样子、相似的状态，并且以地界强盛、以能力(satti)超胜的方式，把心朝向安置在「pathavī = 地」这一世间语言概念(lokavohārapaññatti)上，作「pathavī pathavī = 地、地」这样作意。

假如你这位善人去作意安住在地遍轮上的、称为朝霞色的那种颜色色彩，那么它就不再是地遍，而会变成色遍(vaṇṇakasiṇa) = 颜色遍了。 
假如你这位善人作意到地遍轮上强盛显现的地界的坚硬性质，那么就不叫做在作意地遍，而叫做在作意界业处(dhātukammaṭṭhāna)了。 
这就是已经从地遍的道路转到界业处的道路那一边去了。
更为麻烦的一个问题是：如果作意到那地遍轮上存在的坚硬性质，当那地遍轮向十方扩展开去的时候，那坚硬的性质就会变得好像笼罩覆盖着瑜伽行者的整个色身(rūpakāya)一样；并且随着定的力量越来越锐利，坚硬的性质也会越来越强烈，那位瑜伽者善人往往会变得无法忍受那种坚硬的性质。 
请多加注意。 
无论是在自然原本的土地圆轮上取相的时候，或者是在某个地方禅坐、再一次缘取那相为所缘的时候，都请遵守这项规则。

在把眼睛一开一闭地取安住于大地上的原本地遍轮的相时，如果就像用平常张开的眼睛看见遍轮相那样，在闭上眼睛的时候那遍轮相也仍旧显现出来，那么这时候取相就已经生起了。 
再者，当到某个地方去禅坐的时候，也请先把自己已经获得的第四禅定建立起来，然后借助由于那第四禅定而生起的光明的帮助，再一次缘取原先曾经取过相的那个地遍轮相为所缘；这时候如果它像用张开的眼睛看见那样显现出来，那么在那个时候也叫做取相已经生起了。 
如果继续作意、继续修习、继续增长那取相，那么就会依照次第：诸盖(nīvaraṇa)已经被镇伏 = 已经脱离；诸烦恼(kilesa)沉静下来；心以近行定(upacārasamādhi)而变得安定。 
似相(paṭibhāganimitta)就生起了。 
如果把那似相加以增大，或者不使它增大，就这样继续作意下去，那么就能够一直达到第四禅定。
不过，如果把相扩展开去，修习定就能够长久地维持，所以请尽自己的能力把相扩展开去，然后再观照修习直到达到第四禅为止。

在取相当中，手指印、木棍痕等等遍的过失往往还很明显。 
至于似相，则像从袋子里取出来的铜镜面一样，像擦拭得很好的螺贝盘一样，像从云层之间出现的满月轮一样，像在乌云的背景上飞翔的白鹭一样，仿佛冲破取相而出现，比那取相清净洁净上百倍千倍还不止地显现出来。(《清净道论》，1，122。)

依照上面已经撰写陈述过的那样，对于从白遍开始、在其他种种遍上修习定的势力已经变得强盛的某些瑜伽行者来说，甚至不必特地去制作地遍的相轮，只要以白遍等等把定建立到达到第四禅定，当由于那第四禅定的修习心(bhāvanācitta)而使智(ñāṇa)的光明闪闪发亮、明晃晃地照耀起来的时候，就用由于那第四禅修习定而生起的智的光明界，投射到自己禅坐作意时下方或者周围存在的、具有朝霞色的自然原本的大地上，去取地遍相，这样同样也是能够获得的。 
如果一再反复地修习增长那相，就能够依照次第生起三种相、三种修习、三种定。 
当达到似相的时候，请尽自己的能力把相扩展开去，并继续修习增长，直到达到第四禅定为止。
