### 坏灭随观智(bhaṅgānupassanāñāṇa)部分中以比量智(anvayañāṇa)观照的方式

atha vā so evaṃ viratto yathādiṭṭhaṃ saṅkhāragataṃ, tathā adiṭṭhampi anvayañāṇavasena nirodheti, no samudeti.
nirodhatova manasikaroti.
nirodhamevassa passati, no samudayanti attho. (Visuddhi 2, 279.)

**evaṃ viratto**ti evaṃ bhaṅgānupassanānusārena viratto.
yathā diṭṭhaṃ sampati upaṭṭhitaṃ saṅkhāragataṃ nirodheti nirodhaṃ manasikaroti.
adiṭṭhampi atītānāgataṃ anvayañāṇavasena yathā idaṃ etarahi, evaṃ itarepīti anuminanto nirodheti manasikatassāpi nirodhaṃ karoti, **no samudetī**ti etthāpi eseva nayo, no samudayaṃ manasikarotīti attho. (Mahāṭī 2, 442.)

atha vā = 另一种方式则是。
evaṃ = 由于随行此坏灭随观（＝由于顺次趣向此坏灭随观智）。
viratto = 离于贪着的。
so yogāvacaro = 那位修行者(yogāvacara)。
diṭṭhaṃ = 现前所见的，或，迎面显现出来的。
saṅkhāragataṃ = 诸行法(saṅkhāra)。
nirodheti nirodhaṃ manasikaroti yathā = 犹如作意(manasikāra)其灭(nirodha)一般。
tathā = 同样地。
adiṭṭhampi = 也把那未曾见到的过去、未来诸行法。
anvayañāṇavasena = 依比量智的力量。
（etarahi = 于如今现前之时。idaṃ yathā = 犹如此现在(paccuppanna)所见之行一般。evaṃ tathā = 同样地。tampi = 那未曾见到的过去、未来诸行法也是。evaṃ sabhāvameva = 唯有如此灭坏的性质。iti = 如此。anuminanto = 一边比度推知着。）
nirodheti = nirodhaṃ manasikaroti = 作意于灭。
no samudeti = no samudayaṃ manasikaroti = 不作意于集(samudaya)。
nirodhatova = 唯就灭而言。
manasikaroti = 作意。
assa saṅkhāragatassa = 那诸行法的。
nirodhameva = 唯是灭。
passati = 观。
samudayaṃ = 集。
no passati = 不观。(Pyay-Visuddhimagga-nissaya 5, 207-208.)

= 另一种说法——由于顺次趣向此坏灭随观智，对于诸行法（藉由以镇伏断(vikkhambhanapahāna)能将贪(rāga)长久地移离），那位离于贪着、离于贪的修行者，正如把以坏灭随观智现前所知见的、于坏灭随观智中迎面显现出来的诸行法之聚，作意于该诸行法之聚的灭一般；同样地，对以坏灭随观智尚未遇见、尚未见到的过去、未来诸行法之聚，也藉由那能随顺相应地推知的**比量智**之力——“犹如以名为当下现前之坏灭随观智的、即时的**现见智(paccakkhañāṇa)**所见的此诸行法一般，同样地，以名为坏灭随观智的观智(vipassanāñāṇa)尚未见到的过去、未来诸行法，也唯有如此灭坏的性质”——如此这般地比度推知，作意于灭、即灭的性质，不作意于生起、即集。
唯就灭而言 = 唯作意于灭，唯观照那诸行法之聚的坏灭、即灭，不观照生起、即集。
这即是上述《无碍解道》(Paṭisambhidāmagga)巴利圣典的意旨所在。(Visuddhi 2, 279. Mahāṭī 2, 442.)

ārammaṇānvayena, ubho ekavavatthanā.

nirodhe adhimuttatā, vayalakkhaṇavipassanā. (Paṭisaṃ 56.)

ārammaṇānvayena = 由于顺次随行那即时现前所知见的、作为所见(diṭṭha)的所缘(ārammaṇa)。
ubho = 把所见、未见(adiṭṭha)两种所缘。
ekavavatthanā = 也藉由名为刹那坏灭(khaṇabhaṅga)的同一种性质来分辨记取。
nirodhe = 在诸行法刹那不停、绵绵不断地灭坏的刹那灭(khaṇikanirodha)之中。
adhimuttatā = 也是倾注倾向的状态。
esā = 这即是。
vayalakkhaṇavipassanā = 即是观照诸行法的坏灭、即灭之相(vayalakkhaṇā)的观(vipassanā)。

**ārammaṇānvayena ubho ekavavatthanā**ti paccakkhato diṭṭhassa ārammaṇassa anvayena anugamanena yathā idaṃ, tathā atītepi saṅkhāragataṃ bhijjittha, anāgatepi bhijjissatīti evaṃ ubhinnaṃ ekasabhāveneva vavatthāpananti attho.

vuttampi cetaṃ porāṇehi ---

“saṃvijjamānamhi visuddhadassano,

tadanvayaṃ neti atītanāgate.

sabbepi saṅkhāragatā palokino,

ussāvabindū sūriyeva uggate”ti. (Visuddhi 2, 280.)

**ubho**ti diṭṭhādiṭṭhabhāvena dvepi ārammaṇāni.
**ekavavatthanā**ti khaṇabhaṅguratāya samānāti vavatthāpanā.
**saṃvijjamānamhī**ti paccakkhato upalabbhamāne paccuppanne.
**visuddhadassano**ti bhaṅgadassanassa paribandhavidhamanena visuddhañāṇo, suvisuddhabhaṅgadassanoti attho.
**tadanvayaṃ netī**ti tassa paccuppannasaṅkhāra-bhaṅgadassino ñāṇassa anvayaṃ anugatabhūtaṃ ñāṇaṃ pavatteti.
kattha pana pavattetīti āha “**atīta-nāgate**”ti.
atīte, anāgate ca saṅkhāragate.
**sabbepī**tiādi tassa pavattanākāradassanaṃ. (Mahāṭī 2, 443.)

ñātañca ñāṇañca ubhopi vipassati. (Visuddhi 2, 278.)

**ārammaṇānvayena ubho ekavavatthanā** ——以现见的方式（＝以现见智）亲身当下、洞穿而知见的、已观见的、名为所知(ñāta)的苦谛(dukkhasacca)法与集谛(samudayasacca)法，以及名为智的（即所谓世间道谛(lokiyamaggasacca)法的）观智——由于顺次随行这名为所知智(ñātañāṇa)的行之所缘，正如以坏灭随观智即时所见而知见的此现在法(paccuppannadhamma)、即行法坏灭一般，同样地，过去诸行法之聚也已坏灭、将来未来也将坏灭——如此，把以观智已观见的所见之所缘、以观智尚未观见的未见之所缘这两种所缘，唯藉由这刹那坏灭、即刹那不停、绵绵不断地坏灭这一相同的性质，好好地加以记取。
这即是其意旨、意义所在。
确实如此——古代的义注(aṭṭhakathā)诸位大长老曾如此宣说这段话。——

saṃvijjamānamhi. pa. uggate.（参见上文。）

saṃvijjamānamhi = 在以现见的方式、以所获得的现见智所知见的现在法诸行法之聚中（＝意即所见之法）。
visuddhadassano = 那位具有格外清净的、观照诸行法之坏灭(bhaṅga)的坏灭随观智之见的修行者。
tadanvayaṃ = 把顺次随行那观照该现在法诸行法之坏灭、即灭的坏灭随观智而生起的观智。
atīte = 于作为过去的诸行法中，
anāgate = 于作为未来的诸行法中，
neti = 引带 = 令其生起。
sabbepi = 无余而悉皆一切的、
saṅkhāragatā = 过去行、未来行、现在行这些诸行法之聚，
palokino = 皆具有坏灭的性质。
kimiva = 若问犹如何者——sūriye = 太阳，
uggate = 当升起之时，
ussāvabindu = 露珠，
palokatīva = 犹如消散坏灭一般。(Visuddhi 2, 280.)

= 那位在以现见方式所获得的现见智所知见的、名为所见的现在法诸行法之聚中观照其坏灭、即灭，具有格外清净的坏灭随观智之见的修行者，将顺次随行那观照该现在法诸行法之坏灭、即灭的坏灭随观智而生起的观智，在过去诸行法、未来诸行法之中引入此方法，即令观智生起。
凡是无余悉皆一切的过去、未来、现在诸行法，都具有坏灭的性质。
若问犹如什么呢——犹如被日光一照便消失的露珠一般。(Visuddhi 2, 280. Mahāṭī 2, 443.)

**nirodhe adhimuttatā = 于刹那灭(khaṇanirodha)中的倾注**

**nirodhe adhimuttatā**ti evaṃ ubhinnaṃ bhaṅgavasena ekavavatthānaṃ katvā tasmiññeva bhaṅgasaṅkhāte nirodhe adhimuttatā taggarutā tanninnatā tappoṇatā tappabbhāratāti attho.
**vayalakkhaṇavipassanā**ti esā vayalakkhaṇavipassanā nāmāti vuttaṃ hoti. (Visuddhi 2, 280.)

**bhaṅgasaṅkhāte nirodhe**, na nibbānasaṅkhāteti adhippāyo.
**esā**ti yā ārammaṇanvayena ubho diṭṭhādiṭṭhe khaṇabhaṅguratāya ekabhāvena vavatthāpanā, esā vayalakkhaṇe vipariṇāmalakkhaṇe **vipassanā** bhaṅgānupassanāti attho. (Mahāṭī 2, 443.)
