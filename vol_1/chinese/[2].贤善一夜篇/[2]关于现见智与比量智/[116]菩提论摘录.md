### 菩提论(Bodhikathā)摘录

菩萨(bodhisatta)在大历(Mahāsakkarāja)一〇三年咖颂月(Kason)满月日、日落之前战胜天子魔(devaputtamāra)之后，于那一夜的初夜分证得宿住随念神通智(pubbenivāsānussati-abhiññāṇa)，于中夜分证得天眼(dibbacakkhu)神通智，于后夜分证得漏尽智(āsavakkhaya-ñāṇa)，达到了佛陀(Buddha)之位。

那时，佛陀就在菩提树下的无能胜(aparājita)座上，整整七天以同一个结跏趺坐，领受着阿拉汉果(arahattaphala)、解脱(vimutti)的殊胜大安乐而安住。
于咖颂月满月后第一日，于初夜分、于中夜分、于后夜分 ---

Avijjāpaccayā saṅkhārā, saṅkhārapaccayā viññāṇaṁ. …pe…
Evametassa kevalassa dukkhakkhandhassa samudayo hoti.
Avijjāya tveva asesavirāganirodhā saṅkhāranirodho, saṅkhāranirodhā viññāṇanirodho. …pe…
Evametassa kevalassa dukkhakkhandhassa nirodho hoti. (Vi. 3. 1.)

因无明(avijjā)生起，诸行(saṅkhāra)生起；因行生起，识(viññāṇa)生起。…pe…
如此，这全然不掺杂安乐的、纯粹的苦(dukkha)蕴、苦聚之生起因相与集起相，便明显地显现出来。
唯有由于无明因阿拉汉道(arahatta magga)而无余地灭尽，诸行的寂灭才得以发生；由于行的寂灭，识的寂灭才得以发生。…pe…
如此，这全然不掺杂安乐的、纯粹的苦蕴、苦聚之灭因相与灭相，便明显地显现出来。(Vi. 3. 1.) ---

如此，佛陀既以作为轮回流转之苦(saṃsāra-vaṭṭa dukkha)生起过程的**随顺(anuloma)**，又以作为轮回流转之苦灭尽过程的**逆(paṭiloma)**，作意缘起(paṭiccasamuppāda)之性质法。

在初夜分，佛陀依上述那样顺逆地作意诸缘起之性质法完毕之后，便诵出第一自说偈(udānagāthā)；在中夜分作意完毕之后，诵出第二自说偈；在后夜分作意完毕之后，诵出第三自说偈。关于此，《律藏大品注释书(Vinaya-Mahāvagga-aṭṭhakathā)》如此解说： ---

Bhagavā hi visākhapuṇṇamāya rattiyā paṭhamayāme pubbenivāsaṁ anussari, majjhimayāme dibbacakkhuṁ visodhesi, pacchimayāme paṭiccasamuppādaṁ anulomapaṭilomaṁ manasi katvā "idāni aruṇo uggamissatī"ti sabbaññutaṁ pāpuṇi. Sabbaññutappattisamanantarameva ca aruṇo uggacchi, tato taṁ divasaṁ teneva pallaṅkena vītināmetvā sampattāya pāṭipadarattiyā tīsu yāmesu evaṁ manasi katvā imāni udānāni udānesi. (Vi. Ṭṭha. 3. 237.)

= 佛陀（=菩萨）在大历一〇三年咖颂月满月日之夜的初夜分，以宿住随念神通智顺次追溯、忆念昔日曾住过的诸蕴(khandha)相续；在中夜分令天眼神通智得以清净；在后夜分顺逆地作意、观修缘起时 ---"如今太阳即将升起了"这般可说的时刻，抵达了殊胜的一切知智(sabbaññuta-ñāṇa)。就在抵达殊胜一切知智之后紧接着，太阳也升起了。此后，佛陀整日仍以那结跏趺坐坐着，让时间流逝，直至到来的出关第一日=咖颂月满月后第一日之夜，于夜的三分中，如此顺逆地作意缘起之性质法完毕之后，诵出了这些自说偈。 ---

- 1. Yadā have pātubhavanti dhammā, ātāpino jhāyato brāhmaṇassa.

Athassa kaṅkhā vapayanti sabbā, yato pajānāti sahetudhammaṁ. (Vi. 3. 2.)

ātāpino = 具有能猛烈镇压、逼恼一千五百种烦恼(kilesa)的正勤(sammappadhāna)勤奋精进(vīriya)者。
jhāyato = 对入出息(ānāpāna)等种种止(samatha)的所缘，以及对种种色(rūpa)、名(nāma)法之行的无常(anicca)、苦、无我(anatta)之行相特征，在安止(appanā)时能抵达禅那(jhāna)道，专注深入、格外坚固地强力观照者。
（vā，或）由于强力观照之故。
brāhmaṇassa = 由于已舍离一切恶行，得名清净婆罗门(visuddhi-brāhmaṇa)的阿拉汉(arahanta)尊主大德的相续流(santāna)中。yadā = 于所指之时。
dhammā = 三十七种菩提分(bodhipakkhiya)诸法。
have = 确实。
pātubhavanti = 明显地生起、显现而来。
yato = 由于如此三十七种菩提分诸法明显生起、显现而来之故。
sahetudhammaṁ = 连同以无明为首的诸因法，以及以行为首的诸果法聚集——苦蕴。
pajānāti = 以观慧(vipassanāpaññā)与道慧(maggapaññā)分辨清晰地穿透了知。
atha = 于如此确切、清晰明了地了知缘起之时。
assa = 那位阿拉汉尊主大德的相续流中。
sabbā = 无一遗漏、全部一切的。
kaṅkhā = 对缘起法的疑惑——即由于不了知该缘起法，而对三时中生起的色、名诸法所起的十六种疑惑之法。
vapayanti = vi-apayanti = 如同霜雪在烈日下消融般，消退、寂灭止息。

- 2. Yadā have pātubhavanti dhammā, ātāpino jhāyato brāhmaṇassa.

Athassa kaṅkhā vapayanti sabbā, yato khayaṁ paccayānaṁ avedi. (Vi. 3. 2.)

ātāpino = 具有能猛烈镇压、逼恼一千五百种烦恼的正勤勤奋精进者。
jhāyato = 对入出息等种种止的所缘，以及对种种色、名法之行的无常、苦、无我之行相特征，在安止时能抵达禅那道，专注深入、格外坚固地强力观照者。
（vā，或）由于强力观照之故。
brāhmaṇassa = 由于已舍离一切恶行，得名清净婆罗门的阿拉汉尊主大德的相续流中。
yadā = 于所指之时。
dhammā = 三十七种菩提分诸法。
have = 确实。
pātubhavanti = 明显地生起、显现而来。
yato = 由于如此三十七种菩提分诸法明显生起、显现而来之故。
paccayānaṁ = 以无明为首的诸因法之。
khayaṁ = 作为真实尽灭处的无为(asaṅkhata)涅槃(nibbāna)殊胜法。
avedi = 已穿透地、清晰明了地了知。
atha = 于如此确切、清晰明了地了知诸因法之尽灭处——即得名缘尽(paccayakkhaya)的无为界(asaṅkhata-dhātu)、涅槃究竟法(paramattha)——之时。
assa = 那位阿拉汉尊主大德的相续流中。
sabbā = 无一遗漏、全部一切的。
kaṅkhā = 由于未能穿透、清晰明了地了知无为界、寂静界(santi-dhātu)的涅槃殊胜法，而将在内心生起的种种疑惑之法聚。
vapayanti = vi-apayanti = 如同霜雪在烈日下消融般，消退、寂灭止息。

- 3. Yadā have pātubhavanti dhammā, ātāpino jhāyato brāhmaṇassa.

Vidhūpayaṁ tiṭṭhati mārasenaṁ, sūriyova obhāsayamantalikkhaṁ. (Vi. 3. 2.)

ātāpino = 具有能猛烈镇压、逼恼一千五百种烦恼的正勤勤奋精进者。
jhāyato = 对入出息等种种止的所缘，以及对种种色、名法之行的无常、苦、无我之行相特征，在安止时能抵达禅那道，专注深入、格外坚固地强力观照者。
（vā，或）由于强力观照之故。
brāhmaṇassa = 由于已舍离一切恶行，得名清净婆罗门的阿拉汉尊主大德的相续流中。
yadā = 于所指之时。
dhammā = 三十七种菩提分诸法。
have = 确实。
pātubhavanti = 明显地生起、显现而来。
（tadā = 那时。）sūriyo = 从育甘塔拉山(Yugandhara)之巅升起、显现出来的太阳。
antalikkhaṁ = 空旷无遮的虚空天际。
obhāsayaṁ = obhāsayanto = 以自身的千道光芒驱除黑暗、照耀闪亮着。
tiṭṭhati iva = 犹如安住着一般。
（so brāhmaṇo = 那位阿拉汉尊主大德。tehi dhammehi = 以那三十七种菩提分诸法。）mārasenaṁ = 将染污的感官之乐(kāmarāga)等十重的魔军。
vidhūpayaṁ = vidhūpayanto = 彻底粉碎地击破、消灭着。
tiṭṭhati = 以承载慧(paññā)的殊胜智(ñāṇa)光芒，如日轮般辉煌闪耀、光芒四射地安住着。(Vi. 3. 2.)（《大佛史(Mahābuddhavaṁsa)》第二册，357–361。）
