### 另一种方法的八种功德支

**一、入定（samāhita）** ---- 心相续（santati）藉着第四禅那（jhāna）之定（samādhi）而善加安定着。

**二、遍净（parisuddha）** ---- 由于远远地远离了盖（nīvaraṇa）的污垢，心相续前前后后、周围一切处都是清净的。

**三、洁净（pariyodāta）** ---- 由于已经善加超越、越过了能使心震动惊怖的寻（vitakka）、伺（vicāra）、喜（pīti）、乐（sukha）这些粗重的禅支之法，所以心相续光辉闪闪、光芒灿烂地放出光亮，洁净而明澈。

[**注** ---- 在这个方法中，把「远离那些能使心污浊的诸盖」称为遍净；把「远离那能使心动摇的寻、伺，能使心显得明显突出的喜，以及能对快乐的所缘作意、能感受快乐的乐」称为洁净。 
虽然初禅那确实唯有远离了诸盖才能获得，但初禅那对诸盖的远离，并不像这第四禅那这样远。 
同样地，虽然第二禅那离了寻、伺，第三禅那离了喜，但都不像这第四禅那这样彻底脱离。 
因此，才唯独把这第四禅那解说为「遍净」、「洁净」。（大义疏（Mahāṭī），2，8。）] 

**四、无烦恼烙印（anaṅgaṇa）** ---- 由于没有那些以「获得禅那」为因缘而生起的、以卑劣的欲望而潜入的慢（māna）、诳（māyā）、谄（sāṭheyya）等等不善（akusala）的污垢，所以远离了不善的污垢。（《清净之道》，2，6。）

以「获得禅那」为因缘，还可能生起一种自视甚高的慢。
还可能生起一种带着慢的欲求：「世尊在大众中间开示法（dhamma）的时候，若是能一再地只问我：『比库（bhikkhu）……你对这个法有什么看法呢？』这样来开示法，那该多好啊。」 
也可能生起想要掩盖明显过失的诳；也可能生起把没有的功德装作有的谄。 
那一整类慢、诳、谄之法，名为「恶愿行（pāpaka icchāvacara）」，也就是种种卑劣的恶欲。 
这些法虽然不像诸盖那样粗重，但由于能使心相续污浊，所以是被称为「烦恼烙印（aṅgaṇa）」的微细不善法。（大义疏，2，8-9 ---- 参见。） 

**五、离随烦恼（vigatūpakkilesa）** = 对于贪求（abhijjhā）等等能使心污浊的随烦恼（upakkilesa）法，也是远离的。（所谓贪求，就是贪（lobha），是一种想要、贪着。那种贪，是还没有达到欲欲盖（kāmacchanda nīvaraṇa）程度的、对自己的禅那心生喜爱的微细的贪，是初禅那所无法断除的那一类微细的贪。在「贪求等等」这句话里，「等等」一词所指的，正是微细的慢、诳、谄等等。大义疏，2，8-9。）

**六、柔软（mudubhūta）** ---- 由于已经修习并熟练掌握了五种自在（vasī），所以是柔软的。

**七、适业（kammaniya）** ---- 由于已经成为各种神变（iddhi）的基础，所以对于随自己心意而与法相关的种种修习（bhāvanā）之事，都能良好而容易地去做。

**八、住立（ṭhita） - 不动摇（āneñjappatta）** ---- 由于作为「把修习之心导向神通智（abhiññāṇa）的所缘、或者观（vipassanā）的所缘等等所希求的所缘」之基础的第四禅之定的修习已经圆满充足，又由于以「除此之外再没有对第四禅之定应做的工作」这样的力量，那作为「能引领人趣向正等正觉智（sammāsambodhi ñāṇa）、独觉菩提智（paccekabodhi ñāṇa）、弟子菩提智（sāvakabodhi ñāṇa）之中任何一种菩提智」的一切波罗蜜（pāramī）法之总和、也就是至上愿（abhinīhāra）所堪任的那种定的修习已经圆满，所以那第四禅之定在接下来的修习工作场域中已被引向「主导（padhāna）= 居于主导地位」的状态；正因如此，这个定由于「殊胜」的含义、以及「令人不知满足」的含义，而趋近于崇高殊胜的状态，因此没有动摇，坚韧牢固地稳固住立着。（对于把心送往种种神变（iddhividha）等等种种神通智那一方面，它也是恰到好处的。对于把心送往观智、道智、果智那一方面，它也是恰到好处的。像这样恰到好处的第四禅之定的修习，就称为至上愿堪能修习（abhinīhārakkhama bhāvanā）。由于那至上愿堪能修习已经圆满，所以那第四禅之定的修习在种种止（samatha）观修习的工作场域中都居于主导地位。这个定既是殊胜的，也能令人不知满足。无论入定多久，都不会有「够了、满足了」这回事。因此它趋近于崇高殊胜的状态。像这样，这第四禅之定由于成为至上愿堪能修习而周遍圆满，因而趋近于崇高殊胜的状态，达到了不动摇的状态，所以坚韧牢固地稳固住立着 —— 这就是它的意思。）（《清净之道》，2，6。大义疏，2，9。） 

具足这八种支分的第四禅之定，对于把修习之心导向种种神变（= 以神通力变化）等等的神通智修习、观的修习等等种种修习之事，都是堪任而现成的。 
如果你这位禅修者（yogī）善人，为了以观智亲见现证那些应当以观智亲见现证的法，而把你这位禅修者善人的修习之心的相续导向观智的所观所缘那一方面，那么对于作为观智所观所缘的苦谛（dukkhasacca）之法、集谛（samudayasacca）之法，也就是色＋名＋因＋果 = 行（saṅkhāra）法，就能够很容易地了知。 
原因就在于，第四禅之定对于种种至上愿都是堪任的。

在那些能通往自己所志求的正等正觉智、独觉菩提智、弟子菩提智等等菩提智的一切波罗蜜法之中，这些神通智的修习、观的修习也都是包含在内的。

以上就是与第四禅的八种功德支相关的种种解说。 
依照这些解说，把上面第（502）页所引出的 ----

so evaṃ samāhite citte parisuddhe. pa. ayaṃ dukkhanirodhagāminī paṭipadāti yathābhūtaṃ pajānāti —— 这段巴利圣典简要地翻译出来，就是这样。

那位已经获得第四禅的瑜伽行者（yogāvacara），当他这样安定的第四禅之心

一、由于那能把心平等地、善加安置在如入出息（ānāpāna）似相（paṭibhāganimitta）那样的种种似相所缘上的、名为中舍性（tatramajjhattatā）心所的舍（upekkhā）所引生的念（sati）已经清净洁净，因而周遍清净了之后，

二、正由于周遍清净，因而具有光辉闪闪、灿烂夺目的光彩之后，

三、由于藉着「较长时间地把作为贪（rāga）之因的乐受、悦受（somanassa vedanā），以及作为瞋（dosa）之因的苦受、忧受（domanassa vedanā）抽离开来」这样的舍断，也就是镇伏断（vikkhambhanapahāna），而把它们舍断了，因而具有「贪、瞋这样的污垢已被消除、已被抽离」的状态，所以没有贪、瞋这样的污垢之后，

四、（贪、瞋等等的烦恼（kilesa）会使心热恼、会折磨心，会使心污浊。）正由于没有贪、瞋这样的烦恼污垢、已经清净，因而远离了那些能使心热恼、能折磨心的烦恼之后，

五、正由于已被善加培育、善加修习，因而变得柔软之后（= 意思是说，已经达到对五种自在的熟练掌握之后），

六、正由于已经变得柔软，因而在「为了了知四谛而努力精勤」的四谛业处（catusacca kammaṭṭhāna）修习等等种种修习之事上已经堪任、已经相宜之后，

（就像经过冶炼、锻打、提纯而变得纯净的黄金，在制作念珠、耳环等等种种物件时都恰到好处一样，柔软的心在种种修习之事上也是恰到好处的。 
那「柔软（mudu）」与「于修习之事上的堪任（kammaniyaṃ）」这两者，也是唯有由于为了使那第四禅之定达到五种自在的熟练掌握而
善加修习了它，才得以生起的。）

七、由于第四禅之定具有柔软柔韧、以及在修习之事上的堪任，所以它随顺自己的心意（想住一分钟两分钟就住一分钟两分钟，想住一小时两小时就住一小时两小时，如此等等，随顺自己的心意）而安住，因而随顺自己的心意安住了之后，

八、由于被信（saddhā）、精进（vīriya）、念、定、慧（paññā）这五根（indriya）所支持，因而达到了不动不摇的状态之后 ----

那位比库便为了作为诸漏（āsava）法之尽灭处、名为漏尽（āsavakkhaya）的阿拉汉道智（arahattamagga ñāṇa）而使心倾向于它 = 把心引导过去；那位比库 ----

- 一、如实地了知：「这是苦圣谛（dukkha ariyasacca）之法。」
- 二、如实地了知：「这是苦之生起因的集圣谛之法。」
- 三、如实地了知：「这是苦之息灭的灭圣谛之法。」
- 四、如实地了知：「这是通往苦之息灭的涅槃（nibbāna）的行道（= 道圣谛）之法。」（中部，1，347。）（依照《清净之道》，2，5 的注释而翻译。）

想要以这第四禅之定为基础而转入观的你这位瑜伽行者，必须把自己已经获得的第四禅之定反复熏修，直到它具足上述八种功德支。 
必须练习到达到五种自在、熟练掌握五种自在；必须练习到使第四禅之定成为被五根牢固支持的定。 
必须练习到它光辉闪闪、灿烂夺目地放出光明为止。 
唯有这样，对于「摄受名为苦谛的五蕴（khandha）、名为集谛的因-果-相续的缘起（paṭiccasamuppāda）本质之法，并以智慧加以分辨」这样种种修习之事，才会变得堪任；对作为观智所观所缘的那些名为苦谛之法、集谛之法的行法加以作意，也就是「观执持（vipassanābhinivesa）」这项大工程，才会获得成功。 
唯有这样，才能够就那些行法继续修习观的修习业处。
