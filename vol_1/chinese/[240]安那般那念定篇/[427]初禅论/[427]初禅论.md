## 初禅论

在此，继续介绍《清净之道》(Visuddhi Magga)义注(aṭṭhakathā)中所说的「初禅论」等禅那(jhāna)部分的各项内容。

对于以上面已经分别解说过的方式，凭借使精进(vīriya)与定(samādhi)达到平衡相应的力量，令修习(bhāvanā)之心沿着正确的修习轨道前行，并把修习之心朝向入出息似相(ānāpāna paṭibhāga nimitta)驱策的那位禅修者(yogāvacara)来说，此时到了可以说「安止禅(appanā jhāna)即将圆满、即将生起」的那一段速行(javana)轮转之节，有分(bhavaṅga)心的相续、有分心的流动被截断，接着就以「assāsa-passāsa = 入息、出息」这样勤修用功的修习之力，取那个依附于修习之心而显现出来、依附而安立下来的入出息似相为所缘，意门转向(manodvārāvajjana)心生起。
在那个意门转向(= 省察并确定入出息似相所缘的心)之后，或者生起四次、或者生起五次的速行接连地速行下去。
在那四次或五次的速行当中，最后的那一个速行是色界(rūpāvacara)速行。(《清净之道》，1，134。)

有 = 有分 = 有分意明净界 = 为了使一期生命中的心相续不致中断，作为生命的因法而给予助益的心；

波 = 有分波动(bhavaṅgacalana) = 当入出息似相所缘在有分意明净界中显现的时候，
波动起来的有分；

断 = 有分断绝(bhavaṅgupaccheda) = 当入出息似相所缘在有分意明净界中显现的时候，
有分波动之后，由于初学者的禅那心路的心相续即将生起而停止下来的有分、
断绝了的有分；

意 = 意门转向 = 对显现于有分意门即意明净界中的入出息似相
加以省察的心；

遍 = 遍作(parikamma) = 为了使安止禅速行得以生起而作准备的欲界(kāmāvacara)速行；

近 = 近行(upacāra) = 生起于安止禅速行的近旁、在其邻近处运转的欲界速行；

顺 = 随顺(anuloma) = 在这个安止速行心路落下之前，取入出息似相为所缘、
观照入出息修习的那些速行心路，称为遍作。对于那些遍作
也好、对于上面的安止禅也好，都能相顺应的欲界速行；

种= 种姓(gotrabhu) = 能够超越、胜过欲界的族类，而令广大(mahaggata)的族类增长的
欲界速行；

禅 = 安止禅速行；(色界速行)

最初所得的禅那心路生起的情形是这样的 ---- 由于一再地观照入出息似相，临近获得禅那的时候，入出息似相的所缘就在有分 = 意门中显现出来；于是有分波动、有分断绝、意门转向，在钝慧者是遍作、近行、随顺、种姓这样四次近行定(upacāra samādhi)速行，在利慧者则是近行、随顺、种姓这样三次 - 此后安止定(appanā samādhi)速行生起一次，在它落下之时心路便中断，能够生起多少有分就生起多少有分。(这里是依循心路的基本准则而说的。有些论著中只用「有分」一词，而不用「有分波动」、「有分断绝」这样的说法。)
