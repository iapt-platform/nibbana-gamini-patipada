### 《牛喻经(Gāvī upamā sutta)》摘录

诸比库(bhikkhave)……譬如说，有一头愚痴的、不熟练的、对于放牧吃草的牧场情况没有认识了解的、对于在崎岖不平的山上四处游走吃草不善巧的、在山上吃草的母牛。（有一天，那头母牛从山顶的一处远远眺望的时候，看见了一个被青翠湿润的青草与树叶围绕着的、有着清澈之水的大水池。）在那头母牛的心里就生起了这样的念头 - 「我若能到达还不曾到过的地方，若能吃到还不曾吃过的草，若能喝到还不曾喝过的水，那该多好啊」。 
那头母牛（在从山顶往下走的时候），没有把前脚好好地踏稳在能够牢牢立住的落脚处上，就抬起了后脚；那头愚痴的母牛（由于从山上滚落下去），既不能到达还不曾到过的地方，也吃不到还不曾吃过的草，也喝不到还不曾喝过的水，而且连它曾经想过「我若能到达还不曾到过的地方，若能吃到还不曾吃过的草，若能喝到还不曾喝过的水，那该多好啊」的那个原来所住的山顶之处，也不能安稳地回去了。

之所以会变成这样，是什么缘故呢 - 诸比库……这是因为那头母牛愚痴而不熟练，对于放牧吃草的牧场情况没有认识了解，对于在有着崎岖不平地面的山地上四处游走并不善巧，却仍旧在山上吃草的缘故。

诸比库……正如这个譬喻一样，在这个教法(sāsanā)之中，（由于不知道要把定(samādhi)的危难敌害彻底扫除清净）愚痴的、（由于对于使自己达到能够娴熟自在地修习禅那(jhāna)的状态这件事没有通晓了解）不熟练的、（由于不知道在下下层禅那中的自在(vasī)娴熟正是上上层禅那最切近的原因法 = 足处(padaṭṭhāna)）对于自己放牧吃草的牧场情况不了解的、（并且总的说来，由于没有入禅定(jhāna samāpatti)的善巧熟练之能力）不善巧的比库(bhikkhu) - 唯有远离了事欲(vatthukāma)与烦恼欲(kilesakāma)，唯有远离了诸不善(akusala)法，才证得并安住于与思虑 = 寻(vitakka)、审察思惟 = 伺(vicāra)俱在的、由于远离诸盖(nīvaraṇa)而生起的、有喜悦 = 喜(pīti)、有安乐 = 乐(sukha)的初禅(paṭhama jhāna)。

那位比库对于那个相(nimitta)（即初禅定，以及作为获得那初禅定之因的入出息似相(ānāpāna paṭibhāganimitta)），不去一再地亲近、不去修习、不去多多地反复练习，也不为了令它好好地稳固持续而努力建立。

在那位比库的心里就生起了这样的念头 - 「我若能由于思虑 = 寻、审察 = 伺的止息，而证得并安住于那种能令自己内在的内相续(ajjhatta santāna)之中的心澄净、能增长殊胜的心专注 = 定的、没有思虑 = 寻与审察思惟 = 伺的、由心专注 = 定所生起的、有喜悦 = 喜、有安乐 = 乐的第二禅(dutiya jhāna)，那该多好啊」。

那位比库却无力由于思虑 = 寻、审察思惟 = 伺的止息，而证得并安住于那种能令自己内在的内相续之中的心澄净、能增长殊胜的心专注 = 定的、没有思虑 = 寻与审察思惟 = 伺的、由心专注即定所生起的、有喜悦 = 喜、有安乐 = 乐的第二禅。

在那位比库的心里又生起了这样的念头 - 「我若能唯有远离了事欲与烦恼欲，唯有远离了诸不善法，而证得并安住于与思虑 = 寻、审察思惟 = 伺俱在的、由于远离诸盖而生起的、有喜悦 = 喜、有安乐 = 乐的初禅，那该多好啊」。

那位比库唯有远离了事欲与烦恼欲。中略。却无力证得并安住于初禅。

诸比库……就像那头愚痴的、不熟练的、对于放牧吃草的牧场情况没有认识了解的、对于在崎岖不平的山上四处游走吃草不善巧的、在山上吃草的愚痴母牛一样，对于这位比库，也应当说他是从（初禅与第二禅这）两方面都滑落败坏的人、从两方面都退失减少的人。（增支部，3，216。）

像这样，对于自己已经获得的现有禅那，还没有为了达到自在娴熟 = 纯熟精通而先去修习，就为了向上层禅那攀升而努力，那么既会从现有的禅那退失，也不能够向上层禅那攀升上去；因此，这位瑜伽行者(yogāvacara)补特伽罗(puggala)首先应当就在那现有的、当前的初禅之中，成为以五种方式修练亲近过了的、能够娴熟自在地修习的人（= 成为在五种自在上修练到娴熟精通的人）。
