### 三种善 十种相

- 一、行道清净(paṭipadāvisuddhi) = 成为到达初禅(paṭhamajjhāna)之因的行道的清净，称为初禅的「开始」。 
在那开始当中有三种相。

- 二、舍的增长(upekkhābrūhanā) = 中舍性舍(tatramajjhattupekkhā)的增长，称为初禅的「中间」。 
在那中间当中有三种相。

- 三、身心舒畅(sampahaṃsanā) = 喜悦、明净，称为初禅的「结尾」。 
在那结尾当中有四种相。

如此，在初禅当中就有三种善、十种相。其情形如下。

**行道清净** ---- 取极为明亮光耀的入出息似相(ānāpāna paṭibhāganimitta)为所缘，把修习(bhāvanā)之心平静地贴附在那入出息似相所缘上，继续建立入出息念定(ānāpānassati samādhi)的时候，在某一个速行心路(javana vāra)当中，安止禅速行(appanā jhāna javana)便生起了。 
在那安止速行心路当中，被称为盖(nīvaraṇa)的那些烦恼(kilesa)法的聚集，正是那初禅的危难；初禅心从被称为盖的那些禅那(jhāna)的危难中清净了出来。（一）

由于从名为盖的禅那危难中清净了，所以远离了那能够遮蔽覆盖、使人不能获得禅那的盖（舍离了盖），于是就修习了处于中间的止相(samatha nimitta)。

**Majjhimaṃ samathanimittaṃ** nāma samappavatto appanāsamādhiyeva. (Visuddhi, 1, 144.)

修习之心不至于从入出息似相所缘退缩、也不至于散逸，因而保持均衡运转的安止禅定(appanā jhāna samādhi)本身，由于不落入所谓心从修习所缘退缩、散逸这两种极端，所以正是处于中道的适中止相(majjhima samathanimitta)。 
那初禅的安止禅定，也由于是上上诸禅等种种殊胜之法、尊贵之法的根本原因，所以才获得了「止相」这个名称。

以「毫无间隔地施予助益」而说的无间缘力(anantarapaccaya satti)来施予助益的、先前生起的种姓(gotrabhu)心，依着令同一名法相续(santati)转向、变化而成的同一性(ekatta)方法，如实地依安止禅定之力而达到善加安定的状态（＝达到以那安止禅定的行相而生起），因此就称为修习了适中止相，也称为到达了适中止相。（二）

由于这样修习，由于这样到达了适中止相，因而达到了以那安止禅定的行相而生起，所以就称为趣入了那止相。〔就在到达适中止相的那一剎那，由于达到了具有这样安定行相的安止禅定的状态，以安止禅定而达到了心安定的状态，所以称为趣入了那适中止相。〕（三）

依照上面已经说过的方法，在最先、先前生起的种姓心当中明显存在的 ----

- 一、从盖的诸危难中清净，
- 二、到达适中止相，
- 三、趣入那适中止相 ---- 应当知道：唯有依着在能令这些成就的初禅正在生起的那个生起(uppāda)剎那中一路走来的行道(paṭipatti)之力，才说为行道清净。
<r>（《清净之道》(Visuddhi Magga)，1，144。《大义疏》(Mahāṭī)，1，173。）</r>

**舍的增长** ---- 由于已经从盖等垢秽中清净了的那初禅心，不再有需要再一次修治使之清净的情形，所以对于修治使之清净这件事不再作努力(byāpāra)的修行者(yogāvacara)，就称为对已从盖等垢秽中清净了的初禅心保持舍置。（一）

由于已经到达了止的状态，那正沿着止的常轨、正道运转的初禅心，对于要再一次把它调得均衡妥善这件事不再作努力的修行者，就称为对正沿着止的常轨、正道运转的初禅心保持舍置。（二）

再者，正因为它正沿着止的常轨、正道运转，所以已经舍弃了与烦恼的结合、没有烦恼为伴而单独安住的那安止禅心，对于要再一次使它离开烦恼之伴、单独地安住，换句话说，对于要使它稳固地安住在具有单一自性的入出息似相所缘上这件事不再作努力的修行者，就称为对那没有烦恼为伴、单独安住着的安止禅心保持舍置。 
如此，应当依着中舍性舍心所(cetasika)的作用之力，来了知舍的增长
= 中舍性舍的增长。（三）

**身心舒畅** ---- 再者，在这样由中舍性舍所增长的那初禅心当中一同相应生起的、被称为定(samādhi)与慧(paññā)的（由于彼此互不超越，各自作各自相关的工作，就像共轭在同一根轭上被系结在一起的两头牛一样）配成一对的那些法，彼此互不超越地生起了。（一）

再者，信(saddhā)、精进(vīriya)、念(sati)、定、慧这五根(indriya)，由于从种种烦恼中解脱了出来，所以就以「从烦恼中解脱」这一作用而具有相同的作用，如此地生起了。（二）

再者，这位修行者生起了与那些情形 ---- 定、慧二者彼此互不超越，以「从烦恼中解脱」这一作用而具有相同的作用 ---- 相应的精勤精进；并且在那初禅心的坏灭(bhaṅga)剎那当中，也有重复(āsevana)生起。（超过了生起的生时，从住(ṭhiti)时开始，就称为有重复。《大义疏》，1，174。） 
一切全部生起的、以彼此互不超越等为首的、在禅那心当中一同生起的定、慧等诸法所生起的那些行相(ākāra)，是这样的：由于事先就以遍护智慧(pārihāriya ñāṇa)（＝在一切事上善巧娴熟的智慧）了知了污染(saṃkilesa)与净化(vodāna)两方面 ---- 既了知因污染而将招致的那些过失，也了知因净化而将获得的那些利益功德(ānisaṃsa)，所以依着种种不同的行相，定、慧诸法的彼此互不超越等就能够生起；由于依着那些行相入出息念定的修习得到了喜悦，由于正是以那遍护智慧作了修治，由于周遍地得到了净化，所以它们就都已经完成了。
因此 ----

Dhammānaṃ anativattanādibhāvasādhanena pariyodāpakassa ñāṇassa kiccanipphattivasena sampahaṃsanā veditabbā. (Visuddhi, 1, 145.)

= 应当依着「令称为定、慧的诸法(dhamma)彼此互不超越等的情形得以完成」这一点，依着那能修治、能令净化的智(ñāṇa)之作用的完成之力，来了知身心舒畅 = 喜悦、明净 ---- （《清净之道》，1，145。）中就是这样说的。（三）

在那入出息念定的修习之心当中，依着中舍性舍之力，智变得明显。
《无碍解道》(Paṭisambhidā Magga)巴利圣典（221）中是这样开示的。

「依着某种行相被精进所策励、所支撑的（入出息念定的）修习之心，不会在修习的工作当中落入懈怠(kosajja)这一边；依着这样的行相，由于一再地串习那些作为精进觉支(vīriyasambojjhaṅga)之依处的因法，被精进所策励的修习之心，无论精进怎样策励，都是依着「使精进与定保持均等而相应」之力而被策励的，所以它善加地（对入出息似相所缘）保持着舍置。 
依着对入出息似相所缘保持舍置的中舍性舍之力，也依着先前生起的、在一切事上善巧娴熟的遍护慧之力，那洞察着与安止禅相应的入出息似相所缘的慧根(paññindriya)显得格外强盛。 
正因为那慧根的强盛，对于均等地舍置入出息似相所缘的人来说，依着能够舍置的中舍性舍之力，修习之心便从以盖为首的种种烦恼中解脱了出来。 
依着从烦恼中解脱之力，依着洞察入出息似相所缘的慧之力，慧根显得格外强盛。 
由于从烦恼中解脱了，那些具有信、慧、定、精进的诸法就具有了相同的 = 均等的作用；如此，由于诸根具有相同的 = 均等的作用，初禅的入出息念定的修习便生起了。」（《无碍解道》，221。） 

像这样，由于依着舍(upekkhā)之力智的作用变得明显，所以就把作为安止慧之作用而生起的、令修习之心喜悦这件事，解释为初禅定的结尾。（四）（《清净之道》，1，145。） 

如此，那唯有依着三种到达初禅之行道的清净 = 行道清净之力才能获得的、以初禅为殊胜尊贵之法的，又借着三种（能均等舍置入出息似相所缘的）中舍性舍的增长而具足强盛的，并且由于慧根有着超胜的程度而分为四种的 ---- 令修习之心喜悦、明净的身心舒畅，就这样完成了。因此 ----

- 一、作为到达初禅之行道的、一路走来的行道清净当中有三种相，
- 二、增长中舍性舍的舍的增长当中有三种相，
- 三、作为智之作用的、修习之心的喜悦、明净的身心舒畅当中有四种相 ----
- 
应当知道：这三种善、十种相，是唯有在初禅当中才能获得的诸法。（《大义疏》，1，175。）
