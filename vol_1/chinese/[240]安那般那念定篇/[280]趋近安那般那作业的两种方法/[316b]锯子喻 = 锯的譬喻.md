### 锯子喻(kakacūpamā) = 锯的譬喻

nimittaṃ assāsapassāsā, anārammaṇamekacittassa.

ajānato ca tayo dhamme, bhāvanānupalabbhati.

nimittaṃ assāsapassāsā, anārammaṇamekacittassa.

jānato ca tayo dhamme, bhāvanā upalabbhatīti. (《无碍解道》，169。《清净之道》，1，273。)

**nimitta**nti upanibandhananimittaṃ nāsikaggaṃ mukhanimittaṃ vā. **anārammaṇamekacittassā**ti assāsapassāsānaṃ ekakkhaṇe appavattanato ekassa cittassa tayopi ārammaṇaṃ na honti, nimittena saha assāso passāso vāti dveyeva ekakkhaṇe ārammaṇaṃ hontīti attho. 
**ajānato ca tayo dhamme**ti nimittaṃ assāso passāsoti ime tayo dhamme ārammaṇakaraṇavasena avindantassa. (《疑惑度脱》，1，216-217。)

= (1) 观照入息(assāsa)-出息(passāsa)的修习(bhāvanā)心所系缚之处，即鼻端或上唇这一相(nimitta)，(2) 入息，(3) 出息，这三种法并不是一个心的所缘(ārammaṇa)。 
即使这样并非同一个心的所缘，但对于不能以取为所缘的方式了知这三种法的人来说，是无法获得入出息念定(ānāpānassatisamādhi)之修习的。

[**注** ---- 由于入息与出息不会在一个心识刹那(cittakkhaṇa)之内同时生起，所以相、入息、出息这三种法不可能成为一个心的所缘。 
一个心无法同时了知这三种法。 
相与入息，以及相与出息，则能够在一个心识刹那之内成为一个心所了知的所缘。 
因此意思是说：虽然在一个心识刹那之内这三种法不会同时生起，所以不能成为一个心所了知的所缘，但对于不同心识刹那(nānācittakkhaṇa)(＝各别的心识刹那)来说，它们是能够成为所了知的所缘的。 
还请记住：这段话是就尚未到达似相(paṭibhāganimitta)之前的时段而说的。 
请参看第346-347页。]

(1) 观照入息-出息的修习心所系缚之处，即鼻端或上唇这一相，(2) 入息，(3) 出息，这三种法并不是一个心所了知的所缘；即使这样并非所了知的所缘，也唯有对了知这三种法的人，才能获得入出息念定的修习。(《无碍解道》，169。)

此外，在《无碍解道》(Paṭisambhidāmagga)巴利圣典中，还以下面这样的问答方式，对入出息的作业范围继续作了解说与阐明。

- 1. 这三种法是如何地不成为一个心所了知的所缘呢？
- 2. 这三种法是如何地并非不显现于修行者(yogāvacara)的了知之智中呢？
- 3. 如何才不会陷入心的散乱呢？ 
- 4. 努力修习入出息念定的精进(vīriya)又是如何变得明显的呢？ 
- 5. 如何能够成就那能舍离盖(nīvaraṇa)的禅那(jhāna)呢？ 
- 6. 如何能够获得那能断除结(saṃyojana)的道(magga)呢？

譬如说，在平整的地面上放着一根木头。 
有个男子用锯去锯断那根木头。(请记住：这里指的是一个人用单向锯独自锯着木头。) 
以锯齿触碰木头之力，那男子的念(sati)显现了；他并不作意那些朝自己这边(向自己一侧)过来的锯齿，也不作意那些朝另一边去的锯齿。 
虽然不作意，但朝自己这边(向自己一侧)过来的锯齿、朝另一边去的锯齿，也并非不显现(意思是说：并非不知道那些锯齿，而是知道的)。
锯断木头的精进也很明显，锯断木头的努力也得以完成。

- 1. 如同放在平整地面上的那根木头一样，同样地，应当记住以念系缚住的入息、出息所触碰之处，即鼻端或上唇这一相。(意思是说：木头与相相同。)
- 2. 如同那些锯齿一样，同样地，应当记住入息与出息。(意思是说：锯齿与入息、出息相同。)
- 3. (甲) 如同以锯齿触碰木头之力而使那男子的念显现那样(意思是说：如同只把心专注在锯齿所触碰的木头上那样)，<br> ( 乙 ) 如同对拉动时朝自己一侧过来的锯齿、推动时朝另一边去的锯齿都不作意那样，<br> ( 丙 ) 如同拉动时朝自己一侧过来的锯齿、推动时朝另一边去的锯齿也并非不显现那样，<br> (丁) 如同锯断木头的精进也很明显那样，<br> ( 戊 ) 如同锯断木头的努力也得以完成那样，<br> 正与这个譬喻相同——<br>(甲) 那位修行的比库(bhikkhu)把念安置于鼻端，或者上唇之端而坐着。 <br> ( 乙 ) 对向内进来的入息、向外出去的出息都不作意。(意思是说：不沿着被称为入息、出息行经之路的内侧与外侧，让心一路追随而去。) <br> ( 丙 ) 向内进来的入息、向外出去的出息，并非不显现于了知之智中，而是显现的。 <br> (丁) 精进显现了，<br> ( 戊 ) 也成就了禅那，<br> ( 己 ) 也获得了那能断除结的道，<br> (庚) 名为精勤(padhāna)的精进也生起了。

**精勤**——是什么呢？具足所修精进的人，其身与心都适宜于入出息念定修习之业，这就称为精勤。

**加行(payoga)**——是什么呢？具足所修精进的人，舍弃了那些使心污浊、障碍并阻断禅那与道果的随烦恼(upakkilesa)与盖，寻(vitakka)也止息了，这就称为加行。

**殊胜(visesa)**——是什么呢？具足所修精进的人，结消失了，潜伏(anusaya)之界也离去了，这就称为殊胜。

如此，相、入息、出息——这三种法并不是一个心的所缘；虽然这样不成为一个心的所缘，但这三种法并非不显现于修行者的智(ñāṇa)中，而是显现的。

如果不显现，那么心就会从入出息业处(kammaṭṭhāna)的所缘散乱到其他所缘上去；能够成就入出息念定修习的精进也将不再显现；能够舍离盖的垢秽、能带来并生起有力之定(samādhi)的修习努力——加行，修行者也将无法完成。 
但事实并非如此：正因为相、入息、出息——这三种法显现于修行者的智中，心才不散乱而变得安定；能够成就入出息念定修习的努力与精进也变得明显了；能够舍离盖的垢秽、能带来并生起有力之定的修习努力——加行，修行者也能够完成了；那能断除结的、层层递进的世间的(lokiya)、出世间的(lokuttara)种种功德利益之殊胜，也都能够获得了。(《无碍解道》，169-170。Pyi，2，248-249——参看。)

ānāpānassati yassa, paripuṇṇā subhāvitā.

anupubbaṃ paricitā, yathā buddhena desitā.

so imaṃ lokaṃ pabhāseti, abbhā muttova candimā. (《无碍解道》，170。)

= 正如正等正觉的佛陀(Buddha)所宣说、开示、教导的那样，以长、短等等(16)种次第，依次周遍地学习入出息念定的修习，并善加培育增长；由于这样修习，藉由(16)种事的圆满而在一切方面都圆满地修行的那位修行者比库，就像脱离了雾、霭、云、烟、尘等一切污浊而清朗出来的月亮一样，能以慧的光明、智的光辉照耀这五蕴等名色法行的世间，光辉灿烂、璀璨闪耀，如同月轮一般安住、庄严——这就是它的意思。(《无碍解道》，170。)
