### 无碍解道巴利圣典的解说

在《无碍解道》(Paṭisambhidāmagga)巴利圣典中，也以问答的方式对平息(passambhaya)的生起情形作了如下的解说与开示。(Paṭisaṃ, 183.)

要怎样努力，才算是「我要平息粗的身行(kāyasaṅkhāra)而吸入入息」呢？要怎样努力，才算是「我要平息粗的身行而呼出出息」呢？

所谓的身行，是指哪些呢？

1. 长的入息生起于身，[**kāyikā**ti rūpakāye bhavā (Paṭisaṃ, ṭṭha, 2, 113. Mahāṭī, 1, 324) = 意思是说：入息(出息)是依靠名为不净所生身(karajakāya)的、由大种色(bhūtarūpa)与所造色(upādārūpa)构成的色身(rūpakāya)=色法的聚集而生起的。] 那些法(=那些入息)由于与身(=名为不净所生身的色法聚集)相连结 = 由于是相互关联着生起的，并且由于是被那不净所生身所造作的，所以称为身行。 
由于是在平息、在灭除、在使那些身行达到寂止，所以说为「努力」。(意思是说：使粗的身行逐层变得柔细、逐层止息。)

2. 长的出息生起于身(依靠名为不净所生身的色法聚集)，那些法(=那些出息)由于与身(=名为不净所生身的色法聚集)相连结 = 由于是相互关联着生起的，并且由于是被那不净所生身所造作的，所以称为身行；由于是在平息、在灭除、在使那些身行达到寂止，所以说为「努力」。

3. 短的入息……略……

4. 短的出息……略……

5. 修习到对入息的起始-中间-末尾整体都清楚明白地了知，如此保持下来的那些入息……略……

6. 修习到对出息的起始-中间-末尾整体都清楚明白地了知，如此保持下来的那些出息生起于身(=依靠名为不净所生身的色法聚集)。 
那些法(=修习到对起始-中间-末尾整体都清楚明白地了知、如此保持下来的那些出息)由于与身(=名为不净所生身的色法聚集)相连结 = 由于是相互关联着生起的，并且由于是被那不净所生身所造作的，所以称为身行；由于是在平息、在灭除、在使那些身行达到寂止，所以说为「努力」。

由具有如下性质的、粗的身行使身(=色身)产生 ----

- 1. ānamanā = 由后向前(=朝前方)的弯曲，
- 2. vinamanā = 朝两胁(=朝两侧)的弯曲，
- 3. sannamanā = 朝四周充分地弯曲，另一种说法 - 过度地弯曲，
- 4. paṇamanā = 由前向后的弯曲，
- 5. iñjanā = 略微朝前的晃动，
- 6. phandanā = 略微朝胁侧的晃动(=颤动)，
- 7. calanā = 略微朝四周的晃动，
- 8. pakampanā = 略微朝后的晃动 ----

这样的情形是存在的。「我要平息具有那样性质的、粗的身行而吸入入息」——这样地努力、这样地修习。 
「我要平息具有那样性质的、粗的身行而呼出出息」——这样地努力、这样地修习。

由具有如下性质的身行使身产生 ----

- 1. 不由后向前(=朝前方)弯曲，
- 2. 不朝两胁弯曲，
- 3. 不朝四周充分地弯曲，
- 4. 不由前向后弯曲，
- 5. 不略微朝前晃动，
- 6. 不略微朝胁侧晃动，
- 7. 不略微朝四周晃动，
- 8. 不略微朝后晃动 ----

这样的情形是存在的。「我要平息具有那样性质的、寂静微细的身行而吸入入息」——这样地努力、这样地修习。 
「我要平息具有那样性质的、寂静微细的身行而呼出出息」——这样地努力、这样地修习。

假如按照上面所说的这些不同方式，以「我要平息极为柔细微细的身行而吸入入息」的心态去努力、去修习；假如以「我要平息极为柔细微细的身行而呼出出息」的心态去努力、去修习；若是这样的话 ----

- 1. 以入息、出息为所缘而贴附了知的修习心(bhāvanā citta)，其生起与增长将不会发生。 
- 2. 由于修习的力量而变得微细柔和的入息、出息已经止息消失，因此对微细的入息、出息的增长与生起，也将不会发生。 
- 3. 正因为入息、出息不存在，与以那入息、出息为所缘的修习心相应的入出息念(ānāpānassati)，其增长与生起也将不会发生。 
- 4. 正因为以入出息(ānāpāna)为所缘的入出息念不生起，与那入出息念相应的入出息念定(ānāpānassati samādhi)，其增长与生起也将不会发生。 
- 5. 有智慧的善人们也就不可能进入以那入出息为所缘的禅定(jhāna samāpatti)。 
- 6. 由于不可能这样入定，也就不会有从以那入出息为所缘的禅定中出定这回事。 ----

这是质难的说法。

假如按照上面所说的这些情形，以「我要平息身行而吸入入息」的心态去努力、去修习；假如以「我要平息身行而呼出出息」的心态去努力、去修习；这样一层层地平息、灭除粗而又粗的身行时 ----

- 1. 以入息、出息为所缘而贴附了知的修习心，其生起与增长便能发生。 
- 2. 由于修习的力量而变得微细柔和的入息、出息虽然止息消失了，对入息、出息的增长与生起仍然能够发生。 
- 3. 与以入出息为所缘的修习心相应的入出息念，其增长与生起也能够发生。 
- 4. 与以入出息为所缘的入出息念相应的入出息念定，其增长与生起也能够发生。 
- 5. 因此，有智慧的善人们也就能够进入以那入出息为所缘的禅定。 
- 6. 由于能够这样入定，也就能够从以那入出息为所缘的禅定中出定。

前面所说的那种修习次第——一层层地止息粗而又粗的身行，从而增长比柔细微细更加柔细微细的身行——应当如何理解呢？ ----

就可以拿来作比较的世间譬喻来说 -- 敲击铜锣的时候，最先生起的是粗重刺耳的声音；由于对粗重刺耳的声音的所缘之相(这声音是这样的)好好地取住、好好地作意、好好地记在心里，所以即使粗重刺耳的声音灭去了，其后微细轻小的、一层层响下去的声音仍会生起。

由于对微细轻小的、一层层响下去的声音的所缘之相好好地取住、好好地作意、好好地记在心里，所以即使微细轻小的、一层层响下去的声音灭去了，其后以微细的声音之相为所缘的心仍会生起；正如这样 ----

与这个譬喻完全一样：最先生起的是粗重的入息、出息；由于对粗重的入息、出息的所缘之相好好地取住、好好地作意、好好地记在心里，所以即使粗重的入息、出息灭去了，其后微细的入息、出息仍会生起。

由于对微细轻小的入息、出息的所缘之相好好地取住、好好地作意、好好地记在心里，所以即使微细的入息、出息灭去了，其后以微细的入息、出息之相为所缘的修习心仍在生起，而不会陷入散乱。 
这样发生的时候 ----

- 1. 以入息、出息为所缘而贴附了知的修习心，其生起与增长确实发生了。 
- 2. 由于修习的力量而变得微细柔和的入息、出息虽然止息消失了，对入息、出息的增长与生起仍然发生了。 
- 3. 以入出息为所缘的入出息念，其增长与生起也发生了。 
- 4. 与以入出息为所缘的入出息念相应的入出息念定，其增长与生起也发生了。 
- 5. 因此，有智慧的善人们确实进入了以那入出息为所缘的禅定。 
- 6. 由于能够这样入定，也确实能够从以那入出息为所缘的禅定中出定。

在「passambhayaṃ kāyasaṅkhāraṃ = 平息身行」等等这样开示的巴利圣典语句中 ----

入息、出息(=呼吸身(assāsapassāsakāya)、色身、名身(nāmakāya))称为身(kāya)。 
念(sati)由于能贴附并安住于那呼吸身(色身、名身)这个所缘，所以称为建立(upaṭṭhāna)；能够一再反复观照那身的慧(paññā)，称为智(ñāṇa)。

身由于是念所贴附安住之处，所以称为建立，而不称为念。 
念由于能贴附并安住于(三种身这个)所缘，所以既称为建立；由于能忆持所缘，所以也称为念。 
凭借那念、凭借那智，对那三种身一再反复地观照，因此说为「于身随观身的念处修习(kāye kāyānupassanā satipaṭṭhānabhāvanā)」。(Paṭisaṃ, 183-184.)
