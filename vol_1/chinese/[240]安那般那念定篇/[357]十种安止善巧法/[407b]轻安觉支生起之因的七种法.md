### 轻安觉支(passaddhisambojjhaṅga)生起之因的七种法

apica satta dhammā passaddhisambojjhaṅgassa uppādāya saṃvattanti paṇītabhojanasevanatā, utusukhasevanatā, iriyāpathasukhasevanatā, majjhattapayogatā, sāraddhakāyapuggalaparivajjanatā, passaddhakāyapuggalasevanatā, tadadhimuttatāti. (Visuddhi, 1, 130. Dī, Ṭṭha, 2, 382. M, Ṭṭha, 1, 300-301. Saṃ, Ṭṭha, 3, 199.)

- 一、成为得以受用殊胜食物的人，
- 二、成为得以受用与自己相称、能带来安乐的气候(utu)的人，
- 三、成为得以受用与自己相称、能带来安乐的威仪(iriyāpatha)的人，
- 四、成为具有安住于中庸这一性质的加行(payoga)的人，
- 五、成为回避身心带有热恼之人的人，
- 六、成为亲近身心寂静清凉之人的人，
- 七、成为为使那轻安觉支之法明显生起而坚定不移地深入、具有倾向与朝向的心态的人 ----

这七种法，正是使轻安觉支之法明显生起的因法。

**一、受用殊胜食物(paṇītabhojanasevanatā)** = 成为得以受用殊胜食物的人 ----

了知自己身体在当前修行时刻所处的状况之后，按适当的分量取用的、营养充足、富含滋养、与自己相宜(sappāya)的殊胜食物，能够促成身体的轻快、身体的柔软、五蕴之身与修习(bhāvanā)工作相称而顺适等等，因此它便成为心与心所(cetasika)的寂静清凉——轻安觉支之法明显生起的因法。(大复注，1，158。)

**二、受用安乐的气候(utusukhasevanatā)** = 成为得以受用与自己相称、能带来安乐的气候的人 ----

在寒冷的气候(sīta utu) = 冷的气候、炎热的气候(uṇha utu) = 热的气候当中，得以受用与自己相宜的气候的修行者(yogāvacara)的相续流(santāna)中，那气候能够促成身体的轻快、身心的柔软、身心与修习工作相称而顺适等等。 
那气候以强而有力的所依——强依止力(upanissaya satti)给予着帮助。因此，在得以受用与自己相称、能带来安乐的气候的修行者的相续流中，轻安觉支之法也能明显地生起增长。
<r>(中部义注，1，301。大复注，1，158。)</r>

**三、受用安乐的威仪(iriyāpathasukhasevanatā)** = 成为得以受用与自己相称、能带来安乐的威仪的人 ----

在卧、坐、立、行四种威仪当中，得以受用相宜威仪的修行者的相续流中，自己所受用的相宜威仪能够促成身体的轻快、身心的柔软、身心与修习工作相称而顺适等等，因此那相宜的威仪便成为心与心所的寂静清凉——轻安觉支之法明显生起的因法。(大复注，1，158。)

至于某一类人，他是具有名为大丈夫(mahāpurisa)的殊胜男子品格的人，对于一切气候、一切威仪都是能够堪忍的。 
针对这类具有名为大丈夫的殊胜男子品格的人，并不是在说"要受用这种相宜的、能带来安乐的气候，要受用相称的、能带来安乐的威仪"这样的话。 
对于某一位修行者而言，有相称的同分气候(sabhāga utu)、相称的同分威仪(sabhāga iriyāpatha)，以及不相称的非同分气候(visabhāga utu)、不相称的非同分威仪(visabhāga iriyāpatha)这两类；唯有这一类人，若回避不相称的、属于非同分的气候与威仪，而受用相称的、属于同分的气候与威仪，那么在这个人的相续流中，轻安觉支之法便能明显地生起。(长部义注，2，383。中部义注，1，301。相应部义注，3，199。)

以上所说的 ---- (一)食物相宜(bhojana sappāya) = 相称的食物，(二)气候相宜(utu sappāya) = 相称的气候，(三)威仪相宜(iriyāpatha sappāya) = 相称的威仪，受用这三种相宜(= 相称适宜)，凭借它成就了五蕴之身在止(samatha)观(vipassanā)修习上的堪任与相称顺适，从而也担负起心在修习上的堪任与相称顺适，因此它便成为身轻安(kāyapassaddhi) = 心所的寂静清凉，与心轻安(cittapassaddhi) = 心的寂静清凉，这两种轻安的因法。(相应部复注，2，437-438。)

**四、中庸加行(majjhattapayogatā)** = 成为具有安住于中庸这一性质的加行的人 ----

省思无论是自己还是他人，唯有业(kamma)才是自己所拥有的财产——这样的省思就称为中庸加行(majjhattapayoga) = 具有安住于中庸这一性质的加行。
执取"有情(satta)们所获得感受的种种苦乐(= 乐(sukha)、苦(dukkha))都是无因(ahetuka) (= 没有原因)的"，这种见解是一边的极端。 
执著相信"是由主宰者(issara) = 自在者、大梵天(mahābrahmā)等创造而生起的"这种不正确的因，这种见解也同样是另一边的极端，也称为低劣之法。 
不趋近这两边的极端、这两种低劣之法，而认为"有情们所获得感受的种种苦乐，是随着属于自己财产的业、依着业而生起的"——这种正确的正见(sammādiṭṭhi)见解，就称为中庸的中道行道(majjhima paṭipadā)之行程、中道行(majjhima paṭipatti)。 
因此，具有接受并相信业与业果这一加行的人，就称为具有中庸加行的人。

[**注释** ---- 所谓加行，就是努力精勤。这里是指为了使接受并相信业与业果之法的正见主张在自己身上确立而作的努力精勤。]

确实如此 ---- 这种接受并相信业与业果的中庸加行，成为已断除热恼之身、即所谓寂静清凉的轻安之身(passaddhakāya)的因法，从而能够担负起心与心所的寂静清凉——身轻安与心轻安这两种。
<r>(长部义注，2，383。相应部义注，3，199。相应部复注，2，438。)</r>

见到某个有情正在感受乐受(sukha vedanā)时，若能作意"这是由于他的善业(kusala kamma)才获得感受这种乐受"；见到某个有情正在感受苦受(dukkha vedanā)时，若能作意"这是由于他的不善业(akusala kamma)才获得感受这种苦受"——那么这样的作意就称为如理作意(yoniso manasikāra)，也称为中庸加行；在具有这样的如理作意与中庸加行的人的相续流中，那时心与心所处于安详清凉的状态，这是只要实地留意、探究观察、依循实践就能知道的事。 
因此，在具有中庸加行的人的相续流中，轻安觉支之法便能明显地生起。

如此，正因为中庸加行 = 具有中庸的加行，能够担负起心与心所的寂静清凉——身轻安与心轻安这两种，所以义注(aṭṭhakathā)才把回避身心带有热恼的人、亲近依止身心寂静清凉的人，解说为能促使那轻安觉支之法明显生起的因，应当这样记取。(相应部复注，2，438。)

**五、远离身热恼之人(sāraddhakāyapuggalaparivajjanatā)** = 成为回避身心带有热恼之人的人 ---- 某一类人以石块、棍棒等折磨他人而四处游荡；在回避这种性质的、身心带有热恼的人的那个人的相续流中，

**六、亲近身轻安之人(passaddhakāyapuggalasevanatā)** = 成为亲近身心寂静清凉之人的人 ---- 在亲近依止那手足有所防护、身心寂静的人的那个人的相续流中，

**七、彼胜解(tadadhimuttatā)** = 成为为使那轻安觉支之法明显生起而坚定不移地深入、具有倾向与朝向的心态的人 ---- 在为了使卧、坐、立、行四种威仪中心与心所的寂静清凉——轻安得以生起，而坚定不移地深入安住、作意倾向朝向于此的人的相续流中 ----

轻安觉支之法便能明显地生起。
