###　喜觉支(pītisambojjhaṅga)生起之因的十一种法

- 一、一再地忆念增长佛陀(Buddha)的功德的佛随念(buddhānussati)，
- 二、一再地忆念增长法(dhamma)的功德的法随念(dhammānussati)，
- 三、一再地忆念增长圣僧团的功德的僧随念(samghānussati)，
- 四、一再地忆念增长自己的戒(sīla)不破不缺等功德的戒随念(sīlānussati)，
- 五、一再地忆念增长自己布施舍离的功德的舍随念(cāgānussati)，
- 六、把天神们的信(saddhā)等法置于见证的地位，一再地忆念增长自己的信等法的神随念(devatānussati)，
- 七、一再地忆念增长涅槃(nibbāna)寂静清凉的功德的止息随念(upasamānussati)，
- 八、成为回避内心粗劣之人的人，
- 九、成为亲近心地柔和细腻之人的人，
- 十、成为省察值得净信的诸经(suttanta)的人，
- 十一、成为为使喜觉支生起而坚定不移地深入、具有倾向与朝向的心态的人

这十一种因法，正是使喜觉支之法明显生起的因法。(清净道论，1，129。长部义注，2，382。中部义注，1，300。相应部义注，3，198。)

一、**佛随念** = 一再地忆念佛陀的功德 ----

在一再反复忆念佛陀功德、修习增长佛随念修习(bhāvanā)业处(kammaṭṭhāna)的修行者(yogāvacara)的相续流(santāna)中，若能修习到近行修习、达到近行定(upacāra samādhi)，那么喜觉支之法便能遍布全身而明显生起。(长部义注，2，382。中部义注，1，300。相应部义注，3，198。)

其意思是这样的。 
以佛陀的功德为所缘(ārammaṇa)、为达到近行定而修习的修习善心速行(javana)的相续，使得那些殊胜微妙的心生色(cittajarūpa)不断生起，它们遍布全身、充满全身，接连不断地持续生起。 
在那被称为意门(manodvārika)大善速行心路(vīthi)的心相续中，每一个修习善心里都含有喜(pīti)，都与喜相应；而那喜也同样是以佛陀的功德为所缘的。 
因此，由于佛陀的功德以所缘缘(ārammaṇa paccaya)之力饶益、促成喜觉支之法明显生起，所以一再反复忆念佛陀功德的佛随念修习，就成了喜觉支之法明显生起的一个原因。 
应当记住：以那佛陀功德为所缘、与喜相应的修习善心所生的殊胜微妙的心生色遍满全身、接连不断地持续生起——正是这一点，被诸义注说成「喜觉支之法遍布全身而生起」。 
其原因在于：那佛随念的修习心，以及与那修习心相应的喜，都只能依止心所依处色(hadayavatthu rūpa)才得以生起。[应当记住：由于佛随念等不能引生、不能获得安止(appanā)禅那(jhāna)，所以上述诸义注中才说「yāva upacāra = 直到近行定为止」。]
(**sakalasarīraṃ pharamāno**ti pītisamuṭṭhānehi paṇītarūpehi sakalasarīraṃ pharamāno. 中部复注，1，388。)

**二、法随念** ---- 在一再反复忆念四种道(magga)、四种果(phala)、涅槃、教理(pariyatti)这十种崇高法的功德的法随念修习业处上勤修的修行者的相续流中，

**三、僧随念** ---- 在一再反复忆念圣僧团那毫不迂回曲折、笔直地行走于通往道、果、涅槃的善妙行道的「善行道(suppaṭipanna)」等功德的僧随念修习业处上勤修的修行者的相续流中，

**四、戒随念** ---- 在长久的日日夜夜之中不使毁损断绝而守护的 <br> (甲) 守护持守律(vinaya)的训练要素(sikkhāpada)这一巴帝摩卡防护戒(pātimokkhasaṃvarasīla)，<br> ( 乙 ) 为使贪(rāga)-瞋(dosa)-痴(moha)等烦恼(kilesa)不从眼-耳-鼻-舌-身-意这六门六道大门侵入，而始终把自己的心纳入某一个业处所缘之中加以守护看护，这就是根防护戒(indriyasaṃvarasīla)，<br> ( 丙 ) 对四种资具作省察(paccavekkhaṇā)之后再受用，这就是资具依止戒(paccayasannissitasīla)，<br> (丁) 在活命方面恭敬地遵行佛陀所制定的诸训练要素，使活命清净而加以圆满修习，这就是活命清净戒(ājīvapārisuddhisīla) ----

在省察这四类四全面净化戒(catupārisuddhisīla)的戒随念修习业处上勤修的修行者比库(bhikkhu)的相续流中，

若是在家的瑜伽善士，那么在以在家的身份不使毁损断绝而守护的十戒或五戒上加以省察的戒随念修习业处上勤修的在家修行者的相续流中，

**五、舍随念** ---- 在粮食短缺、饥荒饿馑这一严重灾难降临的时节等情形下，把殊胜美好的食物布施供养给同修梵行的道友之后——「像这样殊胜美妙的食物，我已经布施出去了」——像这样省察布施舍离的舍(cāga)之法的舍随念修习业处上勤修的修行者比库的相续流中，

若是在家的瑜伽善男子，那么在以在家的身份、于遇到这样粮食短缺饥荒饿馑等严重灾难的时节时，省察自己布施给持戒善士们的布施(dāna)的舍随念修习业处上勤修的修行者的相续流中，

**六、神随念** ---- 那些具足信、戒、闻(suta)、舍、慧(paññā)等善士之财这些功德的天神们，已经获得了天神的身份、到达了天神的生存；像这样，能够使人到达那样的天神生存、天神身份的信、戒、闻、舍、慧等善士之财这些功德，在自己身上也同样明显具备——省察这一点的神随念修习业处上勤修的修行者的相续流中，

**七、止息随念** ---- 以禅那等至(samāpatti)所排除镇伏的诸烦恼，即使经过六十至七十年这样长的时间，也不会再好好地在上面一层层地生起出现——像这样省察诸烦恼的寂静清凉、即有余依涅槃(saupādisesa nibbāna)之功德的止息随念修习业处上勤修的修行者的相续流中，喜觉支之法都能够明显生起。

samuddo mayā diṭṭho = 我看见了大海 --- 在这样的话语中，把看见大海的一小部分说成是看见了整个大海，因而说「我看见了大海」，这样的说法在世间上是明显存在的；与此相同，把诸行(saṅkhāra)法的一部分的寂静清凉，当作是一切行法的寂静清凉，也就是以诸行法之一部分——诸烦恼被禅那等至以镇伏断(vikkhambhanapahāna)的方式较长时间地排除、舍断——为所缘，来修习止息随念修习业处，这正是上述义注所指示教导的。 
像这样，由于作为诸行法一部分的禅那等至的力量，以镇伏断的方式洞察了知诸烦恼较长时间的寂静清凉的慧之法；以这慧之法所生起的诸烦恼的寂静清凉这一止息功德为所缘而修习的止息随念修习的作意(manasikāra)，也具有能够以镇伏断的方式把诸烦恼较长时间排除开的力量，因而能够引生近行定；由于引生了近行定，具足了那样的欢喜愉悦之喜与悦(somanassa)之法，所以它就成为喜觉支之法明显生起的一个原因。(中部复注，1，388。)

**八、避开粗野者(lūkhapuggalaparivajjanatā)** = 成为回避内心粗劣之人的人 ----

在礼敬佛塔(cetiya)、礼敬菩提树、礼敬那些如同僧团之父、身为僧团首领的诸大长老(thera)时，以不恭敬、不尊重的行为明显表现出来的，怀着如同粗糠一般粗劣的心怀，由于对佛陀等三宝没有净信这种信的湿润之质、黏着之质，因而信之法枯干稀薄、如同涂在驴背上的尘垢一般的那些人——回避这样的人的修行者的相续流中，喜觉支之法也能够明显生起。(中部义注，1，300。)

**九、亲近柔和之人(siniddhapuggalasevanatā)** = 成为亲近心地柔和细腻之人的人 -对佛陀等值得净信的诸净信之事有着很多净信、心地柔软温和、柔和细腻、湿润饱满而带着信之黏着的那些人——亲近依止这样的人的人的相续流中，喜觉支之法也能够明显生起。

**十、省察令人净信之经(pasādanīyasuttantapaccavekkhaṇatā)** = 在省察那些能够明显显示三宝之功德恩德的、令人净信的诸经的人的相续流中，

**十一、彼胜解(tadadhimuttatā)** = 在为使那喜觉支之法明显生起而具有坚定不移地深入的心态、具有倾向与朝向之心态的人的相续流中 ----

喜觉支之法都能够明显生起。(中部义注，1，300。相应部义注，3，198-199。)

像这样，在修习的工作过程中，当心力低落的时候，就应当生起并修习增长择法觉支(dhammavicayasambojjhaṅga)、精进觉支(vīriyasambojjhaṅga)、喜觉支这三种崇高的觉支(sambojjhaṅga)之法，使它们明显生起，从而提振低落的心力。这就是第四种安止善巧(appanākosalla)之法。(清净道论，1，129。)
