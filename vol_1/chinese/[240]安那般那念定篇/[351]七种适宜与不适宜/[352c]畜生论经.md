### 《畜生论经》(Tiracchānakathā Sutta)

诸比库(bhikkhu)……不应谈说那些与禅那(jhāna)、道(magga)、果(phala)、涅槃(nibbāna)直接相违背的种种畜生论(tiracchānakathā)之语。 
那些畜生论之语是什么呢？ ----

|                  |                                 |
| ---------------- | ------------------------------- |
| 1. 国王论(rājakathā) | = 与国王有关的话，              |
| 2. 盗贼论(corakathā) | = 与盗贼、强盗有关的话，       |
| 3. 大臣论(mahāmattakathā) | = 与大臣(总理大臣)有关的话，   |
| 4. 军队论(senākathā) | = 与士兵(军队)有关的话，      |
| 5. 怖畏论(bhayakathā) | = 与可怕之事有关的话，          |
| 6. 战争论(yuddhakathā) | = 与作战(战役)有关的话，    |
| 7. 食物论(annakathā) | = 与食物有关的话，            |
| 8. 饮料论(pānakathā) | = 与饮料有关的话，            |
| 9. 衣物论(vatthakathā) | = 与衣服有关的话，              |
| 10. 卧具论(sayanakathā) | = 与床铺住处有关的话，          |
| 11. 花环论(mālākathā) | = 与花有关的话，              |
| 12. 气味论(gandhakathā) | = 与香有关的话，              |
| 13. 亲戚论(ñātikathā) | = 与亲戚有关的话，              |
| 14. 车乘论(yānakathā) | = 与车乘有关的话，              |
| 15. 村庄论(gāmakathā) | = 与村庄有关的话，               |
| 16. 城镇论(nigamakathā) | = 与市镇有关的话，              |
| 17. 城市论(nagarakathā) | = 与城市有关的话，                |
| 18. 国土论(janapadakathā) | = 与地方(州省、邦国)有关的话，  |
| 19. 女人论(itthikathā) | = 与女人有关的话，           |
| 20. 英雄论(sūrakathā) | = 与英雄好汉有关的话，           |
| 21. 街道论(visikhākathā) | = 与街道有关的话，              |
| 22. 井边论(kumbhaṭṭhānakathā) | = 与汲水处有关的话，            |
| 23. 先亡论(pubbapetakathā) | = 与已故亡者有关的话，           |
| 24. 各种论(nānattakathā) | = 与种种杂事有关的话，              |
| 25. 世界起源论(lokakkhāyikakathā) | = 与世界之事有关的话，         |
| 26. 大海起源论(samuddakkhāyikakathā) | = 与大海之事有关的话，      |
| 27. 如是有无论(itibhavābhavakathā) | = 与兴盛、衰败有关的话， |
| 28. 男人论(purisakathā) | = 与男人有关的话，           |
| 29. 林野论(araññakathā) | = 与森林有关的话，               |
| 30. 山岳论(pabbatakathā) | = 与山有关的话，              |
| 31. 河流论(nadīkathā) | = 与河流有关的话，               |
| 32. 岛洲论(dīpakathā) | = 与岛屿有关的话 ----           |

以上就是这些话语。 
为什么不应该谈说这些话呢？

诸比库……这些话语与真实的利益无关，不是名为道的殊胜梵行(brahmacariya)的开端，不能使人厌离轮回(saṃsāra)流转之苦(dukkha)，不能离贪染之贪(rāga)，不能使贪染之贪止息寂灭，不能从一切名为烦恼(kilesa)的热恼中寂静清凉，不能以殊胜之智通达洞见四谛(sacca)，不能亲自现证洞见圣道智(ariyamaggañāṇa)，不能从渴爱(taṇhā)中出离。

诸比库……你们若想谈说 ----

- 1. 应当谈说：这是苦圣谛(dukkha ariya sacca)之法， 
- 2. 应当谈说：这是苦之生起的集圣谛(samudaya ariya sacca)之法， 
- 3. 应当谈说：这是苦灭尽之处涅槃(= 灭圣谛 nirodha ariya sacca)之法， 
- 4. 应当谈说：这是趣向苦灭尽之处涅槃的行道(= 道圣谛 magga ariya sacca)之法，

为什么应当谈说这些呢？其原因是 ----

诸比库……这些话语与真实的利益相关，是名为道的殊胜梵行的开端，能使人厌离轮回流转之苦，能离贪染之贪，能使贪染之贪止息，能从一切烦恼之热恼中寂静清凉，能以殊胜之智通达洞见四谛，能亲自现证洞见圣道智，能从渴爱中出离。 
诸比库……因此，你们应当

- 1. 努力精进，以求了知：这是苦圣谛。 
- 2. 努力精进，以求了知：这是苦之生起的集圣谛。 
- 3. 努力精进，以求了知：这是苦灭尽之处涅槃(= 灭圣谛)。 
- 4. 努力精进，以求了知：这是趣向苦灭尽之处涅槃的行道(= 道圣谛)——世尊如此教导。(《相应部》3，368。)

[**注** ---- 在以上这三十二种名为畜生论的话语中，第(28)项 = 男人论 = 与男人有关的话，只出现在某些版本中，某些版本中则没有。再者，第(29)、(30)、(31)、(32)这四种与森林、山、河流、岛屿有关的话，虽然在巴利圣典中并没有直接出现，但它们是依据巴利圣典中直接出现的最后一种畜生论——如是有无论 = 与兴盛、衰败有关的话之后所出现的 itibhavābhavakathaṃ iti vā 这一语句中、位于 iti vā 之内的 iti 一词，而被总括计算在内的。 ---- tā hi pāḷiyaṃ sarūpato anāgatāpi arañña-pabbata-nadī-dīpakathā iti-saddena saṅgahetvā saggamokkhānaṃ tiracchānabhāvato “dvattiṃsa tiracchānakathā”ti vuttā. (《大复注》1，148。)]

dasakathāvatthunissitaṃ sappāyaṃ, tampi mattāya bhāsitabbaṃ. (《清净之道》1，124。)

= 依止十种论事(kathāvatthu)的话语，正是贤善的修行者(yogāvacara)应当谈说的适宜(sappāya)之语。 
那种适宜之语也只应当适量地谈说。 
十种论事如下。

- 1. 少欲论(appicchakathā) = 与少欲有关的话，
- 2. 知足论(santuṭṭhikathā) = 与容易知足有关的话，
- 3. 远离论(pavivekakathā) = 与身远离(kāyaviveka)、心远离(cittaviveka)、依著远离(upadhiviveka)这三种清净独处而住的远离(viveka)有关的话，

[1. 身远离 = 独自一身清净独处而住，2. 心远离 = 建立近行(upacāra)与安止(appanā)这两种定(samādhi)中的任何一种，使心远离五盖(nīvaraṇa)的污垢而住，3. 依著远离 = 以远离四种依著(upadhi)之处的涅槃为所缘而住]

- 4. 无杂论(asaṃsaggakathā) = 与不与人混杂共住有关的话，
- 5. 精进论(vīriyārambhakathā) = 与努力策励的精进(vīriya)有关的话，
- 6. 戒论(sīlakathā) = 与戒(sīla)有关的话，
- 7. 定论(samādhikathā) = 与定有关的话，
- 8. 慧论(paññākathā) = 与慧(paññā)有关的话，
- 9. 解脱论(vimuttikathā) = 与从诸烦恼中解脱出来的解脱(vimutti)阿拉汉果(arahatta phala)有关的话，
- 10. 解脱智见论(vimuttiñāṇadassanakathā)= 与省察阿拉汉果解脱的省察智(paccavekkhaṇā ñāṇa)有关的话 ----

以上这些就是十种论事。 
依止那十种论事的话语，才称为适宜之语、应当谈说之语。 
但是也只能在应当谈说的限度之内谈说。 
渴望现证以阿拉汉果为顶点的道智(magga ñāṇa)、果智(phala ñāṇa)与涅槃的善男子，在止(samatha)观(vipassanā)修习(bhāvanā)行道的工作范围之内，应当远远地避开不应谈说的种种畜生论之语，只以智慧衡量斟酌那十种适宜之语，努力做到只谈说应当谈说的部分，如此便是恭敬地把佛陀的教诫顶戴奉持。
