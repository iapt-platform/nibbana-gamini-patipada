### 特相 作用 现起 足处

- 1. Hitākārappavattilakkhaṇā **mettā,**

- 2. hitūpasaṃhārarasā,

- 3. āghātavinayapaccupaṭṭhānā,

- 4. sattānaṃ manāpabhāvadassanapadaṭṭhānā.

Byāpādūpasamo etissā sampatti, sinehasambhavo vipatti. (《清净道论》，1，311。)

- 1. 慈(mettā)是 ---- 具有以促成众生们的利益福祉的方式而生起的特相(lakkhaṇa)。或者说：具有令名为利益福祉的那一份得以生起的特相。

- 2. 具有亲近地促成众生们的利益福祉这一职能(作用 rasa)。或者说：具有名为亲近地促成众生们的利益福祉的圆满功德(sampattirasa)。

- 3. 对于把它观照为「能够去除怨恨的法(dhamma)」的瑜伽行者(yogāvacara)之智(ñāṇa)，它会显现出来。（显现行相现起 upaṭṭhānākārapaccupaṭṭhāna）。或者说：它能产生名为怨恨消失的结果。（果现起 phalapaccupaṭṭhāna）。

- 4. 以只看见众生们可爱可敬之处的如理作意(yonisomanasikāra)作为足处(padaṭṭhāna)。想要毁坏众生、想要令众生败坏的瞋恚(byāpāda) = 瞋(dosa)以镇伏断(vikkhambhanapahāna)的方式止息，这称为那慈的圆满，称为善巧地完成了职能。执著贪恋的爱染(taṇhāsineha)的生起，这称为那慈的败坏。（《清净道论》，1，311。）

- 1. Dukkhāpanayanākārappavattilakkhaṇā **karuṇā,**

- 2. paradukkhāsahanarasā,

- 3. avihiṃsāpaccupaṭṭhānā,

- 4. dukkhābhibhūtānaṃ anāthabhāvadassanapadaṭṭhānā.

Vihiṃsūpasamo tassā sampatti, sokasambhavo vipatti. (《清净道论》，1，311。)

- 1. 悲(karuṇā)是 ---- 具有以想要去除众生们的痛苦的方式而生起的性质特相。

- 2. 具有因想要去除他人的痛苦而无法忍受(他人受苦)的职能。（职能作用 kiccarasa）。

- 3. 它能产生不去恼害众生。（果现起）。对于把它观照为恼害逼迫众生的害(vihiṃsā)的对立面的瑜伽行者之智，它会显现出来。（显现行相现起）。

- 4. 以能观照到那些正被痛苦恼害逼迫的众生们没有可依怙、可仰赖之处的这一状态的如理作意作为足处。与那以恼害众生为因、以恼害的方式而生起的悲正面对立的瞋根(dosamūla)心与心所法之聚的止息清凉，这称为那悲的圆满，称为善巧地完成了职能。对于受苦的众生们生起忧愁(soka)，这称为那悲的败坏。（《清净道论》，1，311。）

- 1. Pamodanalakkhaṇā **muditā,**

- 2. anissāyanarasā,

- 3. arativighātapaccupaṭṭhānā,

- 4. sattānaṃ sampattidassanapadaṭṭhānā.

Arativūpasamo tassā sampatti, pahāsasambhavo vipatti. (《清净道论》，1，311。)

- 1. 喜(muditā)是 ---- 具有对他人的财富成就圆满具足感到欢喜愉悦的性质特相。

- 2. 具有对他人的财富成就圆满具足不生嫉妒的职能。或者说：由于是嫉妒的对立面，因而具有断除那嫉妒(issā)的职能。

- 3. 对于以「能够去除对他人的财富成就以及对以殊胜高尚的止(samatha)、观(vipassanā)为首的增上善法(adhikusaladhamma)的不喜乐、不满意」这样的方式来观照的瑜伽行者之智，它会显现出来。（显现行相现起）另一种说法 ---- 它能产生对他人的财富成就以及对以殊胜高尚的止观为首的增上善法的不喜乐、不满意的不乐(arati)的消失止息。（这是果现起。）

- 4. 以能够随时观照到众生们的财富圆满具足的如理作意作为足处。对他人的财富成就以及对以殊胜高尚的止观为首的增上善法不能喜乐、不能满意的不乐的消失止息，这称为那喜的圆满。或者说：称为善巧地完成了职能。对于他人的财富成就与增上善法，以依止于欲乐之家而生起的居家喜(gehasitapīti)感到欢喜愉悦，这称为那喜的败坏(vipatti)。（《清净道论》，1，311。）

- 1. Sattesu majjhattākārappavattilakkhaṇā **upekkhā,**

- 2. sattesu samabhāvadassanarasā,

- 3. paṭighānunayavūpasamapaccupaṭṭhānā,

- 4. “Kammassakā sattā, te kassa ruciyā sukhitā vā bhavissanti, dukkhato vā muccissanti, pattasampattito vā na parihāyissantī”ti evaṃ pavattakammassakatādassanapadaṭṭhānā.

Paṭighānunayavūpasamo tassā sampatti, gehasitāya aññāṇupekkhāya sambhavo vipatti.(《清净道论》，1，311-312。)

- 1. 舍(upekkhā)是 ---- 具有对众生们以居中中庸的方式而生起的特相。

- 2. 由于对众生们是以漠然中立的方式而生起，因而具有只看待(众生)平等这一状态的职能。

- 3. 它能产生对众生们的憎恨与爱恋的止息。（这是果现起。）

- 4. 众生们唯有自己所造作的业(kamma)才是自己的所有物。那些众生们，凭着谁的意愿，就能像修习慈心时所祝愿的「愿他们安乐」那样得到安乐呢？就能像修习悲修习(karuṇābhāvanā)时所祝愿的「愿他们从痛苦中解脱」那样从痛苦中解脱呢？就能像修习喜修习(muditābhāvanā)时所祝愿的「愿他们不要从已得的财富中退失」那样，对于已经到手、已经获得的财富也不退失呢？以这样的方式而生起的、能观照到唯有业才是自己的所有物这一状态的智，即是它的足处。憎恨与爱恋的止息 = 憎恨与爱恋的寂灭，这称为那舍梵住(upekkhā brahmavihāra)的圆满、善巧地完成，即成就(sampatti)。依止于欲乐的、没有智的、与痴(moha)相应的舍的生起，这称为那舍梵住的败坏，即败坏(vipatti)。（《清净道论》，1，311。）

对于安住在那四种梵住(brahmavihāra)法之中的禅那(jhāna)名法(nāma dhamma)的摄取方式，已经在名业处(nāmakammaṭṭhāna)篇的诸表格中写出呈示了。 
所谓的慈，就是无瞋心所(adosa cetasika)。 
慈初禅(paṭhamajjhāna)的名法有(34)个。 
在悲当中，再加上悲这一个心所，因此悲初禅的名法有(35)个。
在喜当中，再加上喜这一个心所，因此喜初禅的名法有(35)个。 
舍梵住的法体，就是中舍性心所(tatramajjhattatā cetasika)。 
舍梵住禅那的名法有(31)个。
