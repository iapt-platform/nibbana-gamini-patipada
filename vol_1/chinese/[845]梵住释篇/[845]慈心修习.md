### 慈心修习

想要修习、努力于这个慈业处(mettā kammaṭṭhāna)的瑜伽行者(yogāvacara)——「对这些人，最初不应当修习慈心修习(mettābhāvanā)。 
对这些人，无论如何都不应当修习慈心修习」——应当这样了知那些会破坏慈心修习的人。

- 1. Appiyapuggala = 不喜爱、不合意的人(= 既不为自己、也不为自己所爱的人带来利益的人，为自己所憎恨的人带来利益的人，作为九种怀恨(āghāta)之所依处的人)，
- 2. Atippiyasahāyaka = 极为亲爱的朋友伙伴，
- 3. Majjhatta = 不爱不恨、居于中间的人，
- 4. Verīpuggala = 仇敌之人(= 既为自己、也为自己所爱的人带来无益损害的人) ---<br>这四种人，就是最初不应当对之修习慈心的人。
- 5. Liṅgavisabhāga = 异性的人(这种人，是不应当单独一个一个地专门作为所缘来修习慈心的人。)
- 6. Kālakata = 已经去世的人(这种人，是完全不应当对之修习慈心的人。)

原因是这样的。 
把不喜爱、不合意的不喜爱之人放在可爱可意的亲爱之人(piyapuggala)的位置上，而修习慈心修习业处的瑜伽行者，容易疲累。
把极为亲爱珍重的伙伴朋友、也就是极亲爱之人放在不爱不恨、居中的中庸之人的位置上，而修习慈心修习业处的瑜伽行比库(bhikkhu)，他的心也容易疲累。 
当连提都不值得提的、仅仅一点点的苦(dukkha)生起时，那位修习努力慈业处的瑜伽行者，就会变得像是要哭出来的样子。 
把不爱不恨、应当漠然置之的中庸之人放在应当恭敬看重的人的位置上，或者放在可爱珍重的亲爱之人的位置上，而修习慈心修习业处的瑜伽行者，他的心也容易疲累。 
对于一再忆念仇敌之人的瑜伽行者来说，忿怒瞋恚(dosa)容易生起。 
因此，对这四种人，最初不应当修习慈心。(在已经证得慈禅(mettājhāna)之后，则是可以修习的。)

如果单独一个一个地专门以异性的人为所缘而修习慈心，那位瑜伽行者的相续(santāna)中容易生起贪欲(rāga)。 
如果以已经去世的人为所缘而修习慈心修习业处，就不可能证得慈禅。 
因此，不应当单独一个一个地专门以异性者为所缘而修习慈心。
对已死之人，则无论如何都不应当修习。 
但是，在已经证得慈禅、并且已经破除人我之间的界限(sīmā)之后，则可以「sabbā itthiyo = 愿一切女人，sabbe purisā = 愿一切男人，都远离危难怨敌」——以这样等等的方式来修习慈心修习。 
应当对之修习慈心的人的次第，是这样的。

- 1. Ahaṃ avero homi = 愿我远离危难怨敌，
- 2. Ahaṃ abyāpajjo homi = 愿我远离心苦，
- 3. Ahaṃ anīgho homi = 愿我远离身苦，
- 4. Ahaṃ sukhī attānaṃ pariharāmi = 愿我健健康康、安安乐乐地担负自己的五蕴(khandhā)之担。

像这样以自己为所缘、最初修习短短一段时间的慈心，并不是为了慈禅。 
这是为了在修习慈心时把自己放在见证者的地位上，依此力量而修习慈心所作的开示。 
想要证得慈禅、必须修习努力以证得慈禅的人——作为慈禅所依处的人的次第，如下所示。

- 1. Piyagarubhāvanīya = 可爱可敬的人，
- 2. Atippiyasahāyaka = 极为亲爱的朋友伙伴，
- 3. Majjhatta = 不爱不恨、应当漠然置之的中庸之人，
- 4. Verī = 仇敌之人 ---

这四种人，必须都是同性的人。 
Evarūpe ca puggale kāmaṃ appanā sampajjati.(《清净道论》，1，289。) 
依照这段文，对于第(1)项、亦即可爱可敬的同性之人修习慈心时，必须一直修习到证得安止禅定(appanā jhāna samādhi)为止。 
等到心变得柔软柔和了，才按照次第转移到另一类人的部分上去，一直修习到证得慈禅为止。
