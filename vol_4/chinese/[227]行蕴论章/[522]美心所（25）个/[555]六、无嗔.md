### 6。无嗔(adosa)

- 1. (ka) **Adoso** acaṇḍikkalakkhaṇo, ( kha ) avirodhalakkhaṇo vā, anukūlamitto viya.
- 2. (ka) āghātavinayaraso, ( kha ) pariḷāhavinayaraso vā candanaṃ viya,
- 3. sommabhāvapaccupaṭṭhāno puṇṇacando viya. (Abhi-ṭṭha-1-171. Visuddhi-2-95.)

- 1. (ka) 心不粗鲁、不残暴之状态这一本质——另一种说法——与心粗鲁、残暴之状态即忿(kopa)相反之性 <r>特相(lakkhaṇa)，</r>
  - ( kha ) 另一种说法——犹如凡事上都随顺的好友那样不相违逆之性 <r>特相，</r>
- 2. (ka) 消除会导致复仇行为之结怨的瞋(dosa)聚集 <r>(作用) 作用(rasa)，</r>
  - ( kha ) 另一种说法——犹如檀香那样消除瞋的热恼 <r>(作用) 作用，</r>
- 3. 如满月之相般清澈清凉的本质法 <r>现起(paccupaṭṭhāna)，</r>
- 4. 所缘(ārammaṇa)——另一种说法——以依处(vatthu)、所缘、触(phassa)为首的相应(sampayutta)诸法 <r>足处(padaṭṭhāna)。</r>

**特相——** Caṇḍikassa bhāvo ciṇḍakkaṃ, kopo. Tappaṭipakkho **acaṇḍikkaṃ**, abyāpādo. <r>(Mahāṭī-2-144.)</r>

使诸心变得粗鲁、残暴的本质法，称为凶暴(caṇḍikka)；另一种说法——作为使人心粗鲁残暴之原由的本质法，称为凶暴；就法体而言即发怒的忿＝瞋法。 
那发怒的忿＝瞋法的相反本质法，就是名为无恚(abyāpāda)的无嗔法。 
因此，无嗔法具有与那使人心粗鲁残暴、发怒的忿法相反的本质特相。 
而那忿的相反本质法，也正是无恚＝不欲破坏之性＝友谊(metta)界的本质法。 
因此，那无嗔的另一种特相，正是犹如随顺的良朋好友那样不相违逆的本质法。 
所谓随顺，是唯有彼此之间安住着友谊界的人们，才能相互怀有的心态。 
因此，正如瞋会同时破坏自己与他人双方那样，这无嗔却不会破坏。 
由于无嗔与瞋是笔直而正面、针锋相对的对立，因此具有身心皆不粗鲁、不残暴的本质特相，以及不相违逆的本质特相。

**作用——** 由于把不欲破坏的无恚法也称作无嗔，故这无嗔，若以有情概念(sattapaññatti)为所缘而清澈清凉地生起时，便又称为包含在无量(appamaññā)梵住(brahmavihāra)诸法中的友谊。 
在那安住着友谊界者的相续中，凡是嗔恨(āghāta)、结怨之类必定止息，此乃法性(dhammatā)；因此，提升到友谊界、友谊禅(mettājhāna)阶段的无嗔，便执行消除结怨的工作职责。 
因此，当知凡是真正的友谊，其法体皆唯是无嗔。 
然而，并非一切无嗔都是友谊。 
若不以有情概念为所缘，而以其他有关布施(dāna)、戒(sīla)、止(samatha)、观禅(vipassanā)的所缘为所缘而生起时，则不是友谊，而只是对那些相关所缘心不粗鲁、不残暴的无嗔而已。 
那无嗔也是——犹如牛头檀香(gosīsacandana)能将火界(tejodhātu)过度失调而降临于身体的过度热界当下瞬间平息清凉那样——它既能消除心热、心所(cetasika)热这种热界，也能消除因那心热、心所热而蔓延灼烧至身体的色热之界，具有这样的作用。

**现起——** 由于无嗔消除瞋的热界，令心相续中进入种种清凉之界，故犹如满月的清澈清凉那样，在以观智(vipassanā ñāṇa)摄持而修习那无嗔的瑜伽行者(yogāvacara)之智中，那无嗔便作为「清澈清凉的本质法」而现前显现。 
关于足处，由于诸义注(aṭṭhakathā)中未特别说明，故将所缘等示为足处。

**[注释——在诸义注中，于无嗔之后，无痴(amoha)**被接着加以解说。 
然而，由于无痴并非与一切美心(sobhaṇa)相应的心所，也就是它不与某些智不相应(ñāṇavippayutta)心相应，故在《摄阿毗达摩义论》(Saṅgaha)中，并未将它列入与一切美心相应的通一切美心(sobhaṇasādhāraṇa)心所名单内，而是单独作为美心所来说明。 
然而，由于诸义注中把无贪(alobha)、无嗔、无痴三者值得记取的相关内容合并汇集在一起撰写陈述，因此本书中也接着撰写陈述无痴心所；不过在编号次第上，仍依《摄阿毗达摩义论》标为(25)。**]**
