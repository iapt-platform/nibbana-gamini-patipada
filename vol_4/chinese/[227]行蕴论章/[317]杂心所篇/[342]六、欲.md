### 六、欲(chanda)

**chando**ti kattukāmatāyetaṃ adhivacanaṃ, tasmā so ---

- 1. kattukāmatālakkhaṇo **chando**, (kattukamyatālakkhaṇo chando.)
- 2. ārammaṇapariyesanaraso,
- 3. ārammaṇena atthikatāpaccupaṭṭhāno,
- 4. tadevassa padaṭṭhānaṃ. (Abhi-ṭṭha-1-176-177. Visuddhi-2-96.)

所谓这个欲，是“想要对所缘(ārammaṇa)造作 = 想要造作者”之状态的名称。想要造作、想要获取某一所缘的性质，就是欲。

- 1. “想要对所缘造作者的状态”这一性质 = 想要造作所缘的性质（想要希求的性质）<r>特相(lakkhaṇa)、</r>
- 2. 寻找所缘 <r>（职务）作用(rasa)、</r>
- 3. 想要所缘的性质法 = 希求所缘的性质法 <r>现起(paccupaṭṭhāna)、</r>
- 4. 那个所想要的所缘 <r>近因(padaṭṭhāna)。</r>

**特相 ---** chandanaṃ chando, ārammaṇena atthikatā. (Mahāṭī-2-146.)

在“chando kāmo ---”(Abhi-2-266)等诸巴利圣典中，佛陀(Buddha)把渴爱(taṇhā)宣说为欲。 
“chandaṃ janeti vāyamati ---”(Abhi-2-255)等诸巴利圣典中，佛陀也把精进(vīriya)宣说为欲。 
为了排除那渴爱与精进 --- **kattukāmatā yetaṃ adhivacanaṃ** = 想要造作所缘的性质、希求所缘的性质，就名为欲——注释书(aṭṭhakathā)阿阇黎如此开示解说。 
**欲作性(kattukāmatā)——** 指的是想要对所缘造作的性质 = 意指作欲(karaṇicchā)。 
那个作欲，大复注(mahāṭīkā)阿阇黎也如下继续解说。

cetasikassa ca dhammassa sārammaṇattā karaṇicchā nāma ālambanassa ālambitukāmatā mukhenevahotīti ārammaṇakaraṇicchālakkhaṇo chando **kattukāmatālakkhaṇo** vutto. (Mahāṭī-2-146.)

在大纲(mātikā)巴利圣典中，佛陀把究竟(paramattha)诸界分为有所缘诸法(sārammaṇa-dhammā)、无所缘诸法(anārammaṇa-dhammā)两类而宣说。 
心(citta)与心所(cetasika)诸法之类，属于能取所缘的有所缘诸法之类。 
欲心所也是属于能取所缘的有所缘诸法之类的一种心所。 
由于那个欲心所是能取所缘的有所缘法，所以想要造作所缘、想要作——所谓作欲，正是以“攀取所缘、想要作所缘者”的状态为先导而生起的性质法。 
因此，说具有想要作所缘之特相的欲为“欲作性特相(kattukāmatālakkhaṇa) = 具有想要造作所缘之特相”。

**欲作性——** 中，“作者(kattu)”里的“kara词根(kara-dhātu)”遍及一切词根，因此——

- 1. 想要造作对色所缘(rūpārammaṇa)的看见 = 想要看见
- 2. 想要造作对声所缘(saddārammaṇa)的听闻 = 想要听闻
- 3. 想要造作对香所缘(gandhārammaṇa)的嗅闻 = 想要嗅闻
- 4. 想要造作对味所缘(rasārammaṇa)的尝味 = 想要尝味 = 想吃、想嚼、想喝、想舔
- 5. 想要造作对触所缘(phoṭṭhabbārammaṇa)的触碰 = 想要触碰
- 6. 想要造作对法所缘(dhammārammaṇa)的了知 = 想要了知

如此，想要造作全部六种所缘、想要作所缘，就是欲的性质特相。 
但是，欲的想要造作所缘、想要作所缘的性质，并不像贪(lobha)想要所缘那样，是喜好、黏着、贪恋的那种性质。 
贪与欲虽然性质彼此不同，但也能够一同相应而在同一个心刹那(cittakkhaṇa)之内生起。

在想要那足以生起贪的、能引生贪的所缘——欲乐(kāmaguṇa)时，贪居于主导，欲则须顺随贪的性质。 
贪是喜好、黏着、贪恋所缘的性质，欲则是想要那所缘的性质 = 想要喜好、黏着、贪恋的性质。

同样地，在与瞋(dosa)等相应时，欲也须顺随瞋等的性质。 
瞋是心刚硬、粗暴的性质，欲则是想要心刚硬、粗暴的性质。 
为了容易理解这些性质法，请如下记住。

- 与贪相应而生起的欲，是想要成为贪的性质；
- 与邪见(diṭṭhi)相应而生起的欲，是想要成为（贪）邪见的性质；
- 与慢(māna)相应而生起的欲，是想要成为（贪）慢的性质；
- 与瞋相应而生起的欲，是想要成为瞋的性质；
- 与嫉妒(issā)相应而生起的欲，是想要成为（瞋）嫉妒的性质；
- 与悭吝(macchariya)相应而生起的欲，是想要成为（瞋）悭吝的性质；
- 与追悔(kukkucca)相应而生起的欲，是想要成为（瞋）追悔的性质；

如此等等，请在名业处(nāmakammaṭṭhāna)的观照范围中领会其义。

同样地，在善的组别方面，在像布施(dāna)、戒(sīla)等以信(saddhā)为主导的事业中、在以信为主导的心相续里，与信相应而生起的欲，是想要成为信的性质；在建立定(samādhi)的部分，在以定为主导的心相续里，与定相应而生起的欲，是想要成为定的性质；在慧(paññā)的阶段，在以慧为主导的心相续里，与慧相应的欲，是想要成为慧的性质（= 想要透彻了知眼净色(cakkhupasāda)、想要透彻了知色法、想要透彻了知名法、想要透彻了知因法与果法、想要透彻了知无常(anicca)、苦(dukkha)、无我(anatta)的性质——如此等等这些锐利透彻地想要了知的性质法，就是与慧相应的欲的诸性质。） 
与精进相应的欲，是想要成为精进的性质——也请如此等等地领会其义。

**作用-现起-近因 ---** 正因为欲具有想要造作所缘、想要作所缘的性质特相，所以欲也具有寻找所缘的作业职务、希求所缘的现起。 
所想要的所缘，正是欲生起的最近的原因（近因）。

**伸手之相 ---** ārammaṇaggahaṇe ayaṃ cetaso hatthappasāraṇaṃ viya daṭṭhabbo. <r>(Abhi-ṭṭha-1-177. Visuddhi-2-96.)</r>

请记住：这个欲，在执取所缘时，如同心伸出手 = 如同伸手。 
意思是说，欲对所缘的希求，很像心朝着所缘一方伸手的样子。 
这段话是为了显明欲希求的样子，虽然心并没有手，却把欲比喻为心之手来述说的“彼法喻语(taddhammūpacāra)”。

这个欲的性质法，在有情(satta)的相续(santāna)中生起时，也极为明显。 
一个小孩想要从父亲的手转到母亲的手，便伸出手，这种想要过去，就是欲。 
想去那边、想来这边、想见到某人、想看、想听、想听闻、想嗅、想吃、想拿、想触、想通晓了解，这一切全都是欲。

svāyaṃ kusalesu uppanno kusalacchandoti vuccati yonisomanasikārasamuṭṭhānattā. <r>(Mahāṭī-2-146.)</r>

想要行布施、想要施舍、想要建立戒、想要戒坚固、想要修习定、想要坚固的定、想要修习观(vipassanā)、想要观智(vipassanāñāṇa)、想要现证涅槃(nibbāna)、想要涅槃、想要成佛、想要成为独觉佛(paccekabuddha)、想要成为上首弟子(aggasāvaka)、大弟子(mahāsāvaka)、普通弟子(pakatisāvaka)、想要成为国王、想要成为富翁、想要成为天神、想要成为梵天神(brahma)、想要成为仙人隐士——如此等等一切想要获得善(kusala)的心，也都是善欲(kusalacchanda)。 
原因是，那些善欲 = 善欲，由于以如理作意(yonisomanasikāra)为根本原因，所以只能在能够以正确方法、正确道路作意的善人的相续中生起。

在一般般的想要中，欲则力弱、力软；在非得不可的想要、非有不可的想要中，欲则力大、力量强盛。 
由于以这个欲为根本、以强猛的精进圆满波罗蜜(pāramī)，所以最终便依其欲而得以成佛、得以成为独觉佛、得以成为上首弟子、得以成为大弟子、得以成为普通弟子。 
得以成为人、得以成为天神、得以成为梵天神。

若连想要到达顶端的基础之欲都还没有，那么谁也不会为了到达顶端而付出锐利的勤勉精进。 
因此，必须首先使那想要获取某一殊胜利益的欲的成分生起。 
这一类欲，也称为渴愿欲(āsāchanda) = 希求。 
此后，应当明白：仅仅有渴愿欲、仅仅祈愿发愿，还无法获得自己所期望的、属于高层的顶端生命，从而全心全意地投入精进、努力精进才行。

正等菩提(sammāsambodhi)的候补者、独觉菩提(paccekabodhi)的候补者，以及上首弟子、大弟子、普通弟子这些伟大的弟子候补者，为了获得各自所期望的菩提智(bodhiñāṇa)，也都以强烈的欲望渴愿欲圆满各种波罗蜜，这本是法性(dhammatā)。 
他们并不是不圆满各种波罗蜜就获得各自菩提智的人。 
他们都是以波罗蜜为根本，才得以获取自己所期望的高层生命的人。

当今时代在俗人方面、僧人方面达到高层的人，也并不是福德与威势格外殊胜、心到之处身也随到、想要什么就能成办的“从天而降的金身贵人”，多半只是随着渴愿欲付出精进、努力过的人罢了。 
因此，虽然已经蒙受宿世善业的扶助而获得了极难获得的人身，若还缺乏想要进步的渴愿欲、想要到达顶端的自性法，只是庸碌懈怠、懒惰无为，那么四恶趣(apāya)便正等着迎接。 
因此，为了使自己在今生也能到达高层、通达道(magga)路，在未来轮回(saṃsāra)中也能到达高层、通达道路，各自都应当使锐利的渴愿欲生起。

chandavato kiṃ nāma na sijjhati = 对有欲者来说，没有不能成办的事。

āsā phalavatī sukhā = 渴望若经努力而获得成果，便能带来安乐。
