如是，获得这五种第一殊胜称号的阿难德尊者，其八项恩赐分为四项「辞谢之愿」与四项「受取之愿」，其中四项辞谢之愿即是——

- 1。 世尊不把自己所获得的上好袈裟赐给弟子（阿难德尊者），

- 4。 不带他一同前往受人邀请之处——便是这些，

四项受取之愿即是——

- 1。 世尊莅临弟子（阿难德尊者）所邀请之处，
- 2。 能获准让从异国他乡前来瞻礼世尊的会众，在抵达的当下便得以瞻礼世尊，
- 3。 若有需要，能立刻趋近世尊座前，以及
- 4。 凡在弟子（阿难德尊者）不在场时所宣说的一切法，都请世尊再重讲一遍——便是这些。（增支部注-1-229-230。）

### (乙) 四种摄事之法

诸比库……能摄受提携世间的「摄事（saṅgaha-vatthu）」便是这四种。是哪四种呢——

- 1。 dāna = 布施、施与，
- 2。 peyyavajja = 说令人喜爱的话语（爱语），
- 3。 atthacariyā = 行利益之事（利行） = 为人效劳操办，
- 4。 samānattatā = 视人如己、与人同等（同事） = 平等相待，

诸比库……能摄受提携世间的「摄事」便是这四种。

在此世间，布施、说可爱之言、行利益之事，以及在种种情况下随其相宜地视人如己——这四种摄事，犹如行驶中车子的车轴销钉 = 车辖一般，摄受提携着世间。

倘若没有这四种摄事，母亲便不会因「儿子」之故而得到供养与敬爱。
父亲也不会因「儿子」之故而得到供养与敬爱。

由于智者们善加观察思择这四种摄事，因而臻于尊贵；那些智者便成为值得称赞的人。（增支部-1-341。）

### (丙) dasa rājadhamma = （10）种治国之法

dānaṃ sīlaṃ pariccāgaṃ, ajjavaṃ maddavaṃ tapaṃ.
akkodhaṃ avihiṃsañca, khantiñca avirodhanaṃ.（小部-6-97。）

- 1。 dāna = 布施施舍 = 以（10）种布施事（dāna-vatthu）为所依处的善思（kusala-cetanā），
- 2。 sīla = 戒 = 守持五戒、十戒，
- 3。 pariccāga = 施予、舍弃散施，
- 4。 ajjava = 心地正直，
- 5。 maddava = 心地柔和温顺，
- 6。 tapa = 持守布萨（uposatha）斋戒，
- 7。 akkodha = 以慈爱为前导、为主的心态，不生忿怒瞋恚，
- 8。 avihiṃsa = 对臣民百姓怀着以悲为前导、为主的心态，不加折磨、不加迫害，
- 9。 khanti = 忍耐，
- 10。 avirodhana = 不与臣民百姓相违逆抵触，

这便是（10）种治国之法。（本生注-5-403。）

### (丁) 领导者德行（6）种

- 1。 khamā = 忍耐 = 具足忍耐（khanti）之法，
- 2。 jāgariyānuyoga = 与警寤相应 = 保持警醒觉寤 = 最低限度也在夜晚三时之中仅睡一时，其余时间唯精勤修习以止（samatha）、观（vipassanā）为首的沙门修行诸法，
- 3。 uṭṭhāna = 比僚属侍从、比门徒子孙更胜数倍地具有奋发振作的精进，
- 4。 saṃvibhāga = 分别衡量地奖掖资助 = 对随从僚属、门徒子孙，恰如其分、随其相宜地将财物资具加以分配，予以奖掖资助，
- 5。 dayā = 对待他人如同自己一般，能慈悯怜爱，
- 6。 ikkhanā = 具足能对一切机遇情势加以思量远见、审视省察的智慧（paññā），

奋发、警醒；慈悯、忍耐；辨施、审察；这六者，便是为尊长者应行之法。

### (戊) 七组不退法 = 使诸王不衰退之（7）种法

那时，阿难德尊者正为世尊打扇送风，侍立在世尊身后；那时，世尊便对阿难德尊者说道——

「阿难德……跋耆的诸君侯是否时常集会？是否屡屡频繁集会？你是如何听闻得知的？」世尊如是问道。
——「尊者……跋耆的诸君侯时常集会，屡屡频繁集会」——弟子如是听闻，世尊。他如是禀白。
「阿难德，只要跋耆的诸君侯时常集会、屡屡频繁集会，那么在此期间内，跋耆的诸君侯便只会兴盛，而不会衰退。」
——如是等，世尊在《大般涅槃经》中宣说了使诸王不衰退之（7）种法。
依那开示（desanā）的内容，其扼要概括如下。

- 1。 诸君侯时常集会、屡屡频繁集会；
- 2。 诸君侯和合地集会、和合地散会，并和合地办理国政要务；
- 3。 诸君侯不擅立古昔君王未曾制立之事，不废除已经制立之事，凡古昔君王所制立的规范，皆遵循奉行；
- 4。 诸君侯尊敬、敬重、爱戴年长的君王，并认为那些年长者的话语理应听取采纳而如是行事；
- 5。 诸君侯不强行掳掠、恃势逼凌地霸占年长与年幼的妇女；
- 6。 诸君侯对城内城外自己的神祠 = 佛塔（cetiya）加以尊敬、敬重、爱戴、供养，并且对那些神祠 = 佛塔，不使那自古以来惯常施予、惯常奉行的、如法的祭神供品有所减损；
- 7。 为使尚未来到自己国土的阿拉汉（arahat）们前来、使已经来到的阿拉汉们在自己国土中安乐而住，诸君侯依法守护、保卫阿拉汉们，并妥善安排周全的护卫；

这些便是使诸王不衰退之（7）种不退法。（长部-2-62-63。）
