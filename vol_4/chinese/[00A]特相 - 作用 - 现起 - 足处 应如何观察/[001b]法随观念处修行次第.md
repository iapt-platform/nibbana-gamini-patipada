### 法随观(dhammānupassanā)念处(satipaṭṭhāna)修行次第

idha bhikkhave bhikkhu ----

- 1. iti rūpaṃ, iti rūpassa samudayo, iti rūpassa atthaṅgamo.
- 2. iti vedanā, iti vedanāya samudayo, iti vedanāya atthaṅgamo.
- 3. iti saññā, iti saññāya samudayo, iti saññāya atthaṅgamo.
- 4. iti saṅkhārā, iti saṅkhārānaṃ samudayo, iti saṅkhārānaṃ atthaṅgamo.
- 5. iti viññāṇaṃ, iti viññāṇassa samudayo, iti viññāṇassa atthaṅgamo. (dī-2-239.)

- 1. (甲) 此即色法(rūpa)，<br>
( 乙 ) 此即色法之生起因的体性与生起的体性，<br>
( 丙 ) 此即色法之坏灭因的体性与坏灭的体性。
- 2. (甲) 此即受法(vedanā)，<br>
( 乙 ) 此即受法之生起因的体性与生起的体性，<br>
( 丙 ) 此即受法之坏灭因的体性与坏灭的体性。
- 3. (甲) 此即想法(saññā)，<br>
 ( 乙 ) 此即想法之生起因的体性与生起的体性，<br>
 ( 丙 ) 此即想法之坏灭因的体性与坏灭的体性。
- 4. (甲) 此即诸行(saṅkhāra)（心所(cetasika)行）诸法，<br>
 ( 乙 ) 此即诸行法之生起因的体性与生起的体性，<br>
 ( 丙 ) 此即诸行法之坏灭因的体性与坏灭的体性。
- 5. (甲) 此即识法(viññāṇa)（了知心之识），<br>
 ( 乙 ) 此即识法之生起因的体性与生起的体性，<br>
 ( 丙 ) 此即识法之坏灭因的体性与坏灭的体性。

如此，在名为「取蕴(upādānakkhandhā)（五）种」的诸法自性(dhammasabhāva)法当中，一再、反复地以「法自性法」而观照地安住着。
 (dī-2-239. mahāsatipaṭṭhānasuttan dhammānupassanā khandhapabba.) 
 在上述念处修行次第的教说(desanā)之中——

- 1. iti rūpaṃ = 此即色法。
- 2. iti vedanā = 此即受法。
- 3. iti saññā = 此即想法。
- 4. iti saṅkhārā = 此即诸行法。
- 5. iti viññāṇaṃ = 此即识法。

如此，佛陀(Buddha)教导禅修比丘：应当在名为「取蕴（五）种」的诸法自性法当中，一再、反复地观照、审察而安住。

那一教导所要表达的本意与义理，义注(aṭṭhakathā)与复注(ṭīkā)如下解说：——

**lakkhaṇa-rasa-paccupaṭṭhāna- padaṭṭhānavasenā**ti kakkhaḷādilakkhaṇavasena, sandhāraṇādirasavasena, sampaṭicchanādipaccupaṭṭhānavasena, bhūtattayādipadaṭṭhānavasena ca.
 (saṃ-ṭī-2-58.)

**问** ——佛陀——此即色法
 此即受法
 此即想法
 此即诸行法
 此即识法——(佛陀)教导禅修比丘，要在这取蕴（五）种之中一再、反复地观照、审察而安住
 如此教导之时，禅修比丘对那取蕴（五）种应当如何了知、应当以正见智(sammādiṭṭhi ñāṇa)慧如何观照呢——这是需要发问的。

**答** ——答案如下。

- 1. 「此即色法，色法仅止于此，超出于此再无任何多余者」——（此语）是要开示：由「冷、热」等诸因缘，使先前生起的色相续(rūpa santati)＝生起过程，与其不同的后后的色相续＝生起过程，其种种形态变异而生起，此名为变坏体性(ruppanasabhāva)＝变异的体性；以及名为大种色(bhūtarūpa)、所造色(upādārūpa)的种种差别的（二十八）类色——从这些开始，藉由「特相(lakkhaṇa)-作用(rasa)-现起(paccupaṭṭhāna)-足处(padaṭṭhāna)」之力，无余、完尽地以智(ñāṇa)分别摄取、摄受(pariggaha)色法——这即是（佛陀）想要开示的本意。
意思是说：应当藉由「特相-作用-现起-足处」而完尽地了知一切色，应当为了了知而观照。

在「此即受法」等等之处，也是——

- 2. 此即受法，受法仅止于此，超出于此再无名为受者。
- 3. 此即想法。pa。
- 4. 此等即诸行法。pa。
- 5. 此即识法，识法仅止于此，超出于此再无名为识法者——
- 2. 受蕴(vedanākkhandha)领受所缘之滋味的体性，
- 3. 想蕴(saññākkhandha)对所缘作记号而了知的体性，
- 4. 行蕴(saṅkhārakkhandha)的自身诸因，为了使应被和合成就的果法生起，而能造作、能成就的体性，
- 5. 识蕴(viññāṇakkhandha)能分别摄取所缘、了知的体性，也是如此，
- 2. 受蕴以乐受(sukha vedanā)等等而有的差别，
- 3. 想蕴以色想(rūpasaññā)等等而有的差别，
- 4. 行蕴以触(phassa)、思(cetanā)等等而有的差别，
- 5. 识蕴以眼识(cakkhuviññāṇa)等等而有的差别，也是如此——

从（这些）开始，藉由「特相-作用-现起-足处」之力，无余、完尽地以智分别摄取、摄受受-想-行-识，此即（佛陀）想要开示的本意。
 意思是说：应当藉由「特相-作用-现起-足处」，无余、完尽地了知一切受-想-行-识法，应当为了了知而观照。 
 (dī-ṭṭha-2-53. saṃ-ṭṭha-2-44-45.)

在上述诸义注中——anavasesarūpapariggaho vutto。pa。 
anavasesavedanāsaññā saṅkhāraviññāṇapariggaho vutto——请注意这些语句。 
（佛陀）教导：应当无余、完尽地藉由「特相-作用-现起-足处」，摄受名为色-受-想-行-识的取蕴（五）种。

- 1. 仅仅一个色法，或者
- 2. 仅仅一个名法(nāma)，或者
- 3. 色法这一边也仅仅一个、名法这一边也仅仅一个——

（佛陀）并未教导说：应当（仅仅）藉由「特相-作用-现起-足处」摄受（这些）。 
（佛陀）唯有教导说：应当无余(anavasesa)地、完尽地摄受色-受-想-行-识，应当以智分别摄取。 
因此，「若观照仅仅一个色界(rūpadhātu)、或者观照仅仅一个名界(nāmadhātu)、或者色界这一边也仅仅一个、名界这一边也仅仅一个地观照，便能办完事务、便能到达涅槃(nibbāna)」这类论断，只不过是从教说脉络偏斜、脱轨的见解而已——应当如此记取、听受。

依照上述巴利圣典(pāli)、义注、复注的教导，禅修的贤圣个体(puggala)——

- 1. 名为大种色、所造色的（二十八）种色，以及地(pathavī)-水(āpo)-火(tejo)-风(vāyo)等每一个、每一个色法各自相应的「特相-作用-现起-足处」，
- 2. 乐受、苦受(dukkha vedanā)、悦受(somanassa vedanā)、忧受(domanassa vedanā)、舍受(upekkhā vedanā)，以及那些受各自的「特相-作用-现起-足处」，
- 3. 名为色想、声想(saddasaññā)、香想(gandhasaññā)、味想(rasasaññā)、触想(phoṭṭhabbasaññā)、法想(dhammasaññā)的种种想，以及那些想各自的「特相-作用-现起-足处」，
- 4. 名为触-思-一境性(ekaggatā)-命(jīvita)-作意(manasīkāra)等等、含摄于行蕴中的（五十）个心所，以及那些心所各自的「特相-作用-现起-足处」，
- 5. 名为眼识、耳识(sotaviññāṇa)、鼻识(ghānaviññāṇa)、舌识(jivhāviññāṇa)、身识(kāyaviññāṇa)、意识(manoviññāṇa)的种种识，以及那各自的识的「特相-作用-现起-足处」，都应当为了了知而观照。

这一点，渴求真实之法、正确之法的你这位善人，应当如同在头顶上钉入铁钉一般，牢固地记取、听受。
