### 14. 女性根(itthindriya) = 女性色(itthibhāvarūpa)

- 1. Itthibhāvalakkhaṇaṃ **itthindriyaṃ**,
- 2. Itthīti pakāsanarasaṃ,
- 3. Itthiliṅganimittakuttākappānaṃ kāraṇabhāvapaccupaṭṭhānaṃ,
- 4. Catumahābhūtapadaṭṭhānaṃ. 
  
(Abhi-ṭṭha-1-358. Visuddhi-2-77.)

- 1. 女(itthi) = “成为女人”之本质——特相(lakkhaṇa)，
- 2. 显现“此人是女人”（作用(kicca)）作用(rasa)，
- 3. (a) 女性形相(itthiliṅga) = 女人的形貌样态 <br>(b) 女性相(itthinimitta) = 知为女人的标记 <br>(c) 女性举止(itthikutta) = 女人的举止行为 <br>(d) 女性仪态(itthiākappa) = 作为“女人的样态仪表”诸法生起之原因的本质法——现起(paccupaṭṭhāna)，
- 4. 女性根所依止的、同一色聚(kalāpa)中的业生大种(kammajamahābhūta)——足处(padaṭṭhāna)。

<br>(a) **女性形相** ---- Liṅgeti gameti bodhetīti liṅgaṃ = 令人知晓“这是女人”的形貌样态 ---- 众多色聚(rūpakalāpa)聚合而安住，这本身就称为“形态(saṇṭhāna)”。
在那些色聚当中，含有女性色的“性十法聚(bhāvadasakakalāpa)”也遍布全身而安住，为数众多；而含有该女性色的性十法聚，连同其余色聚一起聚合安住，这本身就称为女性形相 = 女人的形貌样态。
女人的手、脚、脖颈、胸膛等等的形状，与男人的手、脚、脖颈、胸膛等等的形状并不相同。
确实如此——女人的下半身清晰简单，上半身则不清晰。
手脚都小，脸也小。
(Abhi-ṭṭha-1-357.)

<br>(b) **女性相** ---- 知为女人的标记 ---- 女人的乳房不清晰（明显有别），脸上没有胡须、獠牙般的髭、鬓边的须毛；盘发的样式、拿取衣物的方式，也与男人盘发的样式、拿衣的方式不同。
这些就是知为女人的种种标记。

(Abhi-ṭṭha-1-357.)

<br>(c) **女性举止** ---- 女人们的举止行为 ---- 女人们在年幼时，常爱玩小盘子、小杵之类的玩具。
爱玩各种精巧新奇的小玩偶；还会用名为“mattikavāka”的棉絮来纺出所谓的细线。
这些就是女人们的举止行为。

(Abhi-ṭṭha-1-357.)

<br>(d) 女性仪态 ---- 行走来往等等的样态仪表 ---- 女人们在行走时，往往走得不清爽利落。
站立时，往往站得不清爽利落；躺卧时，往往躺得不清爽利落。
坐时，往往坐得不清爽利落，

咀嚼硬食时，往往嚼得不清爽利落；食用软食时，往往吃得不清爽利落。
确实如此——若见到某个行走起居不清爽利落的男人，人们便会说：“走路像女人一样走，站像女人一样站，睡像女人一样睡，坐像女人一样坐，嚼像女人一样嚼，吃像女人一样吃”——诸如此类地议论。

(Abhi-ṭṭha-1-357-358.)

**女性状态(itthibhāva)** = **女性自性(itthisabhāva)** = 显明地知为女人的标记，就称为女性色。
 **男性状态(purisabhāva)** = **男性自性(purisasabhāva)** = 显明地知为男人的标记，就称为男性色(purisabhāvarūpa)。 

(Abhi-ṭṭha-1-358.)

    Ayaṃ kammajo paṭisandhisamuṭṭhito. Itthiliṅgādīni pana itthindriyaṃ paṭicca pavatte samuṭṭhitāni. 
    
    (Abhi-ṭṭha-1-358.)

    Sakena sakena kammacittādinā paccayena samuṭṭhitānipi itthiliṅgādīni indriyasahite sarīre uppajjamānāni taṃtadākārāni hutvā uppajjantīti **“itthindriyaṃ paṭicca samuṭṭhahantī”**ti vuttāni. 
    
    (Mūlaṭī-1-150.)

    众生(satta)在过去世造作、培育那导致投生此人间之业的期间，身为女人者，以“喜爱自身所具有的女性形相、相、举止、仪态”的渴爱(taṇhā)为根本，造作、培育了业；而那渴爱又是建立在“误以为是女人”的无明(avijjā)之上；那业便是女人的形相、相、举止、仪态等等得以显现的根本原因。

    同样地，身为男人者，也是以“喜爱自身的男性形相(purisaliṅga)、相、举止、仪态”的渴爱为根本，造作、培育了导致投生此人间之业；那渴爱也同样建立在“误以为是男人”的无明之上。
    那业便是男性形相等等得以显现的根本原因。

  以无明-渴爱-取(upādāna)为根本原因之业，使女性色（男性色）得以生起。
  该性色(bhāvarūpa)从结生(paṭisandhi)之时起，于每一心识刹那(cittakkhaṇa)的生-住-灭(uppāda-ṭhiti-bhaṅga)、于每一微小刹那，只要业的势头尚未耗尽，在这整段时期、在整个一生当中，都以生-住-灭 = 生起-住立-坏灭的状态持续地生起。
  
    如此，性色虽从结生之时起便已生起，但女性形相等等、男性形相等等，却唯有到了生命期间(pavatti)之时，才得以有机会显现。
    在这种情形下，唯有在拥有名为“女性根”的女性色者的相续(santāna)中，女性的形相、相、举止、仪态才会生起。
    唯有在拥有名为“男性根(purisindriya)”的男性色者的相续中，男性的形相、相、举止、仪态才会生起。
    要问为什么，那是因为彼此的业各不相同的缘故。
    要问为什么彼此的业各不相同，那是因为作为业之根本原因的无明-渴爱-取彼此各不相同的缘故。
    “想成为女人的心态、想成为男人的心态”这样的无明-渴爱-取有多么繁复奇异，业便有多么繁复奇异；由于业繁复奇异，作为业之果的性色彼此便各不相同。
    由于性色彼此各不相同，故依于女性色而生起女性的形相、相、举止、仪态；依于男性色而生起男性的形相、相、举止、仪态。

    如此，由于以无明为根本、被渴爱所摆布造作的业之繁复奇异，虽然雄性与雌性的形相等等各不相同，但那些形相等等，唯有在拥有女性根(= 女性色)者身上才有女性形相等等的生起，唯有在拥有男性根(= 男性色)者身上才有男性形相等等的生起——因此说：Itthindriyaṃ paṭicca itthiliṅgādīni samuṭṭhahanti = 依于女性根(= 女性色)为原因，女性形相等等便得以显现生起。
    
    (Abhi-ṭṭha-1-357-358. Mūlaṭī-1-150.)

**譬喻(upamā)** --- 有种子时，依于种子，树木便渐渐长大；树木长大之后，便枝杈繁茂、渐趋完备。
就像枝杈渐渐完备、遮满天空而树木得以耸立那样，正如这个譬喻——当名为女性色的女性根存在时，女性形相等等便会显现生起。
当称为男性色的男性根显明存在时，男性形相等等便会显现生起。

女性根与男性根就好比种子(bīja)＝谷种。
就像依于谷种而生长壮大、遮满天空而耸立的树木那样，依于女性根、男性根而生起女性形相等等、男性形相等等，其情形也是相同的——请如此记取。(Abhi-ṭṭha-1-358.)

能使诸色法(rūpadhamma)生起的本源原因诸法，正是业-心(citta)-时节(utu)-食(āhāra)。
那些色法在女人的蕴(khandhā)相续中聚集安住的样子，与在男人的蕴相续中聚集安住的样子，其形态也彼此不同。
盘发的样子、穿衣的样子、玩耍的样子、行走的样子、来往的样子等等，也彼此不同。
那些种种差异，都被“以无明、渴爱为根本原因的业所生的性色”所摆布、所主宰、所掌控。
女性色主宰控制，使一切依女性形相等等的样态而生起，而不依男性形相等等的样态而生起；男性色也同样主宰控制，使一切唯依男性形相等等的样态而生起，而不依女性形相等等的样态而生起。
它作为主宰者而加以掌控。
因此，女性色便称为女性根，男性色便称为男性根。(Mūlaṭī-1-150.)
